# 世界观构建SOP（从零构建新世界）

> **核心定位：** 从一个念头到一个自洽、有深度、有生命力的世界观，七步标准化流程。
>
> **适用场景：** 开新书前的世界观搭建、长篇作品的世界观深化、跨题材创作的世界观重构
>
> **预计耗时：** 极简版1天，标准版3-5天，深度版7天以上
>
> **核心原则：** 先有魂，再有骨，再有血有肉，最后才是皮相。

## 第一阶段：核心矛盾定义（找魂）

### 目标
用一句话说清楚：这个世界最根本的矛盾是什么？

### 执行步骤

**步骤1：灵感捕捉——你最想写什么？**
- 拿出一张纸，随便写：你对这个世界最着迷的点是什么？
- 是力量体系？是某种社会制度？是一个场景？还是一种情感？
- 不要评判，想到什么写什么，写20-30个关键词

**步骤2：提炼核心——最根本的冲突是什么？**
- 从关键词里，找出最让你兴奋的那个点
- 问自己：这个点背后，最根本的矛盾是什么？
- 用"XX vs XX"的格式写出来
- 比如：秩序 vs 自由、命运 vs 抗争、人性 vs 兽性

**步骤3：题材匹配——这个矛盾适合什么题材？**
- 这个核心矛盾，放在什么题材里最有张力？
- 是玄幻？都市？科幻？还是别的？
- 参考KC-SKILL-034「题材选择与定位」

**步骤4：一句话概念—— elevator pitch**
- 用一句话概括你的世界观核心概念
- 格式："在一个____的世界里，____（主角）要____，但____（核心冲突）"
- 比如："在一个灵气复苏的现代都市里，一个普通高中生要守护自己的家人，但世界正在被诡异侵蚀"

### 本阶段产出物
- [ ] 20-30个灵感关键词
- [ ] 核心矛盾陈述（XX vs XX）
- [ ] 一句话核心概念
- [ ] 题材选择与理由

### 验收标准
- [ ] 核心矛盾够根本吗？（不是小打小闹，能支撑长篇）
- [ ] 你自己真的感兴趣吗？（写不下去的时候靠这个撑着）
- [ ] 一句话概念能打动你自己吗？
- [ ] 题材和核心矛盾匹配吗？

## 第二阶段：规则体系搭建（搭骨架）

### 目标
设计3-5条核心规则，以及完整的力量/资源体系。

### 执行步骤

**步骤1：核心规则设计——3-5条就够了**
- 这个世界最核心的规则是什么？
- 什么能做？什么不能做？
- 规则的边界在哪里？
- 把核心规则控制在3-5条，太多记不住

**步骤2：力量体系设计——怎么变强？**
- 力量的来源是什么？（灵气/异能/科技/魔法...）
- 力量分多少个等级？每个等级叫什么？
- 每个等级的特征和差距是什么？
- 升级需要什么条件？（资源/悟性/机遇...）
- 升级难度是递增的吗？（越往上越难）

**步骤3：资源体系设计——稀缺资源是什么？**
- 这个世界最稀缺的资源是什么？
- 资源怎么获取？（修炼/工作/抢夺/交易...）
- 资源怎么分配？（谁掌握资源？）
- 资源的稀缺度如何？（大部分人缺吗？）

**步骤4：代价设计——力量越大代价越大**
- 使用力量需要付出什么代价？
- 升级过快有什么副作用？
- 不同力量体系有不同的代价吗？
- 参考KC-SKILL-033「能力代价系统设计」

### 本阶段产出物
- [ ] 核心规则清单（3-5条）
- [ ] 力量体系等级表
- [ ] 资源类型与获取方式表
- [ ] 代价体系设计

### 验收标准
- [ ] 核心规则够简洁吗？（3-5条，能记住）
- [ ] 规则边界清晰吗？（什么能做什么不能做）
- [ ] 力量体系有天花板吗？（最高级别有多强）
- [ ] 代价和力量成正比吗？
- [ ] 资源是稀缺的吗？（不是随便就能获得）

## 第三阶段：社会结构设计（建社会）

### 目标
搞清楚：这个世界的人是怎么组织起来的？谁在顶端？谁在底层？怎么往上爬？

### 执行步骤

**步骤1：阶层划分——谁在上面谁在下面？**
- 社会分几个阶层？（顶层/上层/中层/底层...）
- 每个阶层大概占多少比例？
- 每个阶层的生活状态是怎样的？
- 阶层之间流动的可能性大吗？

**步骤2：势力划分——有哪些主要势力？**
- 世界上有哪些主要势力？（宗门/国家/公司/组织...）
- 每个势力的核心利益是什么？
- 势力之间是什么关系？（敌对/合作/竞争...）
- 势力分布图大概是什么样的？

**步骤3：权力来源——凭什么统治？**
- 顶层靠什么维持统治？（力量？财富？血统？信仰？）
- 底层为什么不造反？（打不过？有饭吃？被洗脑？）
- 权力交接是怎么进行的？（世袭？选举？比武？）
- 有没有制衡机制？（谁来监督统治者？）

**步骤4：上升通道——底层怎么往上爬？**
- 普通人有哪些途径改变命运？
- 最主要的上升通道是什么？
- 难度有多大？（万分之一？百分之一？）
- 有没有"玻璃天花板"？（某个阶层就到顶了）

**步骤5：职业体系——人们靠什么吃饭？**
- 这个世界有哪些主要职业？
- 战斗职业有哪些？非战斗职业有哪些？
- 最赚钱的职业是什么？最受尊敬的呢？
- 不同职业之间的地位差距大吗？

### 本阶段产出物
- [ ] 社会阶层结构图
- [ ] 主要势力一览表（含核心利益、关系）
- [ ] 权力来源与运行机制说明
- [ ] 上升通道分析
- [ ] 职业体系概览

### 验收标准
- [ ] 社会结构符合权力集中定律吗？（二八定律）
- [ ] 权力来源合理吗？（不是"我就是能统治"）
- [ ] 上升通道清晰吗？难度合理吗？
- [ ] 势力之间有利益冲突吗？（为剧情做准备）
- [ ] 普通人的生活状态具体可感吗？

## 第四阶段：文化心理塑造（育文化）

### 目标
搞清楚：这个世界的人怎么想？信什么？为什么这么活？

### 执行步骤

**步骤1：核心价值观——什么是"好"？什么是"坏"？**
- 这个世界的人最看重什么？（力量？财富？权力？道德？）
- 什么是值得追求的？什么是被唾弃的？
- 不同阶层的价值观一样吗？
- 不同地区的价值观有差异吗？

**步骤2：信仰体系——人信什么？**
- 有宗教吗？有多少种？
- 主流信仰是什么？
- 信仰和权力是什么关系？（政教合一？互相利用？）
- 有没有禁忌？触犯禁忌会怎么样？

**步骤3：习俗传统——人怎么过日子？**
- 有什么重要的节日？节日是怎么来的？
- 婚丧嫁娶有什么讲究？
- 有没有什么独特的风俗习惯？
- 这些习俗背后的原因是什么？

**步骤4：审美偏好——什么是美？**
- 这个世界的人觉得什么是美？
- 流行的服饰风格是什么？
- 建筑风格是什么样的？
- 艺术形式有哪些？（音乐、绘画、文学...）

**步骤5：文化差异——不同地方不一样**
- 不同地区/民族的文化有什么不同？
- 不同势力的文化有什么特色？
- 文化差异会导致冲突吗？
- 有没有文化融合的地方？

### 本阶段产出物
- [ ] 核心价值观说明
- [ ] 信仰体系概览
- [ ] 重要习俗与节日清单
- [ ] 审美偏好与风格指南
- [ ] 地域文化差异说明

### 验收标准
- [ ] 文化有根源吗？（不是凭空冒出来的）
- [ ] 文化和地理、历史、规则对应吗？
- [ ] 文化会影响人物的选择吗？
- [ ] 有文化冲突吗？（为剧情做准备）
- [ ] 有仪式感和符号感吗？（容易记住）

## 第五阶段：地理历史铺陈（铺背景）

### 目标
搞清楚：世界长什么样？是怎么变成今天这样的？

### 执行步骤

**步骤1：地图设计——世界长什么样？**
- 世界有多大？（一个大陆？一个星球？一个宇宙？）
- 主要地形地貌有哪些？（山脉、平原、海洋、森林、沙漠...）
- 重要地点在哪里？（都城、宗门、秘境、战场...）
- 画一张简单的地图（不需要好看，位置对就行）

**步骤2：气候与物产——一方水土养一方人**
- 不同地区的气候怎么样？
- 各地的特产是什么？（矿物、植物、动物...）
- 物产如何影响当地的经济和文化？
- 有没有什么稀缺资源只在特定地方有？

**步骤3：交通与交流——人们怎么来往？**
- 主要的交通方式是什么？（走路、骑马、飞舟、传送...）
- 从一个地方到另一个地方要多久？
- 主要的商路在哪里？
- 信息怎么传递？（信使、飞鸽、传音、网络...）

**步骤4：历史年表——世界是怎么来的？**
- 世界是怎么诞生的？（神话/真实）
- 历史上有哪些重要的时代/时期？
- 每个时期的标志性事件是什么？
- 这些事件对现在有什么影响？

**步骤5：历史真相——有什么被掩盖的？**
- 官方记载的历史，是真的吗？
- 有什么被掩盖的历史真相？
- 谁在掩盖？为什么？
- 真相揭开之后会怎么样？

### 本阶段产出物
- [ ] 世界地图（简版即可）
- [ ] 重要地点一览表
- [ ] 交通方式与时间估算表
- [ ] 历史大事年表
- [ ] 历史真相/秘密清单

### 验收标准
- [ ] 地理环境和文化、经济对应吗？
- [ ] 距离和交通时间合理吗？（没有瞬移bug）
- [ ] 历史能解释现状吗？
- [ ] 有历史悬念吗？（读者想知道真相）
- [ ] 历史不会太复杂吧？（读者能记住）

## 第六阶段：自洽性检验（查bug）

### 目标
全面检查世界观，找出bug、漏洞、矛盾，修复它们。

### 执行步骤

**步骤1：七维自检——一个维度一个维度过**
- 对照KC-SKILL-047「世界设定自洽性检验体系」
- 七个维度一个一个检查：
  1. 规则一致性
  2. 逻辑闭环性
  3. 时间线一致性
  4. 空间地理合理性
  5. 人物行为合理性
  6. 社会文化自洽性
  7. 力量体系稳定性

**步骤2：压力测试——把世界推到极限**
- 极端情境测试：如果最强的人全力出手会怎样？
- 边界条件测试：规则的边界在哪里？
- 连锁反应测试：改变一个设定，会引发什么？
- 反向推理测试：从现状能倒推回原因吗？
- 平民视角测试：普通人能活下去吗？

**步骤3：bug分级——哪些必须改，哪些可以放**
- S级bug：核心规则矛盾，必须立刻改
- A级bug：重要逻辑漏洞，尽快改
- B级bug：次要设定矛盾，有空再改
- C级bug：小细节错误，攒一波一起改

**步骤4：修复bug——一个一个解决**
- 参考KC-SKILL-047的「bug修复方法论」
- 打补丁？埋伏笔？将错就错？还是直接修改？
- 修复完之后，再检查一遍，确保没有新bug

### 本阶段产出物
- [ ] 七维自洽性检验表
- [ ] 压力测试记录
- [ ] bug清单（含分级）
- [ ] bug修复记录

### 验收标准
- [ ] S级bug全部清零
- [ ] A级bug修复80%以上
- [ ] 核心规则没有矛盾
- [ ] 主要剧情线逻辑自洽
- [ ] 你自己相信这个世界吗？

## 第七阶段：故事化适配（做对接）

### 目标
让世界观为故事服务，而不是为设定而设定。

### 执行步骤

**步骤1：主角适配——主角在世界里的位置**
- 主角出身在哪个阶层？
- 主角的初始状态和世界观是什么关系？
- 世界观给主角提供了什么机遇？
- 世界观给主角制造了什么困境？

**步骤2：剧情适配——世界观怎么推动剧情**
- 核心冲突和世界观是什么关系？
- 世界观的规则，怎么影响剧情走向？
- 有哪些剧情是只有在这个世界观里才会发生的？
- 世界观的哪些设定，可以成为关键剧情点？

**步骤3：人物适配——世界观塑造人物**
- 主要人物的性格和世界观有什么关系？
- 人物的目标和动机，和世界观有什么联系？
- 不同势力的人物，有不同的思维方式吗？
- 人物的成长，和世界观的变化有呼应吗？

**步骤4：主题适配——世界观承载主题**
- 你想表达的主题，和世界观是什么关系？
- 世界观的设定，是不是在强化主题？
- 有没有什么设定，和主题无关甚至冲突？
- 怎么通过世界观的呈现，让主题更有深度？

**步骤5：设定瘦身——砍掉没用的设定**
- 哪些设定和故事完全没关系？——砍掉
- 哪些设定很酷但用不上？——先放着，需要的时候再拿出来
- 哪些设定是为了凑数的？——删掉
- 记住：设定的价值在于"用"，不在于"有"

### 本阶段产出物
- [ ] 主角与世界观适配分析
- [ ] 世界观关键剧情点清单
- [ ] 主要人物世界观背景
- [ ] 主题-世界观呼应表
- [ ] 精简后的世界观设定大纲

### 验收标准
- [ ] 世界观和故事是一体的吗？（不是两张皮）
- [ ] 设定都有用武之地吗？（不是摆设）
- [ ] 主角的困境和机遇，都是这个世界特有的吗？
- [ ] 主题通过世界观得到强化了吗？
- [ ] 设定足够精简吗？（读者能记住核心设定）

## 三种版本的工作量对比

| 版本 | 适用场景 | 阶段深度 | 预计耗时 | 设定完整度 |
|:-----|:---------|:---------|:--------:|:----------:|
| **极简版** | 短篇/快节奏/弱设定题材 | 重点做1、2、7阶段，其他简化 | 1天 | 40% |
| **标准版** | 中长篇/大多数题材 | 7个阶段全部做到位 | 3-5天 | 70% |
| **深度版** | 长篇/强设定题材/系列作品 | 每个阶段都深挖，做细做全 | 7天+ | 90%+ |

## 常见问题与解答

**Q：设定写了很多，但故事推进很慢，怎么办？**
A：记住"设定跟着剧情走"原则——剧情需要什么，再补什么。不要一开始就把所有设定都写完，写不完的，而且很多用不上。先搭好核心框架，细节边写边补。

**Q：想到什么就写什么，设定越来越乱，怎么办？**
A：建立"设定索引"，把所有设定分类整理好。每次加新设定，都更新索引。定期（比如每卷）对照检查一遍，有没有矛盾。

**Q：总是忍不住加新设定，越写越复杂，怎么办？**
A：问自己三个问题：这个设定对剧情有用吗？对人物有用吗？对主题有用吗？如果都没用，再酷也砍掉。控制住自己的"设定癖"。

**Q：世界观和别人的太像了，怎么办？**
A：找到你的"核心差异点"——哪怕只有一个。把这个差异点做深做透。差异不在多，在于有没有做到极致。参考KC-SKILL-048「题材迁移与适配方法论」。

**Q：写完才发现世界观有大bug，怎么办？**
A：分情况：
- 还没发出去：直接改，不要犹豫

**其实检验世界观的标准只有一个：**

**你自己信不信这个世界？**

"哇，这个世界真的存在。"
"如果我在这个世界里，我会怎么活？"
"好想知道接下来会发生什么。"

那这个世界观就是成功的。

所有的方法和技巧，都只是帮你达到这个状态的工具。

**不要本末倒置。**

**设定是手段，故事才是目的。**
