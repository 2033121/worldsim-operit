# KC-SKILL-100 · 世界观角色设定方法论

> **核心定位：** L3元方法论——从"怎么写好一个人"跃迁到"怎么让角色在世界观中生长出来"。不是角色 psychology，是角色 ecology。
>
> **适用范围：** 多世界体系、群像工程、众生相工业化量产、世界观中的角色生态设计。

---

## 一、角色生态学：底层思维模型

### 1.1 核心命题

传统角色设计问：**"这个角色是谁？"**
世界观角色设计问：**"这个角色为什么只能在这个世界中长成这样？"**

> 角色不是被"设计"出来的，是被**环境塑造**出来的。你的工作是：先建环境，再放种子，让角色自己长出来。

### 1.2 角色生态四要素

| 要素 | 定义 | 设计问题 |
|:-----|:-----|:---------|
| **土壤** | 角色生长的社会环境（阶层/文化/规则） | 这个世界的什么规则，塑造了这个人的生存策略？ |
| **气候** | 角色经历的历史/时代背景 | 这个时代的什么事件，在这个人身上留下了痕迹？ |
| **养分** | 角色获取资源的方式 | 在这个世界，这个人靠什么活下去？ |
| **竞争** | 角色面对的生存压力 | 这个世界的什么力量，在挤压这个人的生存空间？ |

**示例（汤师）：**
- 土壤：图兰通感美食街的地下黑市文化——"被体制驱逐的人只能在体制缝隙里活"
- 气候：通感协调会的执照制度崩溃了他的正式职业生涯
- 养分：通过情绪调酒的口碑在地下渠道获取资源
- 竞争：镜界科技财团的收购压力 + 地下世界的"要么刀要么肉"法则

### 1.3 角色-世界观绑定检验

**三问检验法：**

1. **替换检验：** 把这个角色放到另一个世界，他还能存在吗？
   - 如果答案是"能"，说明角色与世界观绑定不够深。
   - 汤师放到都市异能世界？不能——他的核心能力"味觉编织"依赖图兰特有的"通感"体系。

2. **剥离检验：** 去掉这个世界的某个核心规则，这个角色还成立吗？
   - 去掉图兰的"通感协调会执照制度"，汤师就不存在"被取消执照后转入地下"的核心经历。

3. **逆向检验：** 这个角色如果改变世界的某个规则，世界会怎么反应？
   - 汤师如果公开了情绪调酒的配方，图兰地下感官交易所会消失，镜界财团会介入——世界因此改变。

## 二、八段式框架的底层逻辑

### 2.1 从"视觉可见"到"深层不可见"的递进

```
基础信息（外貌/姿态）        ← 读者第一眼看到
    ↓
背景履历（经历/状态）        ← 读者理解"为什么是这样"
    ↓
特殊信息（能力/物品）        ← 读者了解"能做什么"
    ↓
人际关系（关系网络）         ← 读者看到"和谁有关"
    ↓
角色声音（语言/自白）        ← 读者"听到"内在
    ↓
额外备注（隐藏深度）         ← 读者意识到"还有秘密"
    ↓
当前切入点（故事启动）       ← 读者期待"会发生什么"
    ↓
辅助定位（团队功能）         ← 读者确认"在故事中的位置"
```

**核心逻辑：** 每一层都在回答一个更深层的问题。

| 模块 | 回答的问题 | 读者心理 |
|:-----|:-----------|:---------|
| 基础信息 | "这个人长什么样？" | 好奇 |
| 背景履历 | "这个人为什么是现在这样？" | 理解 |
| 特殊信息 | "这个人能做什么？" | 评估 |
| 人际关系 | "这个人和谁有关？" | 连接 |
| 角色声音 | "这个人心里在想什么？" | 共情 |
| 额外备注 | "这个人还有什么我不知道的？" | 悬念 |
| 切入点 | "故事要从哪里开始？" | 期待 |
| 辅助定位 | "这个人在故事里是什么位置？" | 确认 |

### 2.2 "有一次..."故事化经历的底层逻辑

**为什么不用抽象概括，要用具体场景？**

| 方式 | 示例 | 效果 |
|:-----|:-----|:-----|
| **抽象概括** | "汤师从小在通感美食街长大，学会了辨认情绪气味" | 信息传递，无感 |
| **具体场景** | "有一次我给一碗汤加'释然'，加成了'麻木'。客人喝完后在店里坐了一下午，然后走出去，再也没回来" | 画面+情感+顿悟 |

**"有一次..."格式的四层功能：**
1. **画面感**：具体场景让读者"看见"
2. **情感冲击**：结果让读者"感受"
3. **顿悟句**："从那以后我就知道"让经历有**意义**
4. **递进链**：多次经历形成角色的**信念演化史**

### 2.3 辅助型定位思维

**传统思维 vs 辅助型思维：**

| 维度 | 传统主角思维 | 辅助型定位思维 |
|:-----|:-------------|:---------------|
| 核心问题 | "这个角色有多强？" | "这个角色能让团队多强？" |
| 能力设计 | 全面、升级、突破极限 | 专精、有代价、有明确边界 |
| 叙事功能 | 解决问题的人 | 让问题能被解决的人 |
| 情感价值 | 让读者崇拜 | 让读者心疼、信任、依赖 |

**辅助型角色不是配角。** 在群像工程中，每个角色都是主角——只是各自发光的领域不同。

**辅助型定位设计公式：**
```
[角色]不是[直接做X的人]，而是[让X能被完成的人]。
他的价值不在[战斗/决策/领导]中，而在[战前/战后/战斗中某个特定时刻]。
```

## 三、角色设定五步法

### Step 1：确定生态位（生态定位）

**问题：** 在这个世界的社会结构中，这个角色占据什么位置？

**生态位分析表：**

| 维度 | 问题 | 示例（汤师） |
|:-----|:-----|:-------------|
| **阶层** | 社会阶层？上升/下降/固化？ | 从正式通感师跌落到黑市从业者——下降通道 |
| **合法性** | 合法/灰色/非法？ | 非法（无执照） |
| **资源控制** | 控制什么资源？稀缺度？ | 控制"情绪纯化"技艺——极度稀缺但非垄断 |
| **信息不对称** | 知道什么别人不知道的？ | 知道某些黑市香料的来源和危险性 |
| **社会网络** | 连接哪些圈子？ | 图兰地下市场 ↔ 镜界地下渠道 |

**产出：** 生态位定位卡（一句话："在[世界]的[领域]，[角色]是一个[身份]，靠[能力/资源]在[合法状态]下生存，与[圈子]有连接。"）

### Step 2：植入环境印记（塑造因果）

**问题：** 这个世界的什么特征，在这个角色身上留下了不可磨灭的印记？

**环境印记三类型：**

| 类型 | 说明 | 设计方法 |
|:-----|:-----|:---------|
| **物理印记** | 身体层面的痕迹 | 疤痕/变异/改造/疾病——每道痕迹对应一个世界事件 |
| **心理印记** | 性格/行为模式的成因 | 某种防御机制/习惯/恐惧——对应世界的某种威胁 |
| **社会印记** | 身份/关系的形成 | 某种社会规则导致的处境——对应世界的制度设计 |

**示例（R）：**
- 物理印记：虹膜纹路稀疏（四阶铭忆过度使用的痕迹）→ 图兰特有的"铭忆"能力体系
- 心理印记：对"真相"的病态执着 → 图兰"真话拼在一起是谎言"的社会环境
- 社会印记：代号"R"来自"冗余档案"分类 → 图兰官僚体系对个体的编号化处理

### Step 3：设计能力边界（功能定义）

**问题：** 这个角色能做什么、不能做什么？能力与世界规则的关系是什么？

**能力设计四原则：**

1. **来源绑定原则**：能力的来源必须与世界观规则一致
   - 汤师的"味觉编织"来自图兰"通感"体系 + 母亲训练 + 美食街实战
   - 不是"天生神力"，是"环境+传承+实践"

2. **上限明确原则**：每个能力必须有"不能做"的边界
   - 汤师不能"强制植入情绪"，只能"邀请体验"
   - R不能处理"被多层幻术覆盖的记忆"

3. **代价对等原则**：能力越强，代价越重
   - 汤师的情绪缓冲需要承受"总和反噬"
   - R的四阶铭忆导致"早期记忆断片"

4. **变化预留原则**：至少一个能力处于非稳定状态
   - 汤师的"反向通感"正在变异
   - 为角色成长/危机爆发预留空间

### Step 4：编织关系网络（连接锚定）

**问题：** 这个角色与世界中哪些势力/人物/事件有不可切割的连接？

**关系网络三层：**

```
核心层（1-3人）：血缘/师徒/宿敌/挚爱——不可切断的连接
    ↓
中间层（3-5人）：同行/客户/上司/地下联系人——功能型连接
    ↓
外围层（不定）：口碑传播者/信息节点/偶然交集——松散连接
```

**关系设计要点：**
- 每个核心层关系都要有**未解决的张力**（冻结的情感/未收的债务/悬而未决的恩怨）
- 每个关系都要能**触发故事**（不是静态的，是随时可以激活的）
- 关系网络要**覆盖不同势力**（不要把所有关系都放在同一个阵营）

### Step 5：预埋叙事钩子（故事启动）

**问题：** 这个角色的设定中，隐藏了哪些可以在故事中引爆的钩子？

**钩子预埋清单：**

| 钩子类型 | 预埋位置 | 引爆方式 |
|:---------|:---------|:---------|
| **能力变异** | 特殊信息·变化状态 | 在关键时刻失控 |
| **未处理债务** | 额外备注 | 债主上门 |
| **未得答案** | 额外备注 | 答案浮现但代价巨大 |
| **隐藏关系** | 人际关系·暗面 | 关系曝光引发连锁反应 |
| **持有物秘密** | 特殊信息·持有物 | 物品被发现是某种关键 |
| **自白中的矛盾** | 角色声音·自白 | 自我认知与现实冲突 |

## 四、群像系统工程法

### 4.1 群像角色矩阵

当需要为一个世界设计大量角色时，使用矩阵法确保多样性：

| | 合法 | 灰色 | 非法 |
|:--|:--:|:--:|:--:|
| **高层** | [统治者/官僚] | [幕后操控者] | [地下王者] |
| **中层** | [专业人士/商人] | [灰色从业者] | [黑市中介] |
| **底层** | [普通劳动者] | [边缘求生者] | [亡命之徒] |

**使用方式：** 在每个格子中填充1-3个角色，确保每个角色都有独特的生态位。

### 4.2 功能互补原则

一个完整的团队/群像，角色功能应该覆盖：

| 功能类型 | 说明 | 示例 |
|:---------|:-----|:-----|
| **信息型** | 获取/整合/验证信息 | R（信息整合者） |
| **执行型** | 完成具体任务/战斗 | 禁手（修假功法修炼者） |
| **缓冲型** | 处理情绪/精神/社交 | 汤师（情绪环境塑造者） |
| **连接型** | 建立关系/获取资源 | 老饕（黑市中间人） |
| **决策型** | 做出关键判断 | （视故事需要配置） |
| **牺牲型** | 承担代价/掩护他人 | （视故事需要配置） |

### 4.3 众生相工业化量产法

当需要大量NPC/背景角色时：

**快速生成公式：**
```
[生态位] + [一个身体标记] + [一个口头禅] + [一个秘密]
```

**示例：**
- 忆砂矿区边缘镇的拾荒老人 + 左手缺了两根手指（矿难） + "年轻人，别往深处走" + 他知道矿脉深处有一条通往镜界的裂缝
- 通感美食街的洗碗工 + 总是戴着一副破手套（掩盖手上的通感茧） + "这汤味道不对" + 她能尝出汤里被加了什么，但她从不说出来

## 五、多世界角色适配指南

### 5.1 跨世界角色迁移原则

当同一个角色需要在多个世界中存在（或设计多个世界的对应角色）：

**保留层（不变）：**
- 核心性格特质
- 核心人际关系模式
- 核心叙事功能

**适配层（根据世界规则调整）：**
- 能力表现形式（图兰的"通感" → 都市的"共情异能" → 科幻的"神经接驳"）
- 社会地位（修真世界的"散修" → 都市的"自由职业者" → 科幻的"无身份编码者"）
- 生存策略（修真的"找灵石" → 都市的"接私活" → 科幻的"黑市数据交易"）

**替换层（完全重新设计）：**
- 具体能力名称和效果
- 具体的势力/组织名称
- 具体的持有物

### 5.2 世界特性对角色的塑造力

| 世界特性 | 对角色的塑造方向 |
|:---------|:----------------|
| **高死亡率环境** | 角色普遍有"即时满足"倾向，不规划长远 |
| **强等级制度** | 角色行为高度规范化，越级者必有特殊动机 |
| **信息封闭** | 角色普遍多疑，信息即权力 |
| **资源极度稀缺** | 角色关系以"交换"为核心，情感被工具化 |
| **超自然公开** | 角色对异常现象麻木，日常化处理方式 |
| **超自然隐藏** | 角色有双重生活，身份管理成为核心技能 |

## 六、质量控制清单

### 6.1 角色设定自检表

| 检查项 | 合格标准 | 常见问题 |
|:-------|:---------|:---------|
| **世界观绑定** | 去掉世界核心规则，角色不成立 | 角色放到任何世界都一样 |
| **能力有界** | 明确说出"不能做什么" | 能力描述只有"能做什么" |
| **代价对等** | 每个能力都有对应代价 | 能力强但无代价 |
| **经历具体** | 用"有一次..."场景而非抽象概括 | "他从小就很聪明" |
| **关系有张力** | 至少一个核心关系有未解决问题 | 所有关系都和谐稳定 |
| **持有物有故事** | 每件物品都能讲出起源 | 物品只是装备清单 |
| **声音独特** | 口头禅/自白能区分于其他角色 | 所有角色说话风格一样 |
| **定位清晰** | 能用一句话说明在团队中的功能 | "他是个好人" |
| **钩子预埋** | 至少一个可以在故事中引爆的点 | 设定中没有悬念 |
| **局限明确** | 明确说出"遇到什么情况会失败" | 角色万能化 |

### 6.2 群像平衡检查

- [ ] 角色功能覆盖是否完整？（信息/执行/缓冲/连接/决策/牺牲）
- [ ] 角色强度是否平衡？（没有明显过强或过弱的角色）
- [ ] 角色关系是否交错？（不是一对一的简单配对，是网状连接）
- [ ] 角色背景是否多样？（不同阶层/势力/世界观的代表）
- [ ] 每个角色是否有独立的叙事线？（不是纯工具人）

## 七、实战案例：从模板到角色

### 案例：为一个末日废土世界设计一个角色

**Step 1 生态位：** 在辐射废土的地下集市，是一个"记忆交易者"——用特殊装置提取和出售幸存者的记忆碎片，灰色合法，与多个拾荒者团伙和地下医生有联系。

**Step 2 环境印记：**
- 物理：右眼是机械义眼（被辐射灼伤后替换）→ 废土的高辐射环境
- 心理：对"遗忘"的执念 → 废土中"记忆是最后的财产"的文化
- 社会：没有正式姓名，只有代号"拾忆" → 废土中身份的流动性

**Step 3 能力边界：**
- 能：提取记忆碎片、分类存储、选择性出售
- 不能：修改记忆、提取已死亡超过24小时的人的记忆
- 代价：每次提取后，自己会随机丢失一段近期记忆
- 变化：近期开始出现"记忆混淆"——分不清哪些是自己的、哪些是提取的

**Step 4 关系网络：**
- 核心：死去的妹妹（她是他开始提取记忆的原动力——想保留她的记忆）
- 中间：地下医生（为他处理义眼）、拾荒者头目（提供"货源"）
- 外围：各种来出售/购买记忆的幸存者

**Step 5 叙事钩子：**
- 他在某次提取中，意外获得了一段关于"地表仍有宜居区"的记忆
- 但他分不清这段记忆是真实的，还是某个濒死者的幻觉
- 而他的"记忆混淆"正在加重...

> **核心心法：** 角色设定的最高境界，不是让读者记住这个角色，而是让读者**相信这个角色真实存在过**——在某个世界的某个角落，在某个时间点，这个人真的活着、呼吸着、做着他的事。
>
> 你的任务不是"设计"一个角色，而是**还原**一个已经存在的人。
