# 开篇黄金三章

## 一、核心原则：前三章定生死

> 编辑看前三章决定签不签约。
> 读者看前三章决定追不追更。
> 前三章没写好，后面写得再好也没用。

编辑和读者只给你3000字的机会。前三章必须做到"快、准、狠"——立刻让主角陷入困境，用冲突抓住眼球；金手指快速上线并解决眼前小危机；同时埋下长线伏笔，让编辑看到"长篇潜力"。

**铁律**：开篇不能慢悠悠写景、介绍世界观。第一句话就要让主角"陷入困境"。

**核心公式：**
```
黄金三章 = 第一章抓眼球 + 第二章立人设 + 第三章抛主线
```

**三章分工：**
- 第一章：吸引（让读者想继续看）
- 第二章：了解（让读者知道讲的是什么）
- 第三章：期待（让读者追下去）

---

## 二、第一章：抓眼球——3秒抓住读者

### 核心目标
让读者看到第一章就被吸引，想继续往下看。

### 第一章三件事

**1. 抛钩子（最重要）**
- 第一章第一段就要有钩子
- 什么是钩子？——让读者想知道"为什么"、"然后呢"的东西
- 参考KC-SKILL-003「钩子九连环」
- 钩子类型：悬念、冲突、反差、危机、金手指...
- 没有钩子的第一章，是失败的第一章

**2. 展示世界观特色**
- 让读者知道：这是个什么样的世界？
- 不用全说，说最有特色的那一点就行
- 比如：
  - 这是个修仙世界
  - 这是个末世
  - 这是个系统流世界
  - 这是个都市异能世界
- 用场景、用对话、用行动展示，不要上来就念设定

**3. 主角登场**
- 第一章主角就要出场
- 不要写了半天，主角还没出现
- 主角一出场，就要给读者留下印象
- 印象不用深，但要有个大概的概念：这是个什么样的人？

### 第一章结构模板
```
第一段：钩子（3秒抓住）
   ↓
第1-10段：展示场景 + 主角登场 + 初步冲突
   ↓
第一章结尾：悬念/反转/小高潮（让读者想看下一章）
```

### 第一章实操步骤

**步骤1（前300字）：抛出至少两个冲突**
- 冲突公式：`被欺负 + 退婚/羞辱/失势` 两个以上负面事件叠加
- 必须在第一句话就把读者拽进冲突现场

**步骤2（300-1000字）：金手指上线**
- 让金手指直接解决眼前的小危机
- 不要等读者耐心耗尽，立刻给一个"小爽点"

**步骤3（1000-2500字）：建立主角处境**
- 主角为什么会被欺负？（灵根尽废/被陷害/重生归来）
- 主角的核心欲望是什么？（复仇/夺回/守护）

### 第一章开篇模板（正确示范）

```
[冲突1] + [冲突2] + [处境交代] + [金手指觉醒] + [小爽点]

"废物！给我跪下！"林家练武场，堂兄林浩一脚踹在林辰胸口，
他捂着渗血的肋骨，听着周围的哄笑——今天是他被测出"灵根尽废"
的第三天，也是未婚妻当众退婚的日子。
```

### 第一章的长度
- 建议：2000-3000字
- 太短：说不清楚
- 太长：读者没耐心看完
- 重点信息放前面，别藏着掖着

## 三、第二章：立人设——让读者认识主角

### 核心目标
让读者了解主角、喜欢主角、代入主角。

### 第二章三件事

**1. 深化主角形象**
- 第一章只是露个脸，第二章要让读者认识主角
- 主角是什么样的人？
  - 性格怎么样？
  - 有什么优点/缺点？
  - 目标是什么？
  - 现在处境怎么样？
- 通过行动、对话、选择来展现，不要直接介绍

**2. 展示金手指/核心能力**
- 如果有金手指，第二章最好就亮出来
- 亮出来之后，展示一下效果
- 给读者一个期待：有了这个，主角以后会有多牛
- 金手指要有规则、有限制，不能太无脑

**3. 引出主要矛盾**
- 主角现在面临的最大问题是什么？
- 接下来要解决什么事？
- 让读者知道：故事大概要讲什么？
- 矛盾不用太大，但要明确

### 第二章结构模板
```
承接第一章结尾的悬念
   ↓
展示主角的性格和能力
   ↓
金手指/核心能力亮相（如果有）
   ↓
引出当前的主要矛盾
   ↓
第二章结尾：新的悬念/小高潮
```

### 第二章实操步骤

**步骤1：展示金手指实用性**
- 系统流：写主角用系统奖励修炼，速度远超常人
- 签到流：在家族祠堂签到获得"祖传宝刀"
- 重生流：利用前世记忆提前布局

**步骤2：发布短期目标（1-3个月可完成）**
- 公式：`[时间限制] + [明确对手] + [明确奖励]`
- 示例："三个月后的家族大比，击败林浩，夺回属于自己的一切。奖励：地级功法一部。"

### 短期目标发布模板

```
[金手指/系统/前辈] + 发布任务 + [时间限制] + [对手/目标] + [奖励]

示例：
系统任务发布：三个月后的家族大比，击败林浩，夺回属于自己的一切。
奖励：地级功法一部。
```

### 读者代入的关键
- 主角要有目标：知道自己要干什么
- 主角要有困境：不是一帆风顺的
- 主角要有闪光点：让读者喜欢TA
- 读者喜欢主角了，才会追下去

## 四、第三章：抛主线——让读者追下去

### 核心目标
抛出主线剧情，让读者对后面的故事产生期待。

### 第三章三件事

**1. 主线明确化**
- 前两章可能还是云里雾里，第三章要让读者看明白
- 这本书主要讲什么？
  - 主角要干什么？
  - 最终目标是什么？
  - 最大的敌人/困难是什么？
- 不用讲完全部，但大方向要清楚

**2. 第一个小高潮**
- 第三章结尾最好有一个小高潮
- 比如：第一场战斗、第一次打脸、第一个反转
- 让读者爽一下，或者震撼一下
- 爽完之后，再抛一个更大的钩子

**3. 留下大期待**
- 第三章结束，读者应该会想：
  - "接下来会怎么样？"
  - "主角接下来会怎么做？"
  - "好期待后面的剧情！"
- 留下期待，读者才会追更

### 第三章结构模板
```
推进当前矛盾
   ↓
冲突升级
   ↓
第一个小高潮（打脸/战斗/反转）
   ↓
主线方向明确
   ↓
第三章结尾：更大的钩子 + 期待感
```

### 第三章实操步骤

**步骤1：埋设"土里种子"型伏笔**
- 不能太明显，要像"埋在土里的种子"
- 后期回收时让读者觉得"作者早有安排"

**步骤2：伏笔三类型分布**
- 主线核心伏笔：影响全书走向（身世/世界观核心秘密）
- 人物暗线伏笔：影响角色关系（未婚妻眼神复杂=有苦衷）
- 支线彩蛋伏笔：增加世界观厚度（瓶底奇怪符号=上古神族标记）

### 伏笔埋设模板

```
[日常道具/动作/对话] + [不起眼的细节] + [后期回收的钩子]

示例1（道具伏笔）：
主角获得的洗髓丹，瓶底刻着一个奇怪的符号
→（伏笔：上古神族标记，暗示主角身世）

示例2（人物伏笔）：
退婚的未婚妻离开时，眼神复杂地看了主角一眼
→（伏笔：她有苦衷，后期会反转）
```

### 三章节奏模板

| 章节 | 字数 | 核心任务 | 关键产出 |
|------|------|----------|----------|
| 第一章 | 2000-2500字 | 冲突+金手指觉醒+小爽点 | 读者"留下来" |
| 第二章 | 2000-2500字 | 金手指用法展示+短期目标 | 读者"追下去" |
| 第三章 | 2000-2500字 | 长线伏笔+人物关系初现 | 读者"长期看" |

### 签约的关键
- 前三章看完，编辑要能看到：
  - 这本书的卖点是什么？
  - 核心冲突是什么？
  - 主角有没有魅力？
  - 有没有商业价值？
- 让编辑看到潜力，签约就稳了

## 五、黄金三章的节奏把控

### 节奏原则：快、准、狠
- **快**：节奏要快，不要拖沓
- **准**：信息要准，不要废话
- **狠**：冲突要狠，不要温吞水

### 信息密度
- 前三章信息密度要高
- 每一段都要有信息量
- 没用的话、没用的描写，全部删掉
- 但也不能太密，要给读者消化的空间

### 爽点分布
- 第一章：小钩子（吸引）
- 第二章：小爽点（满足）
- 第三章：中爽点 + 大期待（追更）
- 节奏：低 → 高 → 更高

### 张弛有度
- 一直紧张也不行，读者会累
- 紧张之后要有小放松
- 但放松不能太长，放松完立刻再紧张
- 像波浪一样，一波比一波高

## 六、不同题材的黄金三章侧重点

| 题材类型 | 第一章重点 | 第二章重点 | 第三章重点 | 核心卖点 |
|:---------|:----------|:----------|:----------|:---------|
| **玄幻/仙侠** | 穿越/重生+危机 | 金手指亮相 | 第一场打脸/战斗 | 升级爽、打脸爽 |
| **都市异能** | 异能觉醒+困境 | 能力展示 | 第一次装逼 | 装逼、逆袭 |

| **末世/求生** | 末世降临+危机 | 求生能力+物资 | 第一次生死战 | 生存、升级、打怪 |

## 七、开篇避坑指南（7大禁忌）

| 禁忌 | 说明 | 错误示例 | 后果 |
|------|------|----------|------|
| **1. 世界观设定开场** | 读者不关心你的世界是什么样的 | "九天大陆分五大帝国……" | 读者秒退 |
| **2. 大段心理描写** | 主角内心独白超过3段 | "林辰望着天空，回想起十年前……" | 节奏崩塌 |
| **3. 过多人物出场** | 三章出场超过8人 | 一开场就介绍全家十口人 | 读者记不住 |
| **4. 无冲突开场** | 平铺直叙、岁月静好 | "清晨的阳光洒在青阳城上……" | 留不住人 |
| **5. 主角被动** | 主角被剧情推着走 | 主角全程旁观，不主动选择 | 无代入感 |
| **6. 文笔炫技** | 过度修饰、辞藻堆砌 | "落霞孤鹜齐飞，秋水共长天一色" | 喧宾夺主 |
| **7. 信息倾倒** | 大段设定灌输 | 连续3段以上说明文无动作穿插 | 读者跳读 |

## 八、常见误区

### ❌ 误区1：第一章全是设定
- 上来就大段大段地介绍世界观、设定、背景
- 结果：读者看得头大，直接弃书
- 正解：设定要慢慢给，通过剧情、通过人物自然地带出来。先讲故事，再讲设定。

### ❌ 误区2：主角出场太晚
- 第一章写了一堆配角、一堆背景，主角到第一章结尾才出场
- 结果：读者看了半天不知道主角是谁，没代入感
- 正解：第一章前几段主角就要出场。读者要先认识主角，才会关心后面的事。

### ❌ 误区3：三章了还不知道讲什么
- 写了三章，东一榔头西一棒子，主线模糊
- 结果：读者看得云里雾里，不知道这本书到底要讲啥
- 正解：第三章结束，主线方向要明确。读者要知道主角要干什么、接下来大概会发生什么。

### ❌ 误区4：太平淡，没冲突
- 三章下来，什么事都没发生，平平淡淡
- 结果：读者看着看着就睡着了
- 正解：前三章必须有冲突、有钩子、有爽点。没有冲突就没有故事。

### ❌ 误区5：太着急，信息全倒出来
- 三章就把所有设定、所有背景、所有人物全交代了
- 结果：读者消化不了，而且后面没悬念了
- 正解：信息要一点一点给。前三章只给最必要的，剩下的慢慢抛。保留悬念，读者才会追。

### ❌ 误区6：人物没立住
- 剧情很热闹，但读者对主角没印象
- 结果：读者不关心主角，也就不关心剧情
- 正解：前三章要把主角立住。让读者知道主角是谁、什么样的人、想要什么。

## 八、黄金三章自检清单

写完前三章后，对照检查：

**第一章：**
- [ ] 第一段有钩子吗？
- [ ] 主角出场了吗？
- [ ] 展示了世界观特色吗？
- [ ] 结尾有悬念吗？
- [ ] 读者想不想看第二章？

**第二章：**
- [ ] 主角形象更清晰了吗？
- [ ] 主角的目标/困境明确了吗？
- [ ] 金手指/核心能力展示了吗？
- [ ] 主要矛盾引出来了吗？
- [ ] 结尾有钩子吗？

**第三章：**
- [ ] 主线方向明确了吗？
- [ ] 有第一个小高潮吗？
- [ ] 读者对后面有期待吗？
- [ ] 能看出这本书的卖点吗？
- [ ] 你自己想不想继续看第四章？

**整体：**
- [ ] 节奏快吗？有没有废话可以删？
- [ ] 人物立住了吗？读者喜欢主角吗？
- [ ] 有爽点吗？爽得合理吗？
- [ ] 有悬念吗？悬念够吸引人吗？
- [ ] 如果是你，你会追下去吗？

## 最后一句话

**黄金三章不是万能的，但没有黄金三章是万万不能的。**

它决定了读者会不会点进来、会不会继续看、会不会收藏追更。

**但也要记住：**

前三章写得好，不代表整本书都好。
后面的剧情、人物、节奏，同样重要。

黄金三章是敲门砖——敲开门之后，得有真东西留住人。

> 先敲开门，再留住人。
