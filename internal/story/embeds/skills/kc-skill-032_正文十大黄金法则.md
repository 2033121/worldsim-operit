# 正文十大黄金法则

## 核心原则

正文写作不是"写出来"的，而是"用法则约束出来的"。十条黄金法则是正文质量的底线，任何一条被违反，都会导致正文质量明显下降。法则之间相互支撑，不能单独使用。

**核心心法**：
- 读者相信眼睛看到的，不相信作者告诉的
- 对话的第一功能是推进剧情，不是传递信息
- 情绪的最高级是留白，不是爆发

**十法则速查**：
```
1. 先动作后心理
2. 对话推进剧情非传递信息
3. 每段存在的理由
4. 长段落情绪锚点
5. 打斗名场面定格
6. 情绪留白
7. 场景先合再开
8. 对话像人话
9. 写做什么胜于写是什么
10. 动停动停节奏
```

## 操作步骤/公式

### 法则1：先让人物动起来，再让人物想下去

**核心**：不要先写心理再写动作，而是用动作展示心理。

**对比示例**：
```
❌ 错误：
林风心里很紧张，他握紧了剑柄，额头冒出了汗。

✅ 正确：
林风的手心全是汗。
他攥攥剑柄，又松开。
又攥紧。
"来就来。"
```

**原理**：读者相信眼睛看到的，不相信作者告诉的。

---

### 法则2：对话的第一功能是推进剧情，不是传递信息

**核心**：对话要制造张力，要让读者想知道"接下来会发生什么"。

**对比示例**：
```
❌ 错误（信息对话）：
"明天我们要去对付那个妖怪。"
"好的，我们需要准备什么？"
"我们需要准备符箓、法器，还有解毒丹。"

✅ 正确（冲突对话）：
"明天的事，你想好了？"
沉默。
"我陪你。"
"不用。"
"你一个人去，我不放心。"
林风没说话，只是把剑从剑鞘里拔出来一寸。
"你这是什么意思？"
"我的意思你懂。"
```

**原理**：信息对话要短，冲突对话要长。

---

### 法则3：每一段都要有存在的理由

**核心**：写之前问自己——这段删掉，故事会不会受影响？

**三问自检**：
```
这段在推进什么？
这段在展示什么？
这段在铺垫什么？

如果三个问题都答不上来，这段可能不需要。
```

---

### 法则4：长段落要设"情绪锚点"

**核心**：每500字检查一次——主角现在是什么情绪？在做什么？

**锚点公式**：
```
[情绪状态] + [当前目标] + [下一步行动]

示例：
"林风现在很愤怒，他想杀掉对方，他要先试探对方的弱点。"

锚点不是写出来的，是写之前要明确的。
```

---

### 法则5：打斗的高潮不是招式名，是名场面定格

**核心**：读者记住的是画面，不是招式。

**对比示例**：
```
❌ 错误：
林风使出"破天剑诀"，剑光如虹，赵峰抵挡不住，身受重伤。

✅ 正确：
林风动了。
剑光像一条白线，从赵峰眼前划过。
赵峰的眼睛跟着那条线动。
然后他看见了——自己的手臂。
"我的手..."
血从断口喷出来，溅在林风脸上。
林风没擦，只是把剑收回鞘里。
"这就是看不起人的代价。"
```

**原理**：慢下来，定格，给读者反应时间。

---

### 法则6：情绪的最高级是留白

**核心**：悲伤到极致不哭，愤怒到极致不语，绝望到极致不解释。

**对比示例**：
```
❌ 错误：
苏晴很悲伤，她哭了出来，眼泪止不住地流，她觉得天都塌了。

✅ 正确：
苏晴站在窗边，一动不动。
手机响了。
她看了一眼，是他的号码。
又响了。
她把手机翻过去，屏幕朝下。
窗外的阳光很好。
她的眼睛很干。
```

---

### 法则7：场景转换要"先合再开"

**核心**：不要跳，要过渡。上一场收尾，下一场开头，中间要有衔接。

**对比示例**：
```
❌ 错误：
他们聊完已经是深夜。林风回到家。

✅ 正确：
他们聊完已经是深夜。
"太晚了，你住哪？"林风问。
"我打车。"
"我送你。"
"不用..."
林风已经拦下了车。
车里很安静。
窗外的霓虹灯一排排闪过。
林风到家的时候，已经快凌晨两点了。
他没开灯，直接倒在沙发上。
```

---

### 法则8：对话要"听"起来像人说话

**核心**：真实的人说话会停顿、会省略、会打断、会重复。

**对比示例**：
```
❌ 错误：
"我真的很喜欢你，你能不能接受我？"

✅ 正确：
"我..."
他顿了顿。
"算了，没什么。"
"你到底想说什么？"
"我喜..."
他深吸一口气。
"我喜欢你。"
"什么？"
"我说，我喜欢你。"
"你说什么？"
他沉默了两秒。
"装傻是吧。"
```

---

### 法则9：写"做什么"比写"是什么"更重要

**核心**：少用"是/有/感到"，多用"做/做/做"。

**对比示例**：
```
❌ 错误：
林风是一个很厉害的人，他有很强的实力，所有人都很怕他。

✅ 正确：
林风走进来，没看任何人。
他找了个角落坐下。
有人想跟他打招呼，手刚抬起来，又放下了。
主位上的人看了他一眼，眉头皱了皱。
然后移开了视线。
```

---

### 法则10：节奏的秘密是"动-停-动-停"

**核心**：动作之后要停顿，给读者消化时间；情绪爆发前要压抑。

**节奏模板**：
```
快 → 停 → 快 → 停 → 爆发

示例：
林风冲上去。（快）
剑光一闪。（快）
对方倒退三步。（快）
血从对方的肩膀渗出来。（停）
林风没动。（停）
对方捂着伤口，脸上的表情从愤怒变成震惊，再变成恐惧。
"你..."
林风的剑已经架在他脖子上了。（爆发）
```

## 正文问题急救手册

### 急救1："太干" → 加感官细节

**症状**：读起来像说明书，干巴巴的

**急救方法**：加五感描写

```
原句：
林风走进房间，看到一张桌子。

加感官后：
林风推开门。
门轴发出一声刺耳的吱呀。
房间里很暗，窗户被封死了。
只有一缕阳光从门缝里挤进来，照在地板上。
空气中有一股霉味，混着...血腥？
他的目光落在桌子上。
桌上放着一把刀。
刀刃上还有没干的血。
```

### 急救2："太水" → 砍废话，直奔冲突

**症状**：啰嗦了半天没进入正题

**急救方法**：找到核心冲突，直接跳到那里

```
原句：
林风今天早上起床有点晚，刷牙用了五分钟，洗脸用了三分钟，
穿衣服选了一件黑色的...他出门了。路上堵车，他很着急。
到了地方，他发现...

急救后：
林风迟到了。
他冲进公司大门的时候，前台的小张用一种同情的眼神看着他。
"林哥，老板发了好大的火。"
林风深吸一口气。
该来的总会来。
他推开办公室的门。
```

### 急救3："太AI" → 朱雀去痕清单

**症状**：读起来像机器人写的

| 问题类型 | 检测项 | 修正方法 |
|---------|-------|---------|
| 机械比喻 | "仿佛/如同/似乎/像极了" ≥3处 | 改成具体动作描写 |
| 假感慨 | "令人惊叹/令人惋惜/令人感动" | 直接写发生了什么事 |
| 机械转折 | "不是A——而是B" | 换成自然转折 |
| AI腔 | "弹幕飘过/开始变密/气氛凝重" | 删掉，用真实反应代替 |
| 堆感叹号 | 连续感叹号 >2处 | 只留一个，其他改句号 |
| 流水情绪 | "他很紧张/他很愤怒/他很悲伤" | 改成动作+反应 |

### 急救4："节奏乱" → 节奏自检5问

```
1. 这章开头有没有钩子？
2. 这章中间有没有至少一个小爽点/冲突？
3. 这章情绪有没有起伏变化？
4. 这章结尾有没有留下悬念/期待？
5. 有没有超过500字的废话段？

如果任何一个问题回答"没有"，重点修改那一项。
```

### 急救5："对话假" → 对话改造3步

**改造步骤**：
```
步骤1：先写动作，再写说话
  ❌ "我不想去。"林风说。
  ✅ 林风摇头。"不去。"

步骤2：加停顿、加省略
  ❌ "我真的很喜欢你，你能不能和我在一起？"
  ✅ "我..."
  ✅ "我喜..."
  ✅ "我喜欢你。"

步骤3：加潜台词
  表面："你自己小心。"
  实际：他担心她，但他不会说出来

  表面："随便你。"
  实际：他很在意，但他装作不在乎
```

### 急救6："心理失衡" → 心理与行动的转换

**症状A：心理太多**
```
改造方法：把心理变成动作或对话

原句：
林风心里很纠结。他不知道该不该告诉她真相...

改造后：
林风张了张嘴，又闭上。
他看了苏晴一眼。又移开。
"林风？"苏晴问，"你想说什么？"
"没什么。"
他转身走向窗边。
```

**症状B：心理太少**
```
改造方法：在关键转折点补内心独白

示例：
林风看着那把刀。刀刃上还有血。
他可以选择杀了对方，一了百了。
但他是修士，不是杀手。
杀人之后，他就不再是原来的他了。
他慢慢放下刀。
"你走吧。"
（内心在"选择"的时候出现，不是全程出现）
```

## 模板/示例

### 正文写作流程模板

```markdown
【写前准备】
□ 确定章节类型（打斗/情感/日常/悬疑/升级/副本）
□ 明确主角当前情绪（具体，不是"开心"）
□ 设计情绪曲线（从哪里开始，到哪里结束）
□ 标注核心爽点

【写中执行】
□ 法则1：先动作后心理
□ 法则2：对话推进剧情
□ 法则3：每段有存在的理由
□ 法则4：每500字检查情绪锚点
□ 法则5：打斗用名场面定格
□ 法则6：情绪最高级用留白
□ 法则7：场景转换先合再开
□ 法则8：对话像人话
□ 法则9：写做什么胜于写是什么
□ 法则10：动停动停节奏

【写后自检】
□ 朱雀去痕扫描（机械比喻≤2处等）
□ 节奏自检5问
□ 镜头检查（至少2次有意识镜头调度）
□ 人设检查（对话符合人物性格？）
□ 逻辑检查（战力合理？时间线无矛盾？）
```

## 适用边界

**适用场景**：
- 所有正文写作（包括打斗/情感/日常/悬疑/升级/副本）
- AI生成文本的修改和去痕
- 正文质量诊断和修改
- 写作新手的法则训练

**不适用场景**：
- 大纲/细纲的撰写（细纲允许"告知"式写法）
- 设定文档（设定文档需要"解释"）
- 番外/楔子（可以采用不同的写作风格）

**重要边界**：
- 十法则是"底线"而非"上限"——满足法则不等于写好，但不满足一定写差
- 法则之间可能冲突——如"情绪留白"和"动停节奏"需要平衡
- 法则的执行需要灵活——日常场景可以放松，关键场景必须严格执行
- 急救手册是"症状导向"的——先诊断症状，再用对应方法
