# 情绪曲线设计

## 情绪曲线核心原则

情绪曲线必须是"波浪形"而非"直线"。单一的情绪无法持续吸引读者，必须在高潮和低谷之间不断切换。

---

## 情绪标注方法

### 情绪刻度
- **-5**：绝望/恐惧/崩溃
- **-4**：极度紧张/危险
- **-3**：紧张/不安
- **-2**：焦虑/担忧
- **-1**：轻微不安/疑惑
- **0**：平静/中性
- **+1**：轻松/好奇
- **+2**：愉悦/期待
- **+3**：兴奋/满足
- **+4**：狂喜/高潮
- **+5**：极致爽感/感动

### 标注规则
- 按500字分段
- 每段标注情绪值
- 必须在-3到+3之间波动
- 禁止连续两段同向情绪超过2个刻度

---

## 情绪曲线模板

### 模板1：紧张型
```
-2（疑惑）→ -3（紧张）→ -4（危机）→ -1（缓解）→ -3（新危机）→ +2（胜利）→ -1（新悬念）
```

### 模板2：情感型
```
0（平静）→ +2（温馨）→ -1（冲突）→ -3（痛苦）→ +3（和解）→ 0（平静）→ +1（新希望）
```

### 模板3：爽点型
```
-2（压抑）→ -3（困境）→ -4（绝境）→ +4（爆发）→ +3（爽感）→ +2（余韵）→ -1（新挑战）
```

---

## 情绪曲线设计步骤

### 步骤1：确定章节基调
- 本章是紧张章、情感章还是爽点章？

### 步骤2：设计情绪波动
- 从起点到终点，设计情绪变化轨迹
- 确保有至少3次明显的情绪波动

### 步骤3：标注关键节点
- 在500字处标注情绪值
- 确保符合标注规则

### 步骤4：检查合理性
- 情绪变化是否合理？
- 是否有足够的情绪起伏？

---

## 情绪曲线自检清单

- [ ] 情绪曲线是否波浪形？
- [ ] 是否有至少3次情绪波动？
- [ ] 情绪值是否在-3到+3之间？
- [ ] 是否有高潮和低谷？
- [ ] 情绪变化是否合理？
