# 限制性视角三不原则

## 核心原则

限制性视角是网络小说的默认视角。读者通过主角的眼睛看世界，主角不知道的，读者也不应该知道；主角没验证的，作者也不应该解释；读者能不能理解，取决于主角能不能理解。

**核心心法**：
- 限制性视角制造信息差，信息差制造悬念，悬念制造追读
- "读者比主角知道得多"是悬疑的核心快感来源
- 视角一旦失控，代入感瞬间崩塌

**三不原则**：
```
不描写主角不知道的
不解释主角没验证的
不预设读者能理解的
```

---

## 操作步骤/公式

### 一、三不原则详解

#### 原则一：不描写主角不知道的

**核心**：所有描写必须限制在主角的感官范围内。主角看不到的、听不到的、感觉不到的，一律不写。

**错误示例**：
```
❌ 陈默走进庙里，但他不知道，身后的柳三爷正用一种复杂的
   眼神看着他的背影，那眼神里有心疼，有愧疚，还有一丝
   不易察觉的决绝。
   （主角不可能知道柳三爷的眼神内容）
```

**正确示例**：
```
✅ 陈默走进庙里。
   身后传来柳三爷的脚步声，停了一下，又跟上来。
   "你确定？"柳三爷问。
   声音有点哑。
   陈默没回头。"确定。"
```

**例外情况**：如果需要展示配角视角，作为番外或特别章节少量释放，正文里继续保持主角视角的纯粹性。

#### 原则二：不解释主角没验证的

**核心**：不要用旁白解释"为什么"。主角没有通过行动验证的"原因"，不应该由作者直接告诉读者。

**错误示例**：
```
❌ 陈默之所以不怕，是因为他从小就被奶奶带着见识过这些
   东西，虽然他不承认，但他的身体已经形成了本能反应。
   （主角没验证过这个"原因"，是作者在解释）
```

**正确示例**：
```
✅ 陈默的手在抖。
   但他还是往前走了一步。
   他也不知道自己为什么不跑。
   可能是奶奶从小带他见的那些东西，在身体里留下了什么。
   也可能只是——腿软得转不了身。
```

#### 原则三：不预设读者能理解的

**核心**：不要假设读者"应该懂"。主角世界观里的常识，对读者可能是陌生的。需要通过主角的"学习过程"让读者理解。

**错误示例**：
```
❌ 陈默运转心神丹元，将灵力注入封印。
   （读者不知道"心神丹元"是什么，怎么"运转"）
```

**正确示例**：
```
✅ 陈默深吸一口气。
   心口那个一直跳的东西，跳得更厉害了。
   像是有什么要从胸口冲出来。
   他试着把那股劲儿往封印上引——
   手掌一热。
   封印上的符文亮了一下。
```

### 二、信息差制造悬念

**信息差三种类型**：

| 类型 | 定义 | 效果 | 示例 |
|------|------|------|------|
| **读者>主角** | 读者知道，主角不知道 | 悬疑感 | 读者看到遗像，主角还以为父亲活着 |
| **主角>读者** | 主角知道，读者不知道 | 伏笔感 | 主角对一个细节反应异常，读者不知道为什么 |
| **都不知道** | 主角和读者都不知道 | 探索感 | 主角进入未知场景，和读者一起探索 |

**信息差运用示例（《神秘复苏》杨间）**：
```
主角知道：父亲已死（被档案点醒）
主角记忆：父亲还活着（被鬼篡改）
读者知道：两种信息同时获得
悬念来源：主角何时发现真相？

技法核心：
1. 读者比主角知道得多：读者看到遗像，读者知道档案
2. 主角认知被操控：鬼修改了记忆
3. 读者焦虑感：替主角着急的阅读快感
```

### 三、感官边界严格遵守

**感官限制模型**：

```
主角能感受的 → 可以描写
主角不能感受的 → 不能描写
主角的限制条件 → 必须明确

示例（《恐怖复苏》浴缸闭气限制）：
主角能感受：水压、缺氧、心跳
主角不能做：睁眼（任务要求）、呼吸
限制条件：60秒内不能离开水面
读者感受：代入主角的无力感
```

**"听到/看到/感觉到"的精准描写**：

**技法要点**：
1. **真实性质疑**：用"或许/可能"保留合理性空间
2. **干扰意图**：鬼的"故意"=智慧的恐怖
3. **读者分心术**：让读者和主角同步焦虑

**示例**：
```
"水流划过耳廓，一片死寂中突然出现了奇怪的声音。
好像是从门外的走廊上传来的，陈歌也不知道他为何能听的
这么清楚，或许是对方故意弄出了声响，只为分散他的注意力。"
```

### 四、视角切换规则

**视角控制阶段策略**：

| 阶段 | 策略 | 说明 |
|------|------|------|
| 前期几万字 | 锁定主角 | 紧紧围绕主角展开，尽量少切甚至不切其他人的视角 |
| 后期字数长了 | 少量释放 | 可添加别的视角，但控制在几百字以内，不要大篇幅展开配角线 |

**视角切换技巧**：

```
【同场景切换】
从全景到特写：从环境到细节
从主角到配角：视角转移（但仍在主角可感知范围内）

【跨场景切换】
时间线切换：用时间词标注（第二天/三小时后）
空间切换：用动作过渡（门打开/光消失）

【心理切换】
内心独白：加"他想"/"他觉得"
闪回：用"——"或"回忆"标注
```

**番外视角处理**：
如果想加入配角的单独视角片段，可以作为番外或特别章节少量释放，正文里继续保持主角视角的纯粹性。

### 五、限制视角与全知视角的混用技巧

**混用原则**：限制为主，全知为辅，过渡要自然。

**混用场景**：

| 场景 | 视角选择 | 原因 |
|------|---------|------|
| 主角在场 | 限制视角 | 保持代入感 |
| 主角不在场的关键事件 | 全知视角（少量） | 传递主角无法获得的信息 |
| 群像场景 | 限制视角为主 | 通过主角眼睛看其他角色 |
| 反派密谋 | 全知视角（作为番外/楔子） | 制造"读者>主角"的信息差 |

**混用禁忌**：
- ❌ 同一段落内反复切换视角
- ❌ 全知视角大段展开配角心理
- ❌ 用全知视角"剧透"主角即将发现的事情

**混用过渡技巧**：
```
【限制→全知】
"陈默不知道的是，就在他走进庙里的同时，
三公里外的玄冥会总部，一个电话打了出去——"
（明确标注"主角不知道"，读者获得信息差快感）

【全知→限制】
"电话那头的人说了什么，陈默当然听不见。
他现在全部的注意力，都在脚下的那块地砖上。"
（用"主角的注意力"拉回限制视角）
```

## 模板/示例

### 限制性视角写作自检模板

```markdown
【场景】XXX

【主角能感知的】
- 视觉：[主角能看到什么]
- 听觉：[主角能听到什么]
- 触觉：[主角能感觉到什么]
- 嗅觉：[主角能闻到什么]
- 第六感：[主角的本能反应]

【主角不能感知的】
- [列出主角无法知道的信息]
- [这些信息如何通过其他方式传递给读者？]

【信息差设计】
- 读者知道而主角不知道的：[XXX]
- 主角知道而读者不知道的：[XXX]
- 都不知道的：[XXX]

【视角切换检查】
- 是否有视角切换？[是/否]
- 切换是否有明确过渡？[是/否]
- 切换后是否及时回到主角视角？[是/否]
```

### 信息差悬念设计示例

```markdown
【设计目标】让读者比主角多知道一层信息

【第1章·读者获得信息】
主角的父亲来访，但读者通过细节（父亲的影子没有完全跟着动）
隐约感觉到"父亲"不对劲。

【第2-5章·主角毫无察觉】
主角和"父亲"正常互动，读者替主角着急。

【第6章·真相揭晓】
主角发现遗像，认知崩溃。
读者：终于发现了！
（信息差闭合，但新的信息差立刻建立：鬼获得了主角的脸）
```

## 自检清单

- [ ] 所有描写是否限制在主角的感官范围内？
- [ ] 是否避免了用旁白解释主角没验证的"原因"？
- [ ] 是否避免了预设读者"应该懂"？
- [ ] 主角世界观里的概念是否通过"学习过程"让读者理解？
- [ ] 信息差设计是否明确（读者>主角 / 主角>读者 / 都不知道）？
- [ ] 感官限制条件是否明确（主角能做什么、不能做什么）？
- [ ] "听到/看到/感觉到"的描写是否精准？
- [ ] 是否用"或许/可能"保留合理性空间？
- [ ] 视角切换是否有明确过渡？
- [ ] 配角视角是否作为番外少量释放，而非正文大段展开？
- [ ] 限制视角与全知视角混用时，是否明确标注"主角不知道"？
- [ ] 是否避免了同一段落内反复切换视角？

## 适用边界

**适用场景**：
- 网络小说的默认视角选择
- 悬疑/恐怖/灵异题材的悬念制造
- 任何需要强代入感的场景
- 读者反馈"代入感不足"时的诊断

**不适用场景**：
- 群像剧（需要多视角平衡）
- 历史题材（有时需要全知视角交代背景）
- 已明确采用全知视角的作品

**重要边界**：
- 限制视角不等于"只能写主角"——可以通过主角的观察呈现其他角色
- 全知视角不等于"可以随便剧透"——必须有明确的信息差设计
- 视角切换不等于"自由切换"——必须有过渡，且不能过于频繁
- 信息差不等于"故意误导读者"——读者获得的信息必须是真实的
