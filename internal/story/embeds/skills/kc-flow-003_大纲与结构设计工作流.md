# 大纲与结构设计工作流

> **核心定位：** 骨架决定能走多远。从一句话梗概到百万字完整大纲，六步标准化流程，确保故事不崩盘。
>
> **适用场景：** 新书大纲搭建、长篇作品分卷规划、中期崩盘后的大纲重构
>
> **预计耗时：** 极简版1天，标准版3-5天，深度版7天以上
>
> **核心原则：** 先有核心冲突，再有主线，再有分卷，最后才是细节。大纲是底线，不是枷锁。

## 第一阶段：核心冲突设计（找发动机）

### 目标
用一句话说清楚：这个故事最根本的冲突是什么？

### 执行步骤

**步骤1：冲突类型判断**
- 你的故事核心冲突属于哪种类型？
  - **人与自我**：内心挣扎、成长蜕变、自我超越
  - **人与人**：爱情、友情、亲情、敌对、竞争
  - **人与社会**：制度、阶层、规则、文化、偏见
  - **人与自然/命运**：灾难、命运、未知、不可抗力
- 大多数故事是多种冲突的混合，但要有一个核心

**步骤2：核心冲突提炼**
- 用"XX vs XX"的格式写出核心冲突
- 比如：
  - 小人物 vs 命运
  - 正义 vs 邪恶
  - 自由 vs 秩序
  - 个人 vs 体制
  - 理性 vs 感性
- 核心冲突要够根本，能支撑长篇

**步骤3：冲突层级设计**
- 核心冲突往下拆，分成几个层级：
  - **核心层**：最根本的冲突（1个）
  - **主线条**：主线剧情的冲突（1-2个）
  - **分卷层**：每一卷的核心冲突（每卷1个）
  - **章节层**：每个章节的小冲突（每章1-3个）
- 冲突要层层递进，小冲突积累成大冲突

**步骤4：冲突升级路径**
- 冲突怎么一步步升级？
  - 从个人恩怨 → 到势力对抗 → 到世界存亡？
  - 从一个小目标 → 到更大的目标 → 到终极目标？
  - 从表面冲突 → 到深层矛盾 → 到核心对立？
- 升级的关键节点有哪些？
- 每次升级，给主角带来什么新的挑战？

### 本阶段产出物
- [ ] 核心冲突陈述（XX vs XX）
- [ ] 冲突类型判断
- [ ] 冲突层级图（核心→主线→分卷→章节）
- [ ] 冲突升级路径图

### 验收标准
- [ ] 核心冲突够根本吗？（能支撑长篇，不是小打小闹）
- [ ] 冲突有层次感吗？（不是一团乱麻）
- [ ] 升级路径清晰吗？（知道怎么一步步升级）
- [ ] 你自己对这个冲突感兴趣吗？

## 第二阶段：主线搭建（画大脉络）

### 目标
从开头到结尾，主线怎么走？有哪些关键节点？

### 执行步骤

**步骤1：三幕式大结构**
- 用三幕式搭大框架：
  - **第一幕（开端）**：20-25%篇幅
    - 介绍世界观、人物
    -  inciting incident（触发事件）
    -  第一幕结尾：主角做出选择，踏上旅程
  - **第二幕（发展）**：50-60%篇幅
    -  midpoint（中点）：重大转折
    -  第二幕上半：上升期，主角越来越强
    -  第二幕下半：下降期，遇到重大挫折
    -  第二幕结尾：最低谷，一切似乎都完了
  - **第三幕（结局）**：20-25%篇幅
    -  最终决战/终极挑战
    -  高潮
    -  结局：主角获得什么？失去什么？成长了什么？

**步骤2：关键节点标记**
- 在三幕式结构上，标记出关键节点：
  - 开头：主角初始状态
  - 触发事件：打破平衡的事件
  - 第一转折点：主角踏上旅程
  - 第一个小高潮
  - 中点：重大转折
  - 第二个小高潮
  - 最低谷：一切似乎都完了
  - 最终决战
  - 高潮
  - 结局
- 每个节点用一两句话描述

**步骤3：主线一句话**
- 用一句话说清楚主线：
  - "主角从____（起点）出发，为了____（目标），经历了____（主要困难/转折），最终____（结局）。"
- 检验：听完这句话，知道故事大概讲什么吗？

**步骤4：主题思考**
- 这个故事，你想表达什么主题？
  - 比如：成长、友情、正义、自由、命运、人性...
- 主题和核心冲突是什么关系？
- 主题怎么通过剧情体现出来？
- 主题不用明说，但要贯穿始终

### 本阶段产出物
- [ ] 三幕式结构框架
- [ ] 10个关键节点描述
- [ ] 主线一句话梗概
- [ ] 主题思考

### 验收标准
- [ ] 主线清晰吗？（知道从哪来到哪去）
- [ ] 有起承转合吗？（不是一条直线）
- [ ] 关键节点有冲击力吗？（能让人记住）
- [ ] 主题和剧情呼应吗？（不是两张皮）

## 第三阶段：分卷规划（切小块）

### 目标
把百万字长篇切成若干卷，每卷有独立的核心冲突和高潮，合起来又是完整的大故事。

### 执行步骤

**步骤1：确定卷数**
- 你打算写多少字？
- 每卷大概多少字？（建议15-30万字/卷）
- 大概分多少卷？（建议5-10卷，太多太少都不好）
- 比如：200万字，每卷20万，共10卷

**步骤2：每卷核心冲突**
- 给每一卷设定一个核心冲突
- 每卷的冲突是总冲突的一部分
- 卷与卷之间，冲突要升级
- 比如：
  - 第1卷：新手村冲突（小）
  - 第2卷：城市级冲突（中）
  - 第3卷：国家级冲突（大）
  - 第4卷：世界级冲突（更大）
  - ...

**步骤3：每卷核心事件**
- 每卷有哪些主要事件？
- 每卷的开头、发展、高潮、结尾是什么？
- 每卷结尾留什么钩子，吸引读者看下一卷？
- 每卷大概列5-10个关键事件

**步骤4：每卷人物成长**
- 每一卷，主角成长了什么？
- 能力提升？性格变化？认知升级？
- 主角在每卷结尾的状态，和开头有什么不同？
- 人物成长要和剧情推进同步

**步骤5：爽点分布**
- 每卷安排多少个爽点？
- 大爽点（卷末高潮）：1个
- 中爽点（卷中高潮）：2-3个
- 小爽点（章节爽点）：每章1-2个
- 爽点密度要合理，不能太密也不能太疏

### 本阶段产出物
- [ ] 分卷规划表（卷数、每卷字数、核心冲突）
- [ ] 每卷关键事件（5-10个/卷）
- [ ] 每卷人物成长点
- [ ] 爽点分布规划

### 验收标准
- [ ] 每卷有独立的核心冲突吗？
- [ ] 卷与卷之间冲突在升级吗？
- [ ] 每卷结尾有钩子吗？（让人想看下一卷）
- [ ] 人物在每卷都有成长吗？
- [ ] 爽点分布合理吗？

## 第四阶段：人物弧光设计（人物与剧情同步）

### 目标
确保人物在故事中成长变化，而不是一成不变的工具人。

### 执行步骤

**步骤1：主角弧光**
- 主角的起点是什么样的？
- 主角的终点是什么样的？
- 主角发生了什么变化？
  - 性格变化？
  - 能力变化？
  - 认知变化？
  - 价值观变化？
- 变化的原因是什么？（哪些事件导致了变化）
- 用弧线画出来：起点 → 上升 → 转折 → 下降 → 低谷 → 反弹 → 终点

**步骤2：关键转折点**
- 主角的人生有哪些关键转折点？
- 每个转折点发生了什么？
- 转折点之后，主角有什么变化？
- 转折点要和主线的关键节点对应
- 建议：3-5个主要转折点

**步骤3：反派弧光**
- 反派有弧光吗？（不是所有反派都要有，但有会更立体）
- 反派的起点是什么样的？
- 反派为什么变成现在这样？
- 反派的终点是什么样的？
- 反派和主角有什么对照关系？

**步骤4：配角弧光**
- 主要配角有成长吗？
- 哪些配角有比较完整的弧光？（2-3个就够了）
- 配角的成长和主线是什么关系？
- 配角不要抢主角的戏，但也要有自己的成长

**步骤5：人物-剧情对应**
- 人物成长和剧情推进是同步的吗？
- 剧情事件导致人物变化，人物变化推动剧情发展
- 不是剧情在走，人物没变；也不是人物在变，剧情没跟上
- 检查每个关键节点，人物状态和剧情是不是匹配

### 本阶段产出物
- [ ] 主角弧光图（起点→终点，关键转折点）
- [ ] 3-5个关键转折点描述
- [ ] 反派弧光（如适用）
- [ ] 主要配角弧光（2-3个）
- [ ] 人物-剧情对应检查表

### 验收标准
- [ ] 主角有明显的成长变化吗？
- [ ] 变化有原因吗？（不是突然变了）
- [ ] 人物成长和剧情同步吗？
- [ ] 反派/配角有立体感吗？（不是工具人）
- [ ] 你相信人物的变化吗？

## 第五阶段：伏笔系统设计（埋线与回收）

### 目标
系统化管理伏笔，确保该埋的埋了，该收的收了，不让伏笔烂尾。

### 执行步骤

**步骤1：长线伏笔（全书级）**
- 有哪些贯穿全书的长线伏笔？
  - 主角身世之谜？
  - 世界的终极秘密？
  - 反派的真实目的？
  - 某个神秘人物的身份？
- 这些伏笔什么时候埋？（一般在前期）
- 什么时候收？（一般在后期/结局）
- 长线伏笔不用多，3-5个就够了

**步骤2：中线伏笔（分卷级）**
- 每一卷有哪些中线伏笔？
- 这些伏笔在卷内埋，卷内收（或者跨1-2卷）
- 每卷大概2-3个中线伏笔
- 中线伏笔要为本卷的核心冲突服务

**步骤3：短线伏笔（章节级）**
- 每章有哪些小伏笔？
- 这些伏笔很快就会回收（几章内）
- 短线伏笔不用刻意规划，写的时候自然埋就行
- 但重要的短线伏笔，最好记一下

**步骤4：伏笔回收计划表**
- 把所有重要的伏笔录下来，做成表格：
  - 伏笔内容
  - 伏笔类型（长线/中线/短线）
  - 埋下位置（第几卷第几章）
  - 回收位置（计划第几卷第几章）
  - 回收方式
- 写完一卷更新一次，确保没有遗漏

**步骤5：伏笔质量检查**
- 伏笔够自然吗？（不是硬塞的）
- 伏笔有暗示吗？（不是突然冒出来的）
- 回收有惊喜吗？（读者：哦！原来如此！）
- 有没有埋了没收的？（烂尾伏笔）
- 有没有太明显的？（读者一眼就看穿了）

### 本阶段产出物
- [ ] 长线伏笔清单（3-5个）
- [ ] 中线伏笔清单（每卷2-3个）
- [ ] 伏笔回收计划表
- [ ] 伏笔质量检查报告

### 验收标准
- [ ] 重要伏笔都记录在案了吗？
- [ ] 每个伏笔都有明确的回收计划吗？
- [ ] 伏笔够自然吗？不是硬塞的吧？
- [ ] 回收的时候会有惊喜感吗？
- [ ] 有没有烂尾伏笔的风险？

## 第六阶段：节奏编排（掌控情绪）

### 目标
让读者跟着你的节奏走，时而紧张，时而放松，时而热血，时而感动。

### 执行步骤

**步骤1：情绪曲线设计**
- 整本书的情绪曲线是什么样的？
  - 开头：好奇→期待
  - 发展：紧张→兴奋→小高潮→回落→再上升
  - 中点：重大转折，情绪翻转
  - 后半段：压抑→积累→爆发
  - 结尾：高潮→释放→回味
- 用曲线画出来，高低起伏，不要一条直线

**步骤2：爽点节奏**
- 爽点怎么分布？
  - 小爽点：每章1-2个（章内爽）
  - 中爽点：每3-5章一个（小高潮）
  - 大爽点：每卷1-2个（卷高潮）
  - 终极爽点：全书1个（最终高潮）
- 爽点之间要有间隔，一直爽就不爽了
- 爽点之前要有铺垫，压抑之后的爆发才够劲

**步骤3：张弛节奏**
- 紧张之后要有放松
- 高潮之后要有过渡
- 打打杀杀之后要有日常
- 热血沸腾之后要有感动
- 张弛有度，读者才不会累
- 比例建议：7分紧张+3分放松，或者8:2

**步骤4：记忆点设计**
- 整本书有哪些让人印象深刻的名场面？
- 每一卷至少要有1-2个记忆点
- 记忆点类型：
  - 燃场面（热血沸腾）
  - 泪场面（感动落泪）
  - 爽场面（大快人心）
  - 虐场面（揪心虐心）
  - 反转场面（意想不到）
- 参考KC-SKILL-029「记忆钉系统」

**步骤5：节奏检查**
- 整体节奏合理吗？
  - 开头会不会太慢？
  - 中间会不会水？
  - 结尾会不会太仓促？
- 有没有哪里节奏不对？
  - 一直快，读者累
  - 一直慢，读者跑
  - 该快的时候快，该慢的时候慢

### 本阶段产出物
- [ ] 全书情绪曲线图
- [ ] 爽点分布表（小/中/大/终极）
- [ ] 张弛节奏规划
- [ ] 记忆点清单（名场面设计）
- [ ] 节奏检查报告

### 验收标准
- [ ] 情绪曲线有起伏吗？（不是一条直线）
- [ ] 爽点分布合理吗？（疏密有致）
- [ ] 张弛有度吗？（不会一直紧或一直松）
- [ ] 有让人印象深刻的记忆点吗？
- [ ] 整体节奏舒服吗？（读者愿意追下去）

## 常见误区

### ❌ 误区1：大纲太细，失去灵活性
- 把每一章每一段都规划好了
- 结果：写的时候被框死了，没灵感了，写出来的东西僵硬
- 正解：大纲是底线，不是枷锁。大方向定好，细节留给灵感。建议规划到分卷级，章节级的可以边写边想。

### ❌ 误区2：大纲太粗，等于没有
- 只有一句话梗概，剩下的全靠临场发挥
- 结果：写着写着跑偏了，中期崩盘，烂尾太监
- 正解：核心冲突、主线、分卷、人物弧光，这几个必须有。太细不行，太粗也不行，刚刚好最重要。

### ❌ 误区3：只有剧情，没有人物
- 大纲全是事件，人物只是推动剧情的工具
- 结果：剧情很热闹，但人物没印象，读者没感情
- 正解：人物成长和剧情推进要同步。事件塑造人物，人物推动事件。

### ❌ 误区4：伏笔埋了不收
- 前期埋了一堆伏笔，后期忘了收，或者收不了
- 结果：读者骂烂尾，信任感崩塌
- 正解：重要伏笔一定要记录，要有回收计划。没把握收的，就别埋。

### ❌ 误区5：一直快节奏，没有喘息
- 全程高能，一直打一直爽
- 结果：读者审美疲劳，爽点也不爽了
- 正解：张弛有度，有快有慢。压抑之后的爆发才够劲，放松之后的紧张才够刺激。
