# 创作全流程工作流

> **核心定位：** 从0到1再到0的完整创作周期全景图。新手入门第一张卡，建立全局认知。
>
> **适用场景：** 开新书前建立全局视角、写作中途校准方向、完本后复盘总结
>
> **核心价值：** 避免走一步看一步、写到哪算哪的盲目写作；每个阶段有明确的交付物和准入准出标准

## 第一阶段：立项与定位（找赛道）

### 目标
用系统化方法确定：写什么题材、写给谁看、有没有市场、自己能不能写。

### 关键任务
1. **市场调研**：当前什么题材火？平台扶持什么？读者爱看什么？
2. **自我评估**：我擅长什么？我对什么题材有热情？我有什么独特资源？
3. **受众画像**：我的读者是谁？他们多大？在哪？爱看什么？为什么看？
4. **卖点提炼**：我的书和别人的有什么不一样？核心差异点是什么？
5. **可行性验证**：这个题材我能写多久？能写多少字？商业前景如何？
6. **立项决策**：go/no-go，做还是不做？

### 本阶段产出物
- [ ] 市场调研报告（3-5个对标作品）
- [ ] 受众画像说明书
- [ ] 核心卖点提炼（3个以内）
- [ ] 可行性评估报告
- [ ] 立项决策书（go/no-go）

### 准入准出标准
- **准入**：有一个初步的想法或灵感
- **准出**：明确题材、明确受众、明确卖点、明确可行性

---

## 第二阶段：世界观构建（搭舞台）

### 目标
从零构建一个自洽、有深度、有生命力的世界观，为故事提供坚实的舞台。

### 关键任务
1. **核心矛盾定义**：这个世界最根本的矛盾是什么？（找魂）
2. **规则体系搭建**：3-5条核心规则 + 力量体系 + 资源体系（搭骨架）
3. **社会结构设计**：阶层、势力、权力、上升通道（建社会）
4. **文化心理塑造**：价值观、信仰、习俗、审美（育文化）
5. **地理历史铺陈**：地图、气候、交通、历史（铺背景）
6. **自洽性检验**：七维验证 + 压力测试（查bug）
7. **故事化适配**：世界观为故事服务（做对接）

### 本阶段产出物
- [ ] 世界观设定大纲
- [ ] 核心规则清单
- [ ] 力量/资源体系图
- [ ] 社会结构与势力图
- [ ] 历史年表与地图
- [ ] 自洽性检验报告

### 准入准出标准
- **准入**：题材和核心概念已确定
- **准出**：世界观自洽、有深度、能支撑故事、通过自洽检验

---

## 第三阶段：人物塑造（立角色）

### 目标
设计从主角到龙套的完整人物体系，确保人物有血有肉、行为自洽、成长可信。

### 关键任务
1. **主角设计**：身份、性格、目标、动机、缺陷、金手指、成长弧光
2. **配角配置**：功能型配角、成长型配角、工具人配角的分层设计
3. **反派塑造**：反派类型学、动机深度、魅力公式、反派弧光
4. **关系网络**：人物关系图、化学反应设计、冲突与羁绊
5. **成长弧光**：每个人物的起点、转折点、终点，人物如何变化

### 本阶段产出物
- [ ] 主角人物卡（详细版）
- [ ] 主要配角人物卡（3-5个）
- [ ] 核心反派人物卡（1-2个）
- [ ] 人物关系图
- [ ] 人物成长弧光设计

### 准入准出标准
- **准入**：世界观框架已搭好
- **准出**：主要人物立住、关系网络清晰、成长弧光完整

---

## 第四阶段：大纲设计（搭骨架）

### 目标
从一句话梗概到百万字完整大纲，确保故事有起承转合、有高潮收尾、不崩盘。

### 关键任务
1. **核心冲突设计**：主线冲突是什么？怎么产生？怎么升级？怎么解决？
2. **主线搭建**：从开头到结尾，主线怎么走？关键节点有哪些？
3. **分卷规划**：每一卷的核心冲突、核心事件、核心成长是什么？
4. **人物弧光**：人物在故事中如何变化？关键转折点在哪里？
5. **伏笔系统**：有哪些长线伏笔？什么时候埋？什么时候收？
6. **节奏编排**：爽点密度、情绪曲线、张弛节奏怎么安排？
7. **多系统协同**：人物、情节、世界观、情感、节奏、主题六大系统协同

### 本阶段产出物
- [ ] 一句话故事梗概
- [ ] 主线大纲（300-500字）
- [ ] 分卷大纲（每卷500-1000字）
- [ ] 情绪曲线图
- [ ] 伏笔回收计划表
- [ ] 节奏编排表

### 准入准出标准
- **准入**：世界观和主要人物已确定
- **准出**：大纲完整、逻辑自洽、能支撑百万字、节奏合理

---

## 第五阶段：开篇写作（过生死线）

### 目标
写出能抓住读者、抓住编辑的前三章，确保签约成功。

### 关键任务
1. **开篇钩子设计**：第一章用什么钩子抓住读者？
2. **黄金三章布局**：三章分别承担什么功能？怎么层层递进？
3. **人设快速建立**：前三章怎么让读者记住主角？
4. **世界观渗透**：怎么自然地介绍世界观而不尬？
5. **冲突快速展开**：核心冲突怎么快速抛出来？
6. **去AI味精修**：去除AI味，注入人味和灵魂
7. **签约自查**：对照签约标准，检查是否达标

### 本阶段产出物
- [ ] 前三章定稿
- [ ] 投稿版本（含简介、标签）
- [ ] 签约自查报告

### 准入准出标准
- **准入**：大纲和人物已确定
- **准出**：前三章达到签约水平、通过七维质检

---

## 第六阶段：连载运营（持久战）

### 目标
稳定更新、维持数据、逐步提升，从签约到上架到精品。

### 关键任务
1. **日常更新**：按照SOP稳定产出，确保更新频率和质量
2. **节奏把控**：张弛有度，爽点密度合理，情绪起伏有致
3. **数据监控**：每天看数据，了解读者反应
4. **每周复盘**：每周数据诊断，找出问题，调整策略
5. **读者互动**：评论区互动，收集反馈，建立读者粘性
6. **运营推广**：推荐期配合、活动参与、引流增粉
7. **中期调整**：根据数据反馈，微调剧情走向和节奏

### 本阶段产出物
- [ ] 每日更新内容
- [ ] 每周数据复盘报告
- [ ] 中期调整方案（如需要）

### 准入准出标准
- **准入**：签约成功，准备上架
- **准出**：完本，或阶段性目标达成

---

## 第七阶段：完本复盘（收尾与升华）

### 目标
圆满收尾、不留遗憾、总结经验、为下一本书铺垫。

### 关键任务
1. **收尾收线**：所有主线副线收束，伏笔全部回收
2. **完本精修**：全文通读修改，提升整体品质
3. **数据复盘**：全书数据回顾，哪些做得好，哪些做得不好
4. **经验总结**：写作技法、节奏把控、读者心理等各方面的经验教训
5. **完本运营**：完本感言、完本推荐、下本书引流
6. **下本规划**：下本书写什么？怎么改进？什么时候开？

### 本阶段产出物
- [ ] 完本终稿
- [ ] 完本感言
- [ ] 全书复盘报告
- [ ] 下本书规划

### 准入准出标准
- **准入**：主线剧情接近尾声
- **准出**：完本、复盘完成、下本规划确定

## 阶段间的关系

### 不是线性的，是循环迭代的
```
立项 → 世界观 → 人物 → 大纲 → 开篇 → 连载 → 完本
 ↑        ↓        ↓       ↓
 └────────┴────────┴───────┘ （反复调整、迭代优化）
```

**真实的写作过程不是一条直线，而是循环往复、不断调整的：**
- 设计人物的时候，可能发现世界观有bug，要回去改世界观
- 写大纲的时候，可能发现人物动机不够强，要回去改人物
- 写开篇的时候，可能发现大纲有问题，要回去改大纲
- 连载的时候，根据数据反馈，可能要微调大纲

**所以：**
- 前期准备越充分，后期调整越少
- 但也不要追求完美，先动起来，再迭代优化
- 关键是每个阶段有每个阶段的核心产出，产出了才能进入下一阶段

## 不同题材的阶段侧重

| 题材类型 | 侧重阶段 | 原因 |
|:---------|:---------|:-----|
| **玄幻/仙侠/奇幻** | 世界观构建 + 力量体系 | 强设定题材，世界观是核心卖点 |
| **都市/现实** | 人物塑造 + 情感线 | 贴近生活，人物和情感是核心 |
| **悬疑/推理** | 大纲设计 + 伏笔系统 | 逻辑严密，伏笔回收是关键 |
| **科幻** | 世界观构建 + 核心设定 | 科幻内核是灵魂 |
| **言情/情感** | 人物塑造 + 情感线设计 | 情感是第一生产力 |
| **历史/军事** | 世界观构建 + 历史细节 | 还原感和真实感很重要 |

## 常见误区

### ❌ 误区1：跳过准备直接写
- 觉得"想那么多没用，直接写就完了"
- 结果：写了几万字写不下去，崩盘重来，浪费时间
- 正解：前期准备是磨刀不误砍柴工，准备越充分，后期越顺

### ❌ 误区2：追求完美准备
- 觉得"等我把所有设定都想完美了再动笔"
- 结果：永远在准备，永远不动笔，准备了半年一个字没写
- 正解：完成比完美重要，先有80分，再在写作中迭代到90分

### ❌ 误区3：写到哪算哪
- 觉得"写作是艺术，要跟着感觉走"
- 结果：中期崩盘，主线跑偏，烂尾太监
- 正解：艺术也需要骨架，大纲是底线，不是枷锁

### ❌ 误区4：只看技能不看流程
- 收藏了一堆写作技巧，但不知道什么时候用、怎么配合
- 结果：单点能力很强，但整体效率低下，写出来的东西散
- 正解：用流程卡串联技能卡，形成体系

## 新手使用建议

### 第一遍：建立全局认知
- 把这张卡从头到尾读一遍
- 知道写作分几个阶段，每个阶段做什么
- 不用记住细节，有个大概印象就行

### 第二遍：对照自己的问题
- 你现在卡在哪个阶段？
- 这个阶段的核心任务是什么？
- 你完成了哪些？没完成哪些？

### 第三遍：制定行动计划
- 接下来一周，你要完成哪个阶段的哪些任务？
- 需要调用哪些卡片？
- 产出物是什么？怎么验收？
