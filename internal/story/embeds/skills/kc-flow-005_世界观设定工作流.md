# 世界观设定工作流

> **核心定位：** 世界自洽，读者才信。从表层到深层的五层世界观构建法，五步标准化流程。
>
> **适用场景：** 强设定题材的世界观搭建、长篇作品世界观深化、跨题材创作的世界观重构
>
> **预计耗时：** 极简版1天，标准版3-5天，深度版7天以上
>
> **核心原则：** 先有核心规则，再有社会文化，最后才是细节填充。设定为剧情服务，不为设定而设定。

---

## 第一阶段：核心规则设计（搭骨架）

### 目标
设计3-5条核心规则，以及完整的力量/资源体系。

### 执行步骤

**步骤1：核心规则设计（3-5条）**
- 这个世界最核心的规则是什么？
- 什么能做？什么不能做？
- 规则的边界在哪里？
- 核心规则要简洁，3-5条就够了，太多记不住
- 比如：
  - 灵气复苏，人人可修炼
  - 异能觉醒，但有代价
  - 修仙者长生，但有天劫
  - 科技高度发达，但AI有了自我意识

**步骤2：力量体系设计**
- 力量的来源是什么？
  - 灵气/异能/魔法/科技/血脉/信仰...
- 力量分多少个等级？
  - 每个等级叫什么名字？
  - 每个等级大概有多强？
  - 等级之间的差距有多大？
- 怎么升级？
  - 需要什么条件？（资源/悟性/机遇/心境...）
  - 升级难度递增吗？（越往上越难）
  - 升级有瓶颈吗？（哪些关卡最难过）
- 参考KC-SKILL-039「战力体系防崩三铁律」

**步骤3：资源体系设计**
- 这个世界最稀缺的资源是什么？
- 资源有哪些类型？
  - 修炼资源？（灵石、丹药、天材地宝...）
  - 生存资源？（食物、水、能源...）
  - 信息资源？（功法、机密、情报...）
  - 权力资源？（官职、地位、人脉...）
- 资源怎么获取？
  - 生产/交易/抢夺/探索/任务...
- 资源怎么分配？
  - 谁掌握资源？
  - 普通人能获得多少？
- 资源是稀缺的，不是随便就能获得的

**步骤4：代价与限制**
- 使用力量需要付出什么代价？
  - 体力消耗？精神消耗？寿命消耗？
  - 副作用？后遗症？
- 力量的上限在哪里？
  - 最强能有多强？
  - 有没有天花板？
- 有没有什么事是即使最强的人也做不到的？
- 代价和力量要成正比

**步骤5：与现实的差异点**
- 这个世界和现实世界最大的不同是什么？
- 这个差异点，会带来什么连锁反应？
  - 对社会的影响？
  - 对文化的影响？
  - 对普通人生活的影响？
- 把一个差异点想深想透，比十个浅尝辄止的设定强

### 本阶段产出物
- [ ] 核心规则清单（3-5条）
- [ ] 力量体系等级表
- [ ] 资源类型与获取方式表
- [ ] 代价与限制设计
- [ ] 核心差异点及其连锁反应

### 验收标准
- [ ] 核心规则够简洁吗？（3-5条，能记住）
- [ ] 规则边界清晰吗？（什么能做什么不能做）
- [ ] 力量体系有天花板吗？（最高级别有多强）
- [ ] 代价和力量成正比吗？
- [ ] 资源是稀缺的吗？（不是随便就能获得）

## 第二阶段：势力格局设计（建社会）

### 目标
搞清楚：这个世界的人是怎么组织起来的？谁在顶端？谁在底层？怎么往上爬？

### 执行步骤

**步骤1：阶层划分**
- 社会分几个阶层？
  - 顶层/上层/中层/底层...
- 每个阶层大概占多少比例？
  - 二八定律？一九定律？
- 每个阶层的生活状态是怎样的？
  - 住在哪？吃什么？做什么工作？
- 阶层之间流动的可能性大吗？
  - 上升通道是什么？
  - 难度有多大？

**步骤2：主要势力**
- 世界上有哪些主要势力？
  - 宗门/国家/公司/组织/家族...
- 每个势力的基本信息：
  - 名字？
  - 规模多大？
  - 核心利益是什么？
  - 领导人是谁？
  - 有什么特色/专长？
- 势力之间是什么关系？
  - 敌对？合作？竞争？中立？
- 势力分布图大概是什么样的？

**步骤3：权力来源**
- 顶层靠什么维持统治？
  - 力量？财富？血统？信仰？制度？
- 底层为什么不造反？
  - 打不过？有饭吃？被洗脑？没组织？
- 权力交接是怎么进行的？
  - 世袭？选举？比武？禅让？
- 有没有制衡机制？
  - 谁来监督统治者？
  - 权力有没有制约？

**步骤4：上升通道**
- 普通人有哪些途径改变命运？
  - 修炼？科举？经商？从军？联姻？
- 最主要的上升通道是什么？
- 难度有多大？（万分之一？百分之一？）
- 有没有"玻璃天花板"？
  - 某个阶层就到顶了？
  - 出身决定了上限？

**步骤5：职业体系**
- 这个世界有哪些主要职业？
- 战斗职业有哪些？非战斗职业有哪些？
- 最赚钱的职业是什么？最受尊敬的呢？
- 不同职业之间的地位差距大吗？
- 职业体系和力量体系是什么关系？

### 本阶段产出物
- [ ] 社会阶层结构图
- [ ] 主要势力一览表（含核心利益、关系）
- [ ] 权力来源与运行机制说明
- [ ] 上升通道分析
- [ ] 职业体系概览

### 验收标准
- [ ] 社会结构符合权力集中定律吗？（二八定律）
- [ ] 权力来源合理吗？（不是"我就是能统治"）
- [ ] 上升通道清晰吗？难度合理吗？
- [ ] 势力之间有利益冲突吗？（为剧情做准备）
- [ ] 普通人的生活状态具体可感吗？

## 第三阶段：文化心理塑造（育文化）

### 目标
搞清楚：这个世界的人怎么想？信什么？为什么这么活？

### 执行步骤

**步骤1：核心价值观**
- 这个世界的人最看重什么？
  - 力量？财富？权力？道德？荣誉？自由？
- 什么是值得追求的？什么是被唾弃的？
- 不同阶层的价值观一样吗？
- 不同地区的价值观有差异吗？
- 价值观和世界观的核心规则是什么关系？

**步骤2：信仰体系**
- 有宗教吗？有多少种？
- 主流信仰是什么？
- 信仰和权力是什么关系？
  - 政教合一？互相利用？政教分离？
- 有没有禁忌？
  - 触犯禁忌会怎么样？
  - 禁忌的根源是什么？

**步骤3：习俗传统**
- 有什么重要的节日？
  - 节日是怎么来的？
  - 节日里人们做什么？
- 婚丧嫁娶有什么讲究？
- 有没有什么独特的风俗习惯？
- 这些习俗背后的原因是什么？
  - 不是凭空来的，有历史/地理/社会原因

**步骤4：审美偏好**
- 这个世界的人觉得什么是美？
- 流行的服饰风格是什么？
- 建筑风格是什么样的？
- 艺术形式有哪些？（音乐、绘画、文学...）
- 审美和文化、地理、历史有关系吗？

**步骤5：文化差异**
- 不同地区/民族的文化有什么不同？
- 不同势力的文化有什么特色？
- 文化差异会导致冲突吗？
- 有没有文化融合的地方？
- 文化冲突可以成为剧情的推动力

### 本阶段产出物
- [ ] 核心价值观说明
- [ ] 信仰体系概览
- [ ] 重要习俗与节日清单
- [ ] 审美偏好与风格指南
- [ ] 地域文化差异说明

### 验收标准
- [ ] 文化有根源吗？（不是凭空冒出来的）
- [ ] 文化和地理、历史、规则对应吗？
- [ ] 文化会影响人物的选择吗？
- [ ] 有文化冲突吗？（为剧情做准备）
- [ ] 有仪式感和符号感吗？（容易记住）

## 第四阶段：地理历史铺陈（铺背景）

### 目标
搞清楚：世界长什么样？是怎么变成今天这样的？

### 执行步骤

**步骤1：地图设计**
- 世界有多大？
  - 一个大陆？一个星球？一个宇宙？
- 主要地形地貌有哪些？
  - 山脉、平原、海洋、森林、沙漠、沼泽...
- 重要地点在哪里？
  - 都城、宗门、秘境、战场、商路枢纽...
- 画一张简单的地图（不需要好看，位置对就行）
- 地图不需要太精确，但大致方位要对

**步骤2：气候与物产**
- 不同地区的气候怎么样？
  - 热带？温带？寒带？
  - 多雨？干燥？
- 各地的特产是什么？
  - 矿物、植物、动物...
- 物产如何影响当地的经济和文化？
- 有没有什么稀缺资源只在特定地方有？
  - 这可以成为冲突的导火索

**步骤3：交通与交流**
- 主要的交通方式是什么？
  - 走路、骑马、马车、飞舟、传送阵、网络...
- 从一个地方到另一个地方要多久？
  - 比如：从A城到B城要走几天？
- 主要的商路在哪里？
- 信息怎么传递？
  - 信使、飞鸽、传音、通讯玉简、互联网...
- 交通和信息传递的速度，决定了世界的"大小"

**步骤4：历史年表**
- 世界是怎么诞生的？（神话/真实）
- 历史上有哪些重要的时代/时期？
  - 每个时期叫什么名字？
  - 持续了多久？
- 每个时期的标志性事件是什么？
- 这些事件对现在有什么影响？
  - 哪些历史事件和主线剧情有关？
- 历史不用太复杂，但重要节点要有

**步骤5：历史真相与秘密**
- 官方记载的历史，是真的吗？
- 有什么被掩盖的历史真相？
- 谁在掩盖？为什么？
- 真相揭开之后会怎么样？
- 历史秘密可以成为重要的剧情钩子
- 参考KC-SKILL-021「世界观四维分层」

### 本阶段产出物
- [ ] 世界地图（简版即可）
- [ ] 重要地点一览表
- [ ] 交通方式与时间估算表
- [ ] 历史大事年表
- [ ] 历史真相/秘密清单

### 验收标准
- [ ] 地理环境和文化、经济对应吗？
- [ ] 距离和交通时间合理吗？（没有瞬移bug）
- [ ] 历史能解释现状吗？
- [ ] 有历史悬念吗？（读者想知道真相）
- [ ] 历史不会太复杂吧？（读者能记住）

## 第五阶段：自洽性验证（查bug）

### 目标
全面检查世界观，找出bug、漏洞、矛盾，修复它们。

### 执行步骤

**步骤1：七维自检**
- 对照KC-SKILL-047「世界设定自洽性检验体系」
- 七个维度一个一个检查：
  1. 规则一致性
  2. 逻辑闭环性
  3. 时间线一致性
  4. 空间地理合理性
  5. 人物行为合理性
  6. 社会文化自洽性
  7. 力量体系稳定性

**步骤2：压力测试**
- 把世界推到极限，看看会不会崩：
  - **极端情境测试**：如果最强的人全力出手会怎样？
  - **边界条件测试**：规则的边界在哪里？
  - **连锁反应测试**：改变一个设定，会引发什么？
  - **反向推理测试**：从现状能倒推回原因吗？
  - **平民视角测试**：普通人能活下去吗？

**步骤3：bug分级与修复**
- 把发现的问题分个级：
  - S级bug：核心规则矛盾，必须立刻改
  - A级bug：重要逻辑漏洞，尽快改
  - B级bug：次要设定矛盾，有空再改
  - C级bug：小细节错误，攒一波一起改
- 优先级：S > A > B > C
- 修复方法：打补丁？埋伏笔？将错就错？还是直接修改？

**步骤4：故事化适配检查**
- 世界观和故事是一体的吗？
- 设定都有用武之地吗？（不是摆设）
- 主角的困境和机遇，都是这个世界特有的吗？
- 主题通过世界观得到强化了吗？
- 设定足够精简吗？（读者能记住核心设定）
- 砍掉没用的设定，设定的价值在于"用"

### 本阶段产出物
- [ ] 七维自洽性检验表
- [ ] 压力测试记录
- [ ] bug清单（含分级）
- [ ] bug修复记录
- [ ] 精简后的世界观设定大纲

### 验收标准
- [ ] S级bug全部清零
- [ ] A级bug修复80%以上
- [ ] 核心规则没有矛盾
- [ ] 主要剧情线逻辑自洽
- [ ] 你自己相信这个世界吗？

## 不同题材的世界观侧重

| 题材类型 | 侧重方面 | 原因 |
|:---------|:---------|:-----|
| **玄幻/仙侠** | 力量体系 + 修炼资源 + 宗门势力 | 升级打怪是核心，力量体系是骨架 |
| **都市异能** | 能力规则 + 隐藏世界 + 现实影响 | 平衡日常和异能，逻辑自洽很重要 |
| **科幻** | 核心科幻设定 + 科技影响 + 社会变化 | 科幻内核是灵魂，要想深想透 |
| **历史/架空** | 历史背景 + 社会制度 + 文化习俗 | 还原感和真实感很重要 |
| **末世/求生** | 灾难设定 + 生存资源 + 人性考验 | 极端环境下的人和社会 |
| **灵异/诡异** | 规则体系 + 世界观秘密 + 恐怖氛围 | 规则怪谈的核心是规则本身 |

## 常见误区

### ❌ 误区1：设定癖，为设定而设定
- 沉迷于设定，写了一大堆，但剧情没推进多少
- 结果：设定集很丰富，但故事不好看
- 正解：设定为剧情服务，剧情需要什么再补什么。不要一开始就把所有设定都写完，写不完的，而且很多用不上。

### ❌ 误区2：设定太复杂，读者记不住
- 力量体系分几十级，势力有十几个，地图密密麻麻
- 结果：读者看晕了，弃书
- 正解：核心设定要简洁，3-5条核心规则，3-5个主要势力，读者能记住的才是有效的。

### ❌ 误区3：设定自相矛盾，bug满天飞
- 前面说A规则是这样的，后面又变成那样了
- 结果：读者出戏，信任感崩塌
- 正解：重要设定要记录下来，定期检查。发现bug及时修复，越早修复成本越低。

### ❌ 误区4：普通人不存在，世界只有主角和配角
- 整个世界好像就主角和几个配角在活动，其他人都是背景板
- 结果：世界假，没代入感
- 正解：花点时间想想普通人是怎么生活的。世界是由无数普通人组成的，普通人的生活状态真实了，世界才真实。

### ❌ 误区5：世界观和故事两张皮
- 世界观设定是一套，故事剧情是另一套，两者没什么关系
- 结果：设定再精彩也没用，和故事脱节
- 正解：世界观要为故事服务。主角的困境、机遇、成长，都应该和世界观紧密相关。换个世界观，这个故事就不成立了——这才是好的世界观。

## 最后一句话

**最好的世界观，是读者看完之后，会偷偷想——**

**"如果这个世界真的存在就好了。"**

所有的方法和技巧，都只是帮你达到这个状态的工具。

**不要本末倒置。设定是手段，故事才是目的。**

> 让读者相信这个世界，他们就会爱上这个故事。
