# 大纲搭建方法论

## 一、核心原则：大纲是底线，不是枷锁

> 没有大纲，写到哪算哪，大概率会崩。
> 大纲太细，被框死了，写出来的东西没灵气。
> 最好的大纲：大方向确定，细节灵活。

百万字长篇创作必须采用"五级漏斗架构"——从总纲到细纲逐层细化，每一级回答一个核心问题。大纲决定"写什么"，细纲决定"怎么写"；大纲崩了，细纲写得再细也救不回来。三幕结构 + 五关键节点是骨架，反向推导五步法是补丁工具。

**铁律**：禁止"过渡章"——每章必须有冲突或钩子。

**核心公式：**
```
好大纲 = 核心冲突清晰 × 主线脉络明确 × 人物弧光完整 × 节奏张弛有度
```

**大纲五层结构：**
1. 一句话梗概
2. 三百字简介
3. 分卷大纲
4. 章节细纲
5. 临场发挥

**五级漏斗架构：**
```
第一级：总纲（回答"写什么"）
├── 50字内说清全书核心脉络
├── 核心主题 + 一句话概括 + 结局走向
└── 交付：核心创意一句话

第二级：故事大纲（回答"怎么写"）
├── 起承转合线路图，标注核心转折点
├── 可拆分为5-10卷，每卷有独立高潮
└── 交付：大纲（1000字）

第三级：卷/部纲（回答"这一卷写什么"）
├── 每卷20-30万字，有独立小目标和收官高潮
├── 卷末必须有让读者"必须看下一卷"的钩子
└── 交付：卷纲（2000字/卷）

第四级：章纲（回答"这一章写什么"）
├── 每章3000-5000字，明确核心功能
├── 必须有冲突或钩子，禁止"过渡章"
└── 交付：章纲（300字/章）

第五级：节/细纲（回答"这一节写什么"）
├── 单章内拆分3-7节，每节标注场景/动作/对话/情绪
├── 每节不超过500字，确保节奏紧凑
└── 交付：细纲（1500字/章）
```

## 二、第一步：一句话梗概——最核心的那句话

### 核心本质
用一句话说清楚你的故事。
如果一句话说不清楚，说明你自己也没想明白。

### 一句话公式
```
在一个____（世界观）里，____（主角）要____（目标），但是____（困难/冲突），最终____（结局/主题）。
```

### 举例
- 玄幻："在一个修仙世界里，一个出身卑微的少年要逆天改命成为最强者，但是他被认为是废柴、被家族抛弃、被敌人追杀，最终他凭借坚韧和机遇，站在了世界之巅，也明白了力量的真正意义。"
- 都市："在现代都市里，一个普通的社畜意外获得了能看到别人寿命的能力，他想用这个能力救人，但是却发现了一个惊天阴谋，最终他揭开了真相，也找到了自己的人生价值。"
- 悬疑："在一个小镇上，一个侦探来调查一起密室杀人案，但是随着调查深入，他发现所有人都有嫌疑，而且案子和二十年前的一桩旧案有关，最终他找到了真凶，却发现真相比想象中更残酷。"

### 检验标准
- 够短吗？（一句话能说完）
- 够清楚吗？（听完知道讲什么）
- 够吸引人吗？（听完有点想看）
- 有冲突吗？（不是一帆风顺的）

## 三、第二步：三百字简介——把故事说清楚

### 核心本质
在一句话的基础上，扩展到三百字左右，把故事的起承转合说清楚。

### 简介结构
```
开头：世界观 + 主角 + 初始状态
   ↓
发展：触发事件 + 目标 + 遇到的困难
   ↓
高潮：最大的冲突 + 最终决战
   ↓
结局：结果如何 + 主题升华
```

### 写简介的注意事项
- **不要剧透太多**：保留悬念，别把所有转折都说了
- **突出卖点**：这本书最吸引人的点是什么？重点写
- **有层次感**：从开头到发展到高潮，层层递进
- **结尾留有余味**：不要写得太死，让读者有想象空间

### 简介的作用
- 给自己看：梳理思路，确保故事完整
- 给编辑看：投稿的时候用
- 给读者看：书的简介，决定读者点不点开

## 四、第三步：分卷大纲——把长篇切成小块

### 核心本质
百万字长篇，直接写到尾太难了。
分成若干卷，每卷一个小目标，一步一步来。

### 分卷原则

**1. 每卷一个核心冲突**
- 每一卷都有自己独立的核心冲突
- 每一卷都有开头、发展、高潮、结尾
- 每一卷结束，冲突暂时解决，但会引出新的冲突

**2. 卷与卷之间要升级**
- 冲突规模要升级：个人 → 城市 → 国家 → 世界
- 对手实力要升级：小喽啰 → 小BOSS → 中BOSS → 大BOSS
- 主角能力要升级：弱 → 中 → 强 → 最强
- 格局视野要升级：小家子气 → 胸怀天下

**3. 每卷留钩子**
- 每卷结尾都要留钩子，吸引读者看下一卷
- 比如：新的敌人出现、新的秘密揭开、新的危机降临
- 卷与卷之间要有衔接，不能断裂

### 分卷大纲的内容
每一卷大概写清楚：
- 本卷核心冲突是什么？
- 本卷主要讲什么事？
- 本卷有哪些关键事件？（5-10个）
- 本卷主角成长了什么？
- 本卷结局是什么？留下什么钩子？

### 分卷数量建议
- 短篇（20万以下）：3-5卷
- 中篇（20-50万）：5-8卷
- 长篇（50-200万）：8-15卷
- 超长篇（200万以上）：15卷以上

### 三幕结构五关键节点

| 幕 | 篇幅 | 功能 | 关键节点 | 节点位置 |
|----|------|------|----------|----------|
| 第一幕 | 约20% | 觉醒：日常被打破 | ① 日常被打破 | 第一章 |
| 第一幕 | 约20% | 觉醒：不可逆选择 | ② 不可逆选择 | 第一幕末 |
| 第二幕 | 约60% | 对抗：冲突升级 | ③ 中点转折 | 第二幕中段 |
| 第二幕 | 约60% | 对抗：最大失败 | ④ 最大失败 | 第二幕末 |
| 第三幕 | 约20% | 决战：最终对决 | ⑤ 最终决战 | 第三幕 |

**五关键节点设计要点**：
1. **日常被打破**：主角的日常在哪个瞬间开始不对劲？
2. **不可逆选择**：主角在哪个节点做出了"回不去"的选择？
3. **中点转折**：发生了什么，让主角从被动应对变成主动出击？
4. **最大失败**：主角在哪一刻最接近放弃？他失去了什么？
5. **最终决战**：主角用什么方式兑现了开篇的承诺？

### 卷纲模板

```markdown
第X卷：[卷名]（XX-XX万字）
【卷核心冲突】________________________
【主角阶段目标】________________________
【关键爽点节点】
  - 第1个：第X章 ________________
  - 第2个：第X章 ________________
  - 第3个：第X章 ________________
【伏笔埋设】
  - 埋：第X章 ________________
  - 回收：第X章 ________________
【卷末钩子】________________________
```

## 五、第四步：章节细纲——写到哪列到哪

### 核心本质
分卷大纲还是太粗，写之前把接下来几章的细纲列一下。
不用列太远，5-10章就行，边写边列。

### 章节细纲的内容
每一章写清楚：
- 本章核心事件是什么？（一句话）
- 本章出场人物有哪些？
- 本章有什么爽点/钩子/反转？
- 本章结尾留什么悬念？
- 本章大概多少字？

### 细纲的灵活度
- 细纲不用太细，知道大概要写什么就行
- 写的时候可以调整，不用完全按照细纲来
- 灵感来了，偏离细纲也没关系
- 但是大方向不能偏，分卷目标要达成

### 为什么要有细纲
- 防止卡文：知道接下来写什么，打开文档就能写
- 防止跑偏：有细纲照着，不容易写着写着就歪了
- 控制节奏：爽点、钩子、反转分布更合理
- 提高效率：减少思考时间，写得更快

### 章纲模板

```markdown
【章节】：第X章
【核心内容】：一句话说清楚这一章发生了什么
【冲突推进】：利益/情感/性格/价值观——哪种冲突？
【爽点设计】：小爽点/中爽点/大爽点
【章末钩子】：抛出问题/制造危机/点明转折
【字数】：约2000-3000字
```

### 细纲五要素模板

```markdown
【本章核心事件】
一句话说清楚这一章发生了什么

【情绪曲线】
从____情绪开始 → 中间经历____情绪转变 → 以____情绪结束

【核心冲突】
这一章主角在对抗谁/什么？（利益/情感/价值观？）

【信息变化】
这一章结束后，谁知道了什么之前不知道的事？

【结尾钩子】
读者读完这一章，最想立刻知道什么？
```

## 六、第五步：临场发挥——大纲是死的，人是活的

### 核心本质
大纲是工具，不是枷锁。
写的时候有灵感、有新想法，可以调整大纲。

### 什么时候可以改大纲

**1. 有更好的想法**
- 写着写着，想到了一个更棒的点子
- 比原来的设定更精彩、更有戏剧性
- 那就改！不要被原来的大纲绑死

**2. 原来的设定有bug**
- 写着写着发现原来的设定有问题
- 逻辑不通、人物OOC、剧情崩了
- 赶紧改！不要硬着头皮写下去

**3. 读者反馈强烈**
- 某个配角特别受欢迎，读者都想看TA的戏
- 某个剧情读者反应平平，甚至反感
- 可以适当调整，加戏或者减戏
- 但不要被读者牵着鼻子走，大方向要自己把握

### 改大纲的原则
- **大方向不动，小方向可调**：主线、核心冲突、人物弧光这些大的，尽量别动；细节、小剧情、配角戏份这些，可以灵活调整
- **改了之后要顺**：改了前面的，后面的也要跟着调，不能前后矛盾
- **想清楚再改**：不要脑子一热就改，改完又后悔。想清楚了再动手。

### 反向推导五步法

**适用场景**：已写完3-10章正文，需要从已有内容反向推导后续大纲

**第一步：建立"法律体系"**
- 将已写章节确立为"判例"，后续所有剧情必须遵守
- 示例：第3章设定"喊三声娘娘回魂触发封印"→后续所有副本必须遵守"三声触发"规则

**第二步：挖掘隐藏矿脉**
- 从无意识埋下的种子中推导支线
- 示例：第6章提及"老鬼徒弟的背叛"→可反向推导30-50章规模的"财阀内斗篇"

**第三步：建立创作GPS**
```
总纲 = 北极星（方向）——始终指向最终目标
大纲 = 高速公路地图（路径）——5-10卷的结构
卷纲 = 服务区（休整+高潮）——每卷的节奏安排
章纲 = 导航语音（"前方500米右转"）——精确到每章的任务
```

**第四步：确保商业钩子密度**
- 在架构阶段就规划每章结尾的钩子类型
- **铁律**：禁止连续两章没有钩子

**第五步：锚点校验三问**
1. 支线发生在主线时间轴的哪个精确位置？
2. 在这个时间点，人物能力/心理/道具是什么状态？
3. 哪些细节必须和主线100%咬合？

## 七、大纲里必须有的五样东西

### 1. 核心冲突
- 这个故事最根本的冲突是什么？
- 没有核心冲突，故事就没有灵魂
- 核心冲突要够根本、够宏大，能支撑长篇

### 2. 主线脉络
- 从开头到结尾，主线怎么走？
- 关键节点有哪些？
- 主线要清晰，不能跑偏

### 3. 人物弧光
- 主角从开头到结尾，有什么成长变化？
- 关键转折点是什么？
- 人物成长要和剧情同步

### 4. 节奏规划
- 爽点怎么分布？
- 高潮在哪里？
- 哪些地方要慢、哪些地方要快？
- 张弛有度，不能一直紧也不能一直松

### 5. 伏笔系统
- 有哪些长线伏笔？
- 什么时候埋？什么时候收？
- 重要伏笔要记下来，别埋了忘了收

## 八、不同题材的大纲侧重点

| 题材类型 | 核心要素 | 大纲重点 |
|:---------|:---------|:---------|
| **玄幻/仙侠** | 升级、打怪、换地图 | 升级路线、地图规划、战力体系 |
| **都市/职场** | 逆袭、装逼、打脸 | 装逼打脸的节奏、事业线推进 |
| **悬疑/推理** | 谜题、线索、反转 | 谜题设计、线索分布、反转节奏 |
| **末世/求生** | 生存、升级、打怪 | 生存难度、怪物设计、基地建设 |
| **言情/情感** | 情感发展、关系变化 | 情感线推进、关系变化节点 |
| **历史/架空** | 历史进程、势力争霸 | 历史大事、势力发展、战争节奏 |

## 九、常见误区

### ❌ 误区1：没有大纲，想到哪写到哪
- 觉得"写作要靠灵感"、"大纲会束缚创造力"
- 结果：写了几万字就写不下去了，主线跑偏，人物崩盘，烂尾太监
- 正解：大纲是底线，不是枷锁。大方向定好，细节可以灵活发挥。没有大纲的自由，是混乱的自由。

### ❌ 误区2：大纲太细，每一句都规划好
- 把每一章每一段都规划得清清楚楚
- 结果：写的时候像填空题，没有灵气，写出来的东西僵硬
- 正解：大纲有个七八分就够了，剩下的两三分留给灵感。太细的大纲，反而会扼杀创造力。

### ❌ 误区3：只有剧情，没有人物
- 大纲全是事件，人物只是推动剧情的工具
- 结果：剧情很热闹，但人物没印象，读者没感情
- 正解：人物成长和剧情推进要同步。事件塑造人物，人物推动事件。

### ❌ 误区4：只有主线，没有支线
- 从头到尾就是一条主线，干巴巴的
- 结果：故事太单薄，世界假，人物少
- 正解：适当加一些支线，丰富故事，丰满人物。但支线不能太多，不能抢了主线的戏。

### ❌ 误区5：大纲写完就不管了
- 写完大纲就扔一边，写的时候完全不看
- 结果：写着写着就跑偏了，和原来的大纲完全不一样
- 正解：大纲是参考，要经常拿出来对照。定期（比如每写完一卷）回头看看，调整优化。

## 十、快速自检清单

写完大纲后，对照检查：

- [ ] 有一句话梗概吗？（能一句话说清楚故事吗？）
- [ ] 核心冲突明确吗？（知道根本矛盾是什么吗？）
- [ ] 主线脉络清晰吗？（知道从开头到结尾怎么走吗？）
- [ ] 分卷合理吗？（每卷有独立冲突吗？卷与卷之间有升级吗？）
- [ ] 人物弧光完整吗？（主角有成长变化吗？）
- [ ] 节奏规划了吗？（爽点、高潮、张弛有度吗？）
- [ ] 有伏笔系统吗？（重要伏笔有记录吗？）
- [ ] 大方向确定吗？（知道故事要往哪走吗？）
- [ ] 有灵活度吗？（细节可以调整吗？）
- [ ] 你自己对这个故事有热情吗？（你自己想写吗？）

## 最后一句话

**大纲是建筑的设计图——设计图越好，房子越稳。**

但也别忘了：

**设计图画得再漂亮，也得一砖一瓦去盖。**

不要沉迷于写大纲而不动笔。
大纲有70分，就可以动笔了，剩下的30分，在写作中补全。

> 先完成，再完美。
