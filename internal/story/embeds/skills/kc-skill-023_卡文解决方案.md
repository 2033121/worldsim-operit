# 卡文解决方案

## 核心原则

1. **先诊断类型再对症下药**：卡文分三类（方向卡/情节卡/表达卡），症状不同，解决方法完全不同，禁止"一招通吃"。
2. **不要从卡住处硬想**：所有卡文的解决思路都是"后退一步"或"切换视角"，而非"原地死磕"。
3. **降级优先于完美**：卡文时优先保证"产出"，而非"质量"。先写骨架再润色，烂草稿胜过空白页。
4. **预防胜于治疗**：存稿缓冲+大纲预留是卡文的根本预防手段，临时解决只能救急。
5. **卡文是信号不是失败**：卡文往往意味着大纲有漏洞或人设有矛盾，是修正作品的机会。

## 操作步骤/公式

### 步骤1：诊断卡文类型

| 类型 | 症状 | 根因 | 解决方法 |
|------|------|------|----------|
| **方向卡**（剧情卡） | 盯着屏幕大脑空白，不知道写什么 | 大纲不清晰/剧情走到死胡同 | 回退三步法 |
| **情节卡**（执行卡） | 大纲清楚，但写不动，每个字像挤牙膏 | 细纲不够细/情绪曲线没设计好 | 降级写作法 |
| **表达卡**（质量卡） | 写完了，但读起来干巴巴的 | 场景/动作/对话缺乏细节 | 换视角重写法 |

### 步骤2：回退三步法（解决方向卡）

```
核心：不要从当前卡住的地方硬想，倒退三步。

第一步：回到最后流畅处
  · 上一个剧情节点是什么？
  · 主角从这个节点获得了什么新信息？

第二步：检查大纲
  · 当前章节的核心任务是什么？
  · 大纲是否有逻辑漏洞？
  · 是否走到了死胡同，需要绕路？

第三步：绕路
  · 如果正面写不通，换一条路径
  · 例：原本计划打斗卡住 → 改为对话推进剧情
  · 例：原本计划情感爆发卡住 → 改为日常铺垫
```

### 步骤3：降级写作法（解决情节卡）

```
核心：告诉自己"这一版只是草稿，烂一点没关系"。

操作：
1. 把目标从"写出好文字"降级为"把剧情骨架搭出来"
2. 用最直白的语言把这场戏的核心动作写出来
3. 对话只写内容不写修饰
4. 描写只标关键词
5. 写完草稿后再回头润色

骨架模板：
【场景】主角在______，遇到______
【动作】主角做了______，对方反应______
【对话】主角说"______"，对方说"______"
【结果】最终______
【钩子】章末留下______

降级原则：先把"发生了什么"写清楚，再补"怎么发生的"
```

### 步骤4：换视角重写法（解决表达卡）

```
核心：把同一场戏换成另一个人物的视角来写。

操作：
1. 当前是主角视角卡住 → 换成对手视角
2. 当前是旁观视角卡住 → 换成当事人视角
3. 当前是上帝视角卡住 → 换成第一人称视角

换视角的作用：
· 立刻发现"缺了什么"（信息差/情绪差/认知差）
· 从新视角看到原本忽略的细节
· 不一定要用在正文里，但这个练习会让你突破卡壳

示例：
原视角（主角）：主角走进庙里，感觉阴森
换视角（邪祟）：它感觉到生人的气息靠近，开始苏醒
→ 立刻有了"被注视"的紧张感，场景活了起来
```

### 步骤5：卡文预防体系

```
预防一：存稿缓冲
· 最少3章存稿（约6000-9000字）
· 老手建议10万字存稿
· 卡文时用存稿过渡，给自己思考时间

预防二：大纲预留
· 三级大纲法：一级大纲（故事核心）+ 二级大纲（分卷规划）+ 三级大纲（单章章纲）
· 每章写完前，先定好：本章核心内容/冲突如何推进/爽点在哪释放/结尾留什么钩子
· 大纲崩了，细纲写得再细也救不回来

预防三：四文件夹灵感库
· 待用情节池：一句话能说清楚的情节梗概（卡文时翻找）
· 对白语料库：按人物分类的台词，按情绪标注（写对话时调用）
· 场景素材库：按场景类型分类的关键词（写场景时调用）
· 设定补丁库：正文新增设定及关联词条（保持一致性）

预防四：维护节奏
· 每章写完：对白、场景、设定归档
· 每单元写完：筛选待用情节池，更新设定补丁
· 每卷写完：全库回溯，挑出下一卷能用的
```

## 模板/示例

### 模板1：卡文急救决策表

```
卡文了 → 先判断症状

症状A：不知道写什么
  → 方向卡 → 回退三步法
  → 检查大纲是否有漏洞
  → 必要时绕路（换章节类型/换推进路径）

症状B：知道写什么但写不动
  → 情节卡 → 降级写作法
  → 先写骨架再润色
  → 对话只写内容，描写只标关键词

症状C：写完了但读起来干巴巴
  → 表达卡 → 换视角重写法
  → 加五感描写（视觉/听觉/触觉/嗅觉/味觉）
  → 用动作展示心理，不要直接写心理
```

### 模板2：降级写作法骨架模板

```markdown
【本章场景】地点：______ 时间：______
【出场人物】主角 + ______
【核心动作】主角______ → 对方______ → 结果______
【关键对话】
  主角："______"
  对方："______"
  主角："______"
【章末钩子】______
【字数预估】______字

写完骨架后，逐段填充：
1. 场景描写（加五感）
2. 动作细节（加镜头调度）
3. 对话润色（加潜台词）
4. 情绪曲线（标注每段情绪值）
```

## 适用边界

- **适用**：所有网文连载作者，尤其是日更作者
- **强适用**：百万字长篇中期（30-100万字）卡文高发期
- **弱适用**：短篇创作（短篇卡文多因构思不足，需重新构思而非急救）
- **不适用**：开篇黄金三章（开篇卡文说明故事本身有问题，需重新设计）
- **慎用**：换视角重写法不一定能用在正文里，主要是练习和突破工具
