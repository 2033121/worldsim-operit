# 签约五核心指标

## 核心原则

编辑审稿看的不是"这本书有没有缺点"，而是"这本书有没有不可替代的优点"。签约的核心是五个指标全部达标：**类型辨识度 / 开篇留存率 / 人物记忆点 / 主线清晰度 / 可商业化**。任一否决项出现即不签。

**铁律**：不要追求"没有缺点"，要追求"有不可替代的优点"。

---

## 操作步骤/公式

### 五核心指标

#### 指标一：类型辨识度（能不能一眼看出这是什么书）

**判断标准**：用一句话能说清楚你的书是什么类型、核心卖点是什么吗？

**合格示例**：
```
《道源直播间》：探灵主播撞上真灵异，一边嘴硬说"相信科学"，
一边用道家真本事修封印。
```

**自检问题**：删掉书名和简介，读者读完第一章能说出"这是一本____类型的书"吗？

#### 指标二：开篇留存率（前三章能不能留住人）

**判断标准**：黄金三章是否完成四个动作——
1. 主角出场并让人记住
2. 日常被打破
3. 主角做出反应
4. 埋下钩子

**达标线**（番茄平台）：
- 前10章完读率 ≥ 8%
- 首秀7日追读率 ≥ 25%
- 10万字整体完读率 ≥ 15%（脑洞文）/ ≥ 10%（爽文）

#### 指标三：人物记忆点（有没有让读者记住的角色）

**判断标准**：删掉所有旁白描写，只保留主角的对话和行动，读者还能感受到主角的性格吗？

**记忆点公式**：`身份 + 反差特征`

| 人物 | 身份 | 反差 | 记忆点 |
|------|------|------|--------|
| 陈默 | 探灵主播 | 不信鬼神 | 手抖但嘴硬说"风化腐蚀" |
| 柳三爷 | 老仙家 | 嘴碎不端着 | 真危险时嘶吼护犊子 |

#### 指标四：主线清晰度（知不知道这本书要写什么）

**判断标准**：读者是否产生了"期待"——隐约知道接下来会发生什么，所以想看它怎么发生。

**自检问题**：读者读完前三章，能用一句话概括"主角要做什么"吗？

#### 指标五：可商业化程度（这本书能不能卖）

**三个参考维度**：
- 有明确的付费点设计吗？（视觉奇观/冲突高潮/悬念揭秘）
- 有系列化潜力吗？（一本完还是能写三本？）
- 有改编潜力吗？（短剧/动漫/有声）

**达标线**：至少满足两项

### 签约否决项（出现即不签）

| 否决项 | 说明 | 自检问题 |
|--------|------|----------|
| **开篇太慢** | 前三章主角还没进入核心冲突 | 第一章是否有冲突？第三章是否有钩子？ |
| **人物工具化** | 角色只是推动剧情的棋子，没有自己的欲望和恐惧 | 删掉该角色，剧情是否完全不受影响？如果是→工具化 |
| **信息过载** | 开篇大量堆砌设定，读者记不住也代入不了 | 前三章每千字新设定是否超过15条？ |

### 编辑审核四维度

| 维度 | 内容 | 自检要点 |
|------|------|----------|
| **阅读观感** | 错别字、语句流畅、排版清晰 | 是否有错别字？段落是否过长？ |
| **题材方面** | 市场热点、受众覆盖面、读者需求 | 是否符合当前市场热点？受众覆盖面广吗？ |
| **内容方面** | 创新点、出场人物、人物设定、事件安排 | 有什么创新点？人物设定是否立体？ |
| **技巧方面** | 叙事视角、节奏把控、文字功底 | 视角是否锁定主角？节奏是否压→缓→压→爆？ |

### 书名三大公式

#### 公式一：主体身份 + 核心噱头

```
格式：主体身份 + 核心噱头
示例：《直播：道长别装了，你就是在修仙》
解析：主体身份（直播道长）+ 核心噱头（其实在修仙）
```

#### 公式二：反常识组合

```
格式：两个看似矛盾的元素组合
示例：《家人们相信科学，但这鬼真不是我请的演员》
解析：相信科学 vs 真有鬼——制造矛盾冲突感
```

#### 公式三：结果前置

```
格式：直接把爽点或结果放在书名里
示例：《直播算命太准，被全网警察关注了》
解析：直接告诉读者"主角算命很准"这个爽点
```

### 书名四标准

| 标准 | 说明 | 检验问题 |
|------|------|----------|
| **辨识度** | 能和其他书区分开吗？ | "道源"有独特文化标签 |
| **期待感** | 读者看完想点进去吗？ | 读者能从书名里读到故事 |
| **记忆点** | 读者能记住你的书名吗？ | "老默"有人物感 |
| **延展性** | 能承载后续系列作品吗？ | 《老默探灵：XX》可成系列 |

## 自检清单

### 五核心指标自检
- [ ] **类型辨识度**：一句话能说清核心卖点吗？有独特标签吗？
- [ ] **开篇留存率**：黄金三章完成"主角出场+日常打破+反应+钩子"四个动作了吗？
- [ ] **人物记忆点**：删掉旁白只看对话行动，能感受主角性格吗？有"身份+反差"吗？
- [ ] **主线清晰度**：读者能用一句话概括"主角要做什么"吗？产生期待了吗？
- [ ] **可商业化**：付费点/系列化/改编潜力至少满足两项吗？

### 否决项自检
- [ ] 开篇是否太慢？（前三章主角是否已进入核心冲突？）
- [ ] 是否有人物工具化？（每个角色是否有自己的欲望和恐惧？）
- [ ] 是否信息过载？（前三章每千字新设定是否≤15条？）

### 书名自检
- [ ] 书名是否符合三大公式之一？
- [ ] 书名是否满足四标准（辨识度/期待感/记忆点/延展性）？
- [ ] 书名长度是否在4-9字（新人推荐）？
- [ ] 是否避开了书名雷区？（晦涩意象/三字以内无卖点/蹭爆款热度）

### 签约策略自检
- [ ] 是否选择了匹配题材的平台？
- [ ] 是否准备了至少10个书名备选？
- [ ] 是否预判了编辑审核四维度？
- [ ] 是否设计了明确的商业卖点？

## 适用边界

**适用场景**：
- 新书签约前自检（投递编辑前最后一道关卡）
- 平台选择决策（番茄/起点/纵横/晋江/七猫）
- 书名生成与筛选
- 已签约作品的"续约"评估

**不适用场景**：
- 已稳定连载的作品（签约已完成）
- 自出版/自媒体平台（无编辑审核环节）
- 文学奖项投稿（评审标准不同）

**特别注意**：
- 编辑审稿看"有没有不可替代的优点"，不是"有没有缺点"
- 不要盲目跟风，选择适合自己的赛道
- 不要频繁换笔名，积累的作品数据会被打断
- 不要完美主义，反复修改第一章（前三章合格即可推进）
- 追读数据是最客观的判断标准——追更没掉就是好作品

---

## 签约避坑提醒

```
✗ 不要盲目跟风，选择适合自己的赛道
✗ 不要频繁换笔名，积累的作品数据会被打断
✗ 不要完美主义，反复修改第一章
✗ 不要写楔子，读者不会等你
✗ 不要堆设定，先讲故事
✗ 不要切换太多视角，围绕主角转
```

**差评处理原则**：
- 常识性错误 → 可以改
- 剧情向建议 → 慎重
- 追读稳但评论骂 → 不用改（边骂边看）
- **最客观的判断标准**：追更数据有没有掉？
