# 角色心理学方法论

> **核心定位：** 用心理学的透镜透视人物行为背后的深层动机，写出有血有肉、行为自洽、让读者又爱又恨的立体人物。人物的每一个选择、每一句话、每一个动作，都有其心理根源。
>
> **核心公式：** 立体人物 = 表层行为 + 中层性格 + 深层动机 + 底层创伤/执念
>
> **关键认知：** 人物不是作者的提线木偶。好的人物有自己的逻辑、自己的选择、自己的命运——作者只是把他们"发现"出来，而不是"创造"出来。

## 一、核心认知：人物行为的底层逻辑

### 1.1 冰山模型：人物的四层结构

```
【表层】行为表现：说什么、做什么、怎么表现
   ↑ 能直接观察到
【中层】性格特质：外向/内向、理性/感性、谨慎/冲动...
   ↑ 相处久了能感受到
【深层】心理动机：为什么这么做？想要什么？
   ↑ 需要深入了解才能发现
【底层】核心创伤/执念：过去的经历、未完成的心结
   ↑ 连自己都未必察觉，却决定了一切
```

**为什么要分层：**
- 只写表层 → 人物扁平、像纸片人
- 写到中层 → 人物有性格，但还不够立体
- 写到深层 → 人物有动机、有逻辑
- 写到底层 → 人物有灵魂、让人难忘

### 1.2 人物行为的心理逻辑链

```
核心信念 → 价值观 → 性格特质 → 行为模式 → 具体选择
```

**举例（复仇者）：**
```
核心信念："只有变强才能保护重要的人"
   ↓
价值观：力量>一切，弱者活该被欺负
   ↓
性格特质：冷酷、多疑、对强者崇拜、对弱者鄙视
   ↓
行为模式：不择手段变强、看不起软弱的人、不信任别人
   ↓
具体选择：为了变强，可以牺牲一切
```

**关键：** 人物的所有行为，都要能从这条链上找到根源。
- 如果找不到 → 行为不合理，读者会觉得"人设崩了"
- 如果能找到 → 人物自洽，哪怕做坏事，读者也能理解

### 1.3 人物矛盾性的心理基础

**真人都是矛盾的。** 没有绝对的好人，也没有绝对的坏人。

**常见的矛盾组合：**
- 外表冷酷，内心柔软
- 嘴上刻薄，心地善良
- 看起来很自信，其实很自卑
- 对敌人残忍，对自己人温柔
- 嘴上说不在乎，其实比谁都在乎

**为什么矛盾的人物更受欢迎：**
- 更真实（真人就是矛盾的）
- 更有深度（可以挖掘的东西多）
- 更有魅力（反差感、神秘感）
- 更有成长空间（从矛盾到统一的过程，就是人物弧光）

## 二、性格分析工具箱：理解人物的透镜

### 2.1 MBTI十六型人格

**四个维度：**

| 维度 | 说明 | 倾向I | 倾向E/J/T/F/S/N/P |
|:----:|:----:|:-----:|:-----------------:|
| **能量来源** | 从哪里获得能量 | I（内向） | E（外向） |
| **获取信息** | 怎么认识世界 | S（实感） | N（直觉） |
| **决策方式** | 怎么做决定 | T（思考） | F（情感） |
| **生活方式** | 怎么过生活 | J（判断） | P（感知） |

**常见网文主角类型：**

| 类型 | 特点 | 代表人物 | 适合题材 |
|------|------|---------|---------|
| **INTJ 建筑师** | 冷静、理智、战略家、独立 | 谋士型主角、幕后大佬 | 权谋、智斗、系统流 |
| **ENTJ 指挥官** | 强势、果断、领导力、野心 | 枭雄型主角、领主 | 争霸、基建、王朝 |
| **INTP 逻辑学家** | 聪明、好奇、研究型、懒散 | 学者型主角、科学家 | 科研流、炼金、修仙研究 |
| **ENTP 辩论家** | 机智、叛逆、创意多、爱折腾 | 搞事型主角、反套路 | 轻松搞笑、反套路 |
| **ISFJ 守卫者** | 温柔、可靠、守护者、忠诚 | 暖男/贤内助型 | 日常、治愈、温情 |
| **ESTP 企业家** | 行动派、冒险、刺激、江湖气 | 浪子型主角、江湖人 | 江湖、冒险、都市 |
| **INFJ 提倡者** | 理想主义、深邃、殉道者 | 圣父/圣母型、先知 | 仙侠、救世、悲壮 |
| **ENFP 竞选者** | 热情、感染力、社交达人 | 魅力型主角、领袖 | 群像、团队、社交流 |

**⚠️ 注意：** MBTI只是工具，不是枷锁。不要把人物套进固定的模子里，人物可以有跨类型的特质。

### 2.2 九型人格

**九种核心欲望与恐惧：**

| 型号 | 名称 | 核心欲望 | 核心恐惧 | 典型动机 |
|:----:|:----:|:--------:|:--------:|:---------|
| **1号** | 完美型 | 做对的事 | 做错/不完美 | 追求正义、道德洁癖 |
| **2号** | 助人型 | 被爱、被需要 | 不被爱、没人需要 | 付出型、讨好型 |
| **3号** | 成就型 | 成功、被认可 | 失败、一事无成 | 野心家、成功者 |
| **4号** | 自我型 | 独特、与众不同 | 平凡、没有存在感 | 艺术家、悲剧角色 |
| **5号** | 理智型 | 全知、有能力 | 无知、无能 | 学者、研究者 |
| **6号** | 疑惑型 | 安全、稳定 | 危险、不可靠 | 忠诚者、怀疑论者 |
| **7号** | 活跃型 | 快乐、自由 | 痛苦、被困住 | 乐天派、冒险家 |
| **8号** | 挑战型 | 掌控、强大 | 软弱、被控制 | 枭雄、霸王 |
| **9号** | 和平型 | 和谐、平静 | 冲突、失去平衡 | 老好人、佛系 |

**九型人格的优势：**
- 更深层次，触及核心动机
- 有成长方向（健康层级）和堕落方向（不健康层级）
- 适合设计人物弧光（从不健康→健康）

### 2.3 大五人格（OCEAN）

**五个维度，更科学、更细腻：**

| 维度 | 说明 | 高分表现 | 低分表现 |
|:----:|:----:|:--------:|:--------:|
| **O 开放性** | 对新事物的接受度 | 好奇、创意、想象力丰富 | 保守、传统、务实 |
| **C 尽责性** | 自律、可靠程度 | 自律、有条理、可靠 | 懒散、随性、不靠谱 |
| **E 外向性** | 社交能量 | 热情、社交达人、爱热闹 | 安静、内向、喜欢独处 |
| **A 宜人性** | 与人相处的友好度 | 善良、信任、乐于助人 | 多疑、冷漠、竞争心强 |
| **N 神经质** | 情绪稳定性 | 敏感、焦虑、情绪波动大 | 冷静、稳定、不容易慌 |

**用法：** 给人物每个维度打个分（1-10分），人物形象立刻就立体了。

### 2.4 气质类型（体液学说）

**四种经典气质，最适合快速人设：**

| 类型 | 对应元素 | 特点 | 代表角色 |
|------|:--------:|------|---------|
| **胆汁质** | 火 | 热情、冲动、暴躁、行动力强 | 张飞、李逵 |
| **多血质** | 风/气 | 活泼、机智、善变、社交强 | 韦小宝、黄蓉 |
| **粘液质** | 水 | 冷静、沉稳、迟钝、可靠 | 郭靖、沙僧 |
| **抑郁质** | 土 | 敏感、细腻、悲观、多愁善感 | 林黛玉、贾宝玉 |

**用法：** 主角团队最好四种气质都有，性格互补，互动才有戏。

## 三、核心动机：人物为什么而活

### 3.1 六大核心动机

| 动机 | 说明 | 人物追求的是 | 典型人物 |
|------|------|:------------:|---------|
| **权力/掌控** | 想要控制一切、掌控自己的命运 | 力量、地位、控制权 | 枭雄、霸主、反派boss |
| **成就/卓越** | 想要做到最好、证明自己 | 成功、荣誉、认可 | 奋斗型主角、天才 |
| **归属/爱** | 想要被爱、被接纳、有归属感 | 爱情、友情、亲情 | 情感型主角、治愈系 |
| **自由/独立** | 想要无拘无束、做自己 | 自由、逍遥、不被束缚 | 浪子、隐士、修仙者 |
| **真理/认知** | 想要知道真相、理解世界 | 知识、真相、智慧 | 学者型、侦探、求道者 |
| **生存/安全** | 想要活下去、活得安稳 | 生存、安全、稳定 | 末世文主角、苟道流 |

**关键：** 每个人物都有一个**主导动机**和一到两个**次要动机**。
- 主导动机决定了人物的大方向
- 次要动机让人物更复杂
- 动机之间可以有冲突（人物的内心挣扎）

### 3.2 动机的层次：从表层到底层

```
表层目标：我要XXX（具体的、外在的）
   ↓
深层需求：因为我需要XXX（抽象的、内在的）
   ↓
核心执念：不然我就XXX（最恐惧的事）
   ↓
童年/过去创伤：因为小时候XXX（根源）
```

**举例（复仇型主角）：**
```
表层目标：我要杀了XXX报仇
   ↓
深层需求：因为我需要正义/需要发泄愤怒/需要让逝去的人安息
   ↓
核心执念：不然我就对不起他们/我就是个废物
   ↓
童年创伤：因为小时候亲眼看着他们死在我面前，我却无能为力
```

**为什么要挖到这么深：**
- 只有表层目标 → 人物单薄，报完仇就没事了
- 挖到深层需求 → 人物有厚度，复仇只是表象
- 挖到核心执念 → 人物有灵魂，读者能共情
- 挖到创伤根源 → 人物有命运感，有弧光空间

### 3.3 动机冲突：人物的内心挣扎

**最有戏的人物，动机永远是矛盾的。**

**经典动机冲突组合：**

| 冲突类型 | 说明 | 戏剧张力 |
|---------|------|---------|
| **感情 vs 事业** | 选爱情还是选天下？ | 经典永流传 |
| **正义 vs 生存** | 坚持原则还是活下去？ | 人性的考验 |
| **复仇 vs 救赎** | 报仇雪恨还是放下过去？ | 人物弧光的核心 |
| **自由 vs 责任** | 逍遥自在还是承担责任？ | 成长的必经之路 |
| **个人 vs 集体** | 顾自己还是顾大家？ | 格局提升的关键 |
| **理智 vs 情感** | 按道理来还是跟着感觉走？ | 所有人物都有 |

**为什么动机冲突很重要：**
- 没有冲突的人物是扁平的
- 冲突越剧烈，人物越立体
- 解决冲突的过程，就是人物弧光
- 读者会代入，因为读者也有同样的挣扎

## 四、心理防御机制：人物为什么会这样

### 4.1 什么是心理防御机制

**定义：** 当人遇到痛苦、焦虑、威胁时，潜意识会自动启动一些"保护机制"，让自己感觉好一点。

**为什么重要：**
- 解释了人物很多"不合理"的行为
- 让人物更真实、更立体
- 可以用来制造反转和人物弧光

### 4.2 十大常见心理防御机制

| 机制 | 说明 | 人物表现 | 写作用途 |
|------|------|---------|---------|
| **否认** | 拒绝承认现实 | "不可能！这不是真的！" | 重大打击时的第一反应 |
| **压抑** | 把痛苦的记忆压进潜意识 | 不记得某件事/某个人 | 揭开伤疤的反转 |
| **投射** | 把自己的缺点推给别人 | "都是你的错！" | 反派的常见操作 |
| **合理化** | 为自己的行为找借口 | "我都是为了你好" | 伪君子、自我欺骗 |
| **反向形成** | 表现出和内心相反的样子 | 越喜欢越欺负（傲娇） | 傲娇、口嫌体正直 |
| **转移** | 把情绪发泄到弱者身上 | 在外面受气，回家撒气 | 反派的可怜之处 |
| **退行** | 遇到挫折变得幼稚 | 紧张时咬指甲、撒娇 | 脆弱时刻的可爱/心疼 |
| **升华** | 把痛苦转化为动力 | 化悲愤为力量 | 人物成长、逆袭 |
| **补偿** | 某方面不行，另一方面努力 | 长得丑但很努力 | 励志型人物 |
| **幽默** | 用幽默化解痛苦 | 笑着说伤心事 | 魅力型人物、成熟角色 |

### 4.3 防御机制与人物塑造

**不同性格的人，常用的防御机制不同：**

| 性格类型 | 常用防御机制 | 表现 |
|---------|:------------:|------|
| **傲娇型** | 反向形成 | 嘴上说不要，身体很诚实 |
| **冷酷型** | 压抑+否认 | 把感情压下去，假装不在乎 |
| **自负型** | 投射+合理化 | 都是别人的错，我没问题 |
| **自卑型** | 补偿+退行 | 要么拼命努力，要么缩起来 |
| **温柔型** | 升华+幽默 | 把痛苦转化为对别人的温柔 |
| **叛逆型** | 否认+转移 | 拒绝一切，和世界对着干 |

## 五、创伤与执念：人物的灵魂底色

### 5.1 什么是核心创伤

**定义：** 过去发生的、对人物造成深远影响的痛苦事件。

**核心创伤的作用：**
- 决定了人物的性格
- 决定了人物的动机
- 决定了人物的恐惧
- 是人物行为的最终根源
- 也是人物弧光的起点（从被创伤控制，到与创伤和解）

### 5.2 经典创伤类型

| 创伤类型 | 说明 | 对人物的影响 | 典型角色 |
|---------|------|:------------:|---------|
| **被抛弃** | 小时候被父母/重要的人抛弃 | 缺乏安全感、害怕被抛弃、不信任感情 | 外冷内热型、傲娇 |
| **被背叛** | 信任的人背叛了自己 | 多疑、不相信任何人、封闭内心 | 冷酷型、孤狼型 |
| **无能为力** | 眼睁睁看着重要的人死去，自己却救不了 | 内疚、拼命变强、保护欲强 | 复仇型、守护型 |
| **被虐待/欺负** | 长期被欺负、被虐待 | 自卑、懦弱、或者反过来变得残忍 | 黑化型、逆袭型 |
| **不被认可** | 努力了也不被认可，永远被否定 | 拼命想要证明自己、渴望认可 | 奋斗型、野心家 |
| **失去一切** | 家破人亡、失去所有 | 复仇、或者空虚、找不到活着的意义 | 复仇者、浪人 |
| **替罪羊** | 不是自己的错，却被怪罪 | 委屈、愤怒、想要证明清白 | 沉冤得雪型 |
| **身份认同危机** | 不知道自己是谁、从哪来 | 迷茫、寻找身世、寻找自我 | 身世之谜型 |

### 5.3 执念：创伤的另一面

**创伤是"失去了什么"，执念是"一定要抓住什么"。**

**经典执念类型：**
| 执念 | 对应创伤 | 人物表现 |
|------|---------|---------|
| **"我一定要变强"** | 无能为力的创伤 | 修炼狂、武痴 |
| **"我绝不会相信任何人"** | 被背叛的创伤 | 孤狼、冷酷 |
| **"我一定要保护好他们"** | 失去重要的人的创伤 | 守护者、护短 |
| **"我要向所有人证明我可以"** | 不被认可的创伤 | 工作狂、爱面子 |
| **"我一定要找到真相"** | 身世之谜/被冤枉 | 侦探、求道者 |
| **"我要让所有人都怕我"** | 被欺负的创伤 | 暴君、恶人 |

### 5.4 创伤与人物弧光

**经典人物弧光 = 与创伤和解的过程**

```
【起点】被创伤控制，执念驱动
   ↓
【触发】遇到某个人/某件事，开始动摇
   ↓
【挣扎】旧的模式不管用了，痛苦、纠结
   ↓
【低谷】最黑暗的时刻，创伤被彻底揭开
   ↓
【觉醒】意识到自己被创伤控制了，做出新的选择
   ↓
【终点】与创伤和解，执念放下了，获得真正的成长
```

**注意：** 不是所有人物都要和创伤和解。
- 主角 → 通常是和解、成长
- 反派 → 可以是被创伤吞噬、走向毁灭
- 也可以是"带着创伤活下去"（更真实）

## 六、行为模式：人物会怎么做

### 6.1 什么是行为模式

**定义：** 人物在特定情况下，会固定做出的反应。

**为什么重要：**
- 让人物有辨识度
- 让读者能预测人物的反应（人物立住了）
- 打破模式的时候，就是人物成长的时候

### 6.2 常见行为模式

**语言模式：**
- 口头禅、说话的语气、语速
- 喜欢用什么词、不喜欢用什么词
- 生气的时候怎么说话、开心的时候怎么说话

**动作模式：**
- 紧张时有什么小动作（摸鼻子、攥拳、咬嘴唇）
- 思考时有什么习惯（摸下巴、踱步、发呆）
- 开心/生气/难过时有什么特定动作

**决策模式：**
- 遇到选择时，是凭感觉还是凭理智？
- 做决定快还是慢？
- 做了决定后会不会后悔？

**社交模式：**
- 跟陌生人怎么相处？
- 跟朋友怎么相处？
- 跟敌人怎么相处？
- 跟喜欢的人怎么相处？

### 6.3 模式的打破：人物成长的信号

**当人物做出和平时不一样的反应时，说明人物变了。**

**举例：**
```
平时：从不相信任何人 → 现在：选择相信了某个人
→ 读者：哇！他变了！
```

**打破模式的三种情况：**
1. **成长型打破** → 人物变好了、成长了（正向弧光）
2. **堕落型打破** → 人物变坏了、堕落了（反向弧光）
3. **伪装型打破** → 平时都是装的，现在露馅了（反转）

## 七、关系中的心理学：两个人为什么会互相吸引

### 7.1 吸引力的心理学基础

**为什么两个人会互相吸引？**

| 吸引类型 | 心理学原理 | 表现 |
|---------|:----------:|------|
| **相似性吸引** | 物以类聚，人以群分 | 有共同语言、三观一致 |
| **互补性吸引** | 缺什么就喜欢什么 | 内向的人被外向的人吸引 |
| **邻近性吸引** | 日久生情 | 在一起久了就有感情了 |
| **互惠性吸引** | 你对我好，我就对你好 | 互相付出、互相感动 |
| **吊桥效应** | 危险/刺激的时候容易动心 | 共患难容易产生感情 |
| **罗密欧与朱丽叶效应** | 越被反对越相爱 | 外界压力让感情更深 |

### 7.2 依恋模式：爱情中的行为

**四种依恋模式：**

| 模式 | 童年根源 | 恋爱中的表现 | 代表角色 |
|------|:--------:|:------------:|---------|
| **安全型** | 被好好爱过 | 信任、坦诚、健康的恋爱关系 | 正常的男女主 |
| **焦虑型** | 忽冷忽热的爱 | 缺安全感、粘人、容易想多 | 恋爱脑、作精 |
| **回避型** | 被拒绝/被抛弃 | 不敢投入、害怕亲密、若即若离 | 高冷型、傲娇 |
| **混乱型** | 虐待/创伤 | 又渴望又害怕、反复无常 | 创伤型角色、疯批 |

**CP组合的化学反应：**
- 焦虑型 × 回避型 = 追逃模式（经典虐恋组合）
- 安全型 × 焦虑型 = 治愈系（温柔的人治愈缺爱的人）
- 安全型 × 回避型 = 慢慢融化（冰山融化的故事）
- 两个安全型 = 健康但可能没那么有戏

### 7.3 人际关系的三种模式

| 模式 | 说明 | 特点 |
|------|------|------|
| **平等型** | 互相尊重、互相支持 | 健康的关系，适合朋友/战友/情侣 |
| **依附型** | 一方依赖另一方 | 有强弱差，适合师徒/主仆/养成 |
| **竞争型** | 互相较劲、互相攀比 | 亦敌亦友，对手变朋友/恋人 |

## 八、人物心理变化的写作技巧

### 8.1 心理变化的阶梯

**人物的心理变化不是一蹴而就的，要一步一步来：**

```
第一层：无意识
（自己都没察觉，只是行为有微妙变化）
   ↓
第二层：疑惑
（开始觉得"奇怪，我怎么会这样？"）
   ↓
第三层：否认
（"不可能！我才不是这样想的！"）
   ↓
第四层：挣扎
（"到底是为什么？我到底想要什么？"）
   ↓
第五层：接受
（"原来...我一直都是这么想的。"）
   ↓
第六层：行动
（做出和以前不一样的选择）
```

**举例（从讨厌到喜欢）：**
```
无意识：总是不自觉地看向TA
   ↓
疑惑："我怎么老是想到那个家伙？"
   ↓
否认："怎么可能！我才不会喜欢那种人！"
   ↓
挣扎："可是...和TA在一起的时候，好像确实挺开心的..."
   ↓
接受："原来...我喜欢上TA了啊。"
   ↓
行动：主动去找TA / 表白
```

### 8.2 心理变化的触发点

**人物不会无缘无故变，要有触发点：**

| 触发点类型 | 说明 | 效果 |
|-----------|------|------|
| **重大事件** | 生死关头、失去重要的人 | 强烈冲击，快速改变 |
| **某个人** | 遇到一个特别的人，改变了自己 | 缓慢但深刻，治愈系 |
| **新的认知** | 知道了某个真相，改变了认知 | 颠覆性的改变 |
| **时间积累** | 慢慢的、不知不觉地变了 | 最真实、最自然 |
| **危机/绝境** | 被逼到绝路，不得不改变 | 倒逼成长，压力测试 |

### 8.3 怎么写心理变化才不突兀

**技巧一：有铺垫**
- 变化之前要有征兆
- 前面可以埋一些小细节
- 读者回头看能恍然大悟

**技巧二：有过程**
- 不要上一秒还讨厌，下一秒就爱上了
- 给变化一个过程、一段时间
- 让读者能跟上人物的心理节奏

**技巧三：有矛盾**
- 变化不是一帆风顺的
- 会反复、会挣扎、会倒退
- 这样才真实

**技巧四：有行动**
- 心理变化最终要落实到行动上
- 不是"我变了"，而是"我做了和以前不一样的事"
- 行动是心理变化的证明

## 九、不同角色的心理设计

### 9.1 主角的心理设计

**主角心理设计要点：**
1. **要有成长空间** → 起点可以不完美，这样才有弧光
2. **要有核心动机** → 读者知道他为什么而战
3. **要有内心挣扎** → 不是圣人，也会犹豫、会犯错
4. **要有可爱之处** → 哪怕有缺点，读者也会喜欢
5. **要有共情点** → 读者能在他身上看到自己

**主角常见心理弧光：**
- 从自私到无私
- 从懦弱到勇敢
- 从仇恨到放下
- 从自卑到自信
- 从迷茫到坚定

### 9.2 反派的心理设计

**反派心理设计要点：**
1. **要有合理的动机** → 不是"我就是坏"，而是"我有我的理由"
2. **要有自己的逻辑** → 在他的视角里，他是对的
3. **要有可怜之处** → 可恨之人必有可怜之处
4. **要有魅力** → 哪怕是反派，也可以很有魅力
5. **要有底线/原则** → 再坏的人，也有不能碰的东西

**反派的三种经典心理：**
| 类型 | 心理 | 特点 |
|------|------|------|
| **悲剧型反派** | 被命运/创伤推着走，身不由己 | 读者又恨又怜 |
| **理念型反派** | 有自己的理念，只是方式错了 | 读者会思考"他说的好像也有道理" |
| **纯粹型反派** | 就是坏、就是强、就是爽 | 读者："虽然坏，但好帅/好带感" |

### 9.3 配角的心理设计

**配角心理设计要点：**
1. **要有自己的故事** → 不是为了主角而活的工具人
2. **要有自己的动机** → 做每件事都有自己的理由
3. **要有自己的弧光** → 哪怕是配角，也可以成长
4. **和主角有化学反应** → 互动要有火花

## 十、避坑指南：人物心理描写的七大禁忌

### 禁忌一：直接告诉读者

```
❌ "他是一个很善良的人。"
```
**为什么不行：** 没有说服力，读者感受不到。

**正确做法：** 通过行为、语言、选择来展现，让读者自己得出结论。

### 禁忌二：心理活动太直白

```
❌ "我喜欢他。"她想。
```
**为什么不行：** 太直白了，没有美感，也没有回味空间。

**正确做法：** 用细节、用动作、用环境来暗示心理。

### 禁忌三：所有人的心理都一样

```
❌ 不管什么性格的人，心里想的都一样
```
**为什么不行：** 人物没有辨识度，像NPC。

**正确做法：** 不同性格的人，想问题的方式、用词、角度都不一样。

### 禁忌四：心理变化太快

```
❌ 上一章还恨得要死，下一章就爱上了
```
**为什么不行：** 太突兀了，读者不信。

**正确做法：** 心理变化要有过程、有铺垫、有触发点。

### 禁忌五：把人物写得太完美

```
❌ 主角永远正确、永远高尚、永远不犯错
```
**为什么不行：** 不真实，读者没法代入。

**正确做法：** 人物要有缺点、要有弱点、会犯错、会犹豫。

### 禁忌六：人物行为不符合心理

```
❌ 嘴上说很害怕，行动却比谁都勇敢（没有铺垫）
```
**为什么不行：** 人设崩了，读者出戏。

**正确做法：** 行为要符合人物的心理和性格，哪怕有反差，也要有解释。

### 禁忌七：心理描写太多太杂

```
❌ 每句话后面都跟着一大段心理活动
```
**为什么不行：** 节奏拖沓，读者看得累。

**正确做法：** 重要的地方写心理，不重要的地方用动作/对话暗示。

### 11.2 心理变化描写自检清单

写完一段心理变化后，问自己：

- [ ] 有铺垫吗？（前面有没有征兆？）
- [ ] 有过程吗？（是一步一步变的，还是突然就变了？）
- [ ] 有触发点吗？（为什么这个时候变？）
- [ ] 有挣扎吗？（有没有犹豫、反复？）
- [ ] 符合人设吗？（这个人会不会这么想？）
- [ ] 用行动证明了吗？（不只是想，还做了什么？）
- [ ] 读者能共情吗？（换做是你，你会这样吗？）

| **开心** | 想分享、觉得什么都好 | 笑、蹦蹦跳跳、话变多 | 心跳轻快、浑身轻松 |

## 十三、使用建议

### 新手入门（从这三步开始）

**第一步：给主角做个MBTI+九型人格**
- 先确定人物的基本性格
- 有了性格框架，写的时候就不容易崩
- 这是最快上手的方法

**第二步：给人物加一个核心创伤+执念**
- 不用太复杂，一个就够
- 有了创伤和执念，人物立刻就有了深度
- 也为人物弧光打好了基础

**第三步：设计3-5个行为模式**
- 口头禅、小动作、习惯反应
- 有了这些，人物立刻就活了
- 读者能快速记住这个人物

### 进阶提升

1. **多层设计：** 从表层到底层，四层都设计到位
2. **动机冲突：** 给人物加内心挣扎，让人物更立体
3. **心理变化：** 写出人物的成长和变化，画出完整的弧光
4. **关系心理：** 设计人物之间的化学反应和互动模式

### 高级玩法

- **不可靠叙事：** 人物自己都不了解自己，读者慢慢发现真相
- **人格解离/多重人格：** 极端创伤后的产物，戏剧张力拉满
- **心理反转：** 你以为的好人其实心理扭曲，你以为的坏人其实...
- **群体心理：** 一群人的心理怎么写？乌合之众、从众效应、群体极化
