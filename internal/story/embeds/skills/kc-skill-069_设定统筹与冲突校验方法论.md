# KC-SKILL-069 · 设定统筹与冲突校验方法论

> **一句话定位：** 连载百万字不"吃书"的守护系统——在动态更新中执行「新旧设定深度对比→全维度冲突校验→问题分级定位→闭环更新」，确保全书设定100%统一。

---

## 一、设定统筹的本质：动态冲突管理

### 1.1 与静态自洽检验的区别

| 对比维度 | KC-SKILL-047 自洽性检验（静态） | KC-SKILL-069 设定统筹（动态） |
|:---------|:-------------------------------|:------------------------------|
| **时机** | 世界观构建完成后的静态验证 | 连载过程中每次新增内容时的动态校验 |
| **对象** | 世界观规则本身是否自洽 | 新内容与已有设定是否冲突 |
| **重点** | 规则逻辑、战力体系、设定闭环 | 新旧设定对比、逻辑漏洞、设定缺失 |
| **输出** | 自洽性报告+压力测试结果 | 冲突分析报告+分级修复方案 |

### 1.2 核心问题：为什么需要设定统筹

百万字连载中，设定冲突是必然挑战：
- 人物性格在第200章偏离第1章设定（人设OOC）
- 战力体系在中后期崩坏（越级乱串）
- 时间线前后矛盾（时间重叠/无过渡跳跃）
- 伏笔废弃未回收
- 道具/能力效果前后不一致

**设定统筹的目标**：在每次新增内容时，自动执行全维度校验，把冲突消灭在萌芽状态。

## 二、三层Bible体系：从全局到单章

### 2.1 层级定义（从高到低，低层必须100%服从高层）

| 层级 | 术语 | 标准释义 | 更新频率 |
|:-----|:-----|:---------|:---------|
| **最高层** | 作品总Bible（Work Bible） | 全局设定圣经，唯一基准线。包含：作品基础信息、核心世界观规则、主角/核心配角人设、战力体系、核心爽点逻辑、剧情主线大纲、强制合规红线、伏笔总表、时间线总表 | 核心设定极少变更，细节随剧情补充 |
| **第二层** | 卷/部纲Bible（Volume Bible） | 分卷设定与剧情大纲。明确本卷核心定位、剧情主线、人物成长线、核心冲突、伏笔回收计划 | 每卷开始时定稿，卷内可微调 |
| **第三层** | 章节Bible（Chapter Bible） | 单章全层级合并档案。包含章节基础信息、本章设定集、章节正文、更新变更日志 | 每章完成后归档 |

### 2.2 层级服从铁律

- 所有单章内容、支线剧情、番外、新设定必须100%服从作品总Bible
- 卷纲Bible必须完全服从作品总Bible
- 章节Bible必须完全服从所属作品总Bible与卷纲Bible
- **绝对禁止反向突破**：低层级不得擅自修改高层级设定

## 三、八大校验维度：全维度冲突扫描

> 每次新增内容（新章节/新设定/新人物）时，必须对以下8个维度进行100%全覆盖扫描。

| 校验维度 | 校验核心内容 | 典型问题 |
|:---------|:-------------|:---------|
| **① 世界观设定冲突** | 新内容是否与底层规则冲突，是否出现前后矛盾的世界运行规则 | 前文设定无异能，后文突然使用异能 |
| **② 战力体系崩坏** | 是否出现战力越级、能力边界突破、力量体系前后不一致、技能效果矛盾 | 主角突然越级击败高阶敌人无合理解释 |
| **③ 人物人设OOC** | 人物台词、行为、动机、决策是否符合人设，是否性格突变、行为逻辑断层 | 隐忍型主角突然冲动行事无铺垫 |
| **④ 时间线/剧情线闭环** | 是否出现时间线混乱、前后剧情矛盾、伏笔废弃/未回收、主线偏离 | 前章配角已出国，后章无解释出现在主角身边 |
| **⑤ 核心规则合规** | 是否符合强制合规红线（如SAN值闭环、直播间交易规则等） | 突破用户明确标注的红线 |
| **⑥ 道具/能力设定** | 道具、技能、特殊物品是否与已归档设定一致，效果是否前后矛盾 | 同一道具前后效果不一致 |
| **⑦ 逻辑漏洞定位** | 是否出现剧情逻辑不通、因果关系不成立、行为动机缺失、剧情断层 | 无动机的反转、无因果的剧情推进 |
| **⑧ 设定缺失识别** | 是否出现关键设定缺失、细节空白、人物背景/道具来源未交代 | 新道具出现无来源交代 |

## 四、问题分级处理机制：核心级 vs 细节级

> **核心原则：绝对禁止越权处理**。必须将问题严格分级，执行不同处理规则。

### 4.1 核心级问题（必须先询问，禁止自行修改）

**定义**：直接影响全书主线、核心世界观、主角人设、底层规则的冲突/漏洞。

| 核心级问题类型 | 示例 |
|:---------------|:-----|
| 与核心世界观/底层规则冲突 | 前文设定"修仙需灵根"，后文出现无灵根修仙 |
| 主角/核心配角/反派核心人设OOC | 隐忍主角无铺垫突然冲动，行为逻辑完全违背既定设定 |
| 战力体系核心层级崩坏 | 主角突然越级，核心能力边界突破 |
| 主线剧情/关键时间线重大矛盾 | 关键剧情节点前后矛盾，时间线混乱 |
| 突破强制合规红线 | 违反用户明确标注的禁忌内容 |
| 影响全书走向的重大逻辑漏洞 | 因果关系不成立导致主线崩塌 |

**处理规则**：
1. 输出完整《设定冲突/逻辑漏洞分析报告》（标注问题位置、冲突双方新旧设定、影响范围、风险等级）
2. 每个核心级问题给出至少2套可落地修复方案（标注优劣势、对主线影响）
3. **等待用户明确确认后方可执行**，绝对禁止擅自决策

### 4.2 细节级问题（可自行完善补全，同步说明）

**定义**：不影响全书主线、核心设定、人物人设的细节性漏洞、设定缺失、轻微逻辑瑕疵。

| 细节级问题类型 | 示例 |
|:---------------|:-----|
| 非核心配角基础信息轻微不一致 | 年龄、外号、出场地点前后小偏差 |
| 非核心道具/技能细节描述缺失 | 轻微效果偏差、外观细节空白 |
| 单章内时间线轻微偏差 | 场景细节空白、时间过渡不完整 |
| 不影响主线的轻微逻辑瑕疵 | 因果关系补充、动机细节完善 |
| 非核心设定细节缺失 | 背景细节空白补充 |

**处理规则**：
1. 严格遵循作品总Bible核心设定，自行完成漏洞补全、细节完善、逻辑闭环
2. 明确标注「自行完善的细节内容清单」，说明补全依据
3. 若对边界存疑，**一律按核心级处理**，先询问，绝不越权

## 五、设定闭环更新流程

### 5.1 触发规则（满足任一即触发）

1. 提交新写的单章/多章正文、新剧情片段、新人设/世界观设定时
2. 执行章节Bible更新、作品总Bible修改操作时
3. 识别到内容中出现与已归档设定不一致的信息时

### 5.2 全流程执行标准（严格按顺序，不得跳步）

```
第一步：新旧设定深度对比
  ↓ 调取最新版作品总Bible作为唯一校验基准
  ↓ 对新内容进行8大维度100%全覆盖扫描
  ↓ 精准定位所有问题
  ↓
第二步：问题分级
  ↓ 核心级问题 → 输出报告+修复方案 → 等待用户确认
  ↓ 细节级问题 → 自行补全 → 标注清单说明依据
  ↓
第三步：统一方案输出与设定闭环更新
  ↓ 同步更新作品总Bible（确保新旧设定完全统一）
  ↓ 同步更新全书伏笔总表、时间线总表
  ↓ 同步更新对应章节Bible
  ↓ 输出结构清晰、标注明确的最终结果
```

## 六、五条强制合规红线

1. **禁止擅自修改核心设定**：未获用户明确确认，不得修改/删除已确认的核心设定、主线剧情、主角人设
2. **禁止隐瞒冲突漏洞**：必须100%透明呈现所有校验结果，不得遗漏
3. **禁止超纲补全**：自行补全的细节必须完全贴合全书世界观、人设、剧情走向，不得新增与主线无关内容
4. **遵循更新流程**：必须「用户确认→更新总Bible→更新章节Bible」，绝对禁止反向操作
5. **跨作品隔离**：A书设定不得用于补全B书漏洞，多作品设定完全物理隔离

## 七、核心信息自动提取规则

> 无论用户提供的是新书大纲、开篇正文、人设片段、世界观设定，还是零散剧情要求、单章正文，都必须自动提取以下核心信息，形成/更新作品总Bible。

| 提取维度 | 核心内容 |
|:---------|:---------|
| 作品基础信息 | 作品名、题材类型、核心标签、目标受众、核心爽点逻辑 |
| 世界观核心规则 | 世界背景、核心力量体系、世界运行底层规则、绝对不能打破的红线 |
| 人物核心人设 | 主角姓名/性格/能力/行为逻辑/成长线/核心执念；核心配角与反派的人设/关系/动机/能力边界 |
| 剧情主线与时间线 | 全书核心故事线、核心冲突、最终目标、关键剧情节点、时间线总表 |
| 伏笔总表 | 已埋设伏笔、已回收伏笔、待回收伏笔 |
| 强制合规红线 | 用户明确要求的绝对禁止内容、必须遵守的创作规则 |

## 十、使用建议

- **开新书时**：建立初始作品总Bible，提取6大维度核心信息
- **每章完成后**：触发全维度校验，核心级问题出方案待确认，细节级问题自行补全
- **每卷结束时**：全本设定统筹归档，更新总Bible确保闭环
- **发现设定打架时**：执行核心冲突统一方案输出，深度对比新旧设定
- **连载中后期**：定期全本扫描，防止长篇设定漂移
