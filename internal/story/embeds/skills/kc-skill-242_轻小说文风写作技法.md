# 轻小说文风写作技法

> **一句话定位**: 流畅的自然语言 + 轻度的吐槽 + 适度的暧昧 + 紧张感适当的战斗 + 每章末尾的面板提示
>
> **参考语调**: 《无限斯特拉托斯》《恶魔高校DxD》中文译本的叙事语调 + 轻小说式吐槽
>
> **适用题材**: 男性向轻小说、系统流、穿越同人、后宫/暧昧向网文

---

## 一、核心写作规则体系

### 1.1 叙事视角与语言基调

| 规则 | 要求 | 正例 | 反例 |
|:----|:-----|:-----|:-----|
| **第三人称有限视角** | 始终跟随主角视角展开，不随意切换他角色内心 | "千里猛灌了一口红茶" | "千里端起茶杯，轻啜一口，眸中闪过一丝深邃"（古风过重） |
| **口语化适度** | 平实流畅的现代汉语，避免过分华丽或古风 | 对话自然，符合角色性格 | 堆砌成语、文言句式 |
| **吐槽只在内心** | 适度吐槽，点到为止，不破坏剧情紧张感 | 内心独白"系统，你这信息量也太直白了吧" | 出声吐槽破坏场景氛围 |

### 1.2 节奏控制公式

```
每章 5,000-7,000 字 → 分 4-5 个小节 → 每节末尾设"小钩子" → 张弛交替
```

**张弛交替模式**:
- 紧张战斗 → 轻松日常/暧昧互动 → 下一轮冲突
- 战斗篇幅控制在 1,000-2,000 字以内
- 侧重战斗中的**心理活动、策略判断、临场反应**，辅以系统数据解析

### 1.3 系统面板展示规范

| 位置 | 内容 | 格式 |
|:----|:-----|:-----|
| **章首/章末** | 完整系统面板（状态更新） | 见模板 |
| **剧情中间** | 只显示关键数据变化 | 好感度变化、能力解析结果 |
| **系统提示** | 中立、不带感情的机械音 | 用【方括号+机械音描述】|

**示例**:
```
【数据解析完成……】
【最佳应对方案：左移三步·下蹲·向斜上方释放魔力冲击】
```

### 1.4 好感度变化的"余韵"写法

在【好感度变化】提示框之后，紧跟一句简短的诗意/氛围描述句，为数据赋予情感余韵：

```
【好感度变化：姬岛朱乃 35→40】

温暖传递。
```

**标注格式**:
- **已有角色**: X→Y（变化值，如 35→40）
- **首次接触**: X/100（绝对值，如 50/100），可附一句说明

### 1.5 外貌与暧昧描写

| 场景 | 写法 |
|:----|:-----|
| **首次出场** | 详细介绍，从主角视角带适度的男性向欣赏感 |
| **后续出场** | 只点出特征（红发、黑发、金发等），不重复堆砌 |
| **暧昧互动** | 先暧昧后暗示：肢体接触→氛围烘托→语言挑逗→隐晦暗示 |
| **性描写** | 不直接写性行为，用比喻+事后反应代替 |

### 1.6 开篇方式（两种模式）

| 模式 | 适用场景 | 写法 | 示例 |
|:----|:---------|:-----|:-----|
| **模式A：场景细节切入** | 高潮/悬念型章节 | 从感官细节入手（触觉/嗅觉/听觉），逐步展开 | "意识模糊中，最先感受到的是冰凉的石板触感。" |
| **模式B：时空陈述切入** | 日常/过渡型章节 | 简洁直白，快速进入正题 | "第二天清晨，千里在驹王学园的男生宿舍里醒来。" |

### 1.7 内心独白双语调

| 语调 | 适用场景 | 示例 |
|:----|:---------|:-----|
| **吐槽式** | 轻松日常场景 | 口语化、短促："至少卖相不错。" |
| **认真式** | 关键抉择场景 | 清晰、坚定："对不起，但我不会把已经到手的东西让出去。" |

两种语调根据场景紧张度切换，同一种内心独白不过长，1-2 句点到为止。

## 二、OOC 防范与角色处理

### 2.1 角色性格标签确认

每个重要配角出场时，先确定其核心性格标签，对话和行为严格贴合：

| 角色类型 | 性格标签 |
|:---------|:---------|
| 高贵型女主 | 高贵、自信、有领导力，对自己人温柔 |
| 温柔大姐姐型 | 表面温柔，内里抖S |
| 冷淡型 | 冷淡寡言，内心细腻 |
| 直率型 | 直率、战斗狂、严肃 |

### 2.2 原男主/原作角色处理

面对原作角色时，写出**内心复杂感**——愧疚与坚定的矛盾冲突：

```
……对不起，但我不会把已经到手的东西让出去。
```

**原则**:
- 保留对原男主的善意，但绝不退让已获得的东西
- 原男主保持善良热情的本性，**不降智、不丑化、不写成小丑**
- 内心戏节奏：先铺垫担忧 → 省略号/沉默停顿 → 表达坚定决心

### 2.3 "唯一特殊存在"互动原则

- 主角是"唯一的特殊存在"
- 周围女性对他的关注要有合理的理由（实力、性格、独特之处）
- 不写成无脑倒贴
- 修罗场的苗头可以适当埋下

## 三、战斗与能力体系

### 3.1 战斗描写规范

- 不过分纠缠于每一招每一式的细节
- 侧重**战斗中的心理活动、策略判断、临场反应**
- 辅以系统的数据解析作为战斗辅助
- 战斗篇幅控制在 1,000-2,000 字以内

### 3.2 能力获取逻辑

- 能力不是凭空获得的——必须有来源、有铺垫、有解锁条件
- 不能在条件未达成时突然使用新能力
- 需要提前获得时，用合理的剧情桥段来解释

### 3.3 技能名独创性

- 原男主专属技能名不能混用（如"Boost"是赤龙帝专属）
- 每个力量的觉醒都应有独特的能力名称和表现形式
- 能力偏向时间/空间时，技能名应体现这一特性（如"Phase"表示空间相位化）

## 四、禁忌与注意

| 项目 | 说明 |
|:-----|:-----|
| ❌ 不能 OOC | 每个角色必须符合原著性格基调 |
| ❌ 不能过度虐主 | 主角可以遇到困难，但不能被长期压制 |
| ✅ 主角占据主动 | 在战斗/恋爱中都处于主导地位 |
| ✅ 女主有独立人格 | 不是工具人，有各自的追求和性格 |
| ✅ 原男主可以惨但不能降智 | 原男主可以被打败，但不能被写成傻子 |
| ❌ 不能写性器名称 | 用比喻代替 |
| ❌ 不能写具体性交过程 | 用隐晦描写+事后反应代替 |
| ❌ 跨世界观名词管控 | 不得出现其他作品独有组织名（如"狮子王机关"） |
| ❌ 大人物不自贬身份 | 高地位角色自我介绍时不应自贬（如"堕天使总督"不说"我只是个小干部"） |

## 五、AI味句式黑名单

| 黑名单句式 | 问题 | 修正方法 |
|:-----------|:-----|:---------|
| "X天后，XX来了。不是……而是……" | 模板化转折，缺画面感 | 从日常细节切入（日光灯闪烁→震动→玻璃碎裂→学生尖叫） |
| "那天，他看到了一切。" | 空泛概括 | 说明"怎么看到的"，把"看到"写出层次 |
| "现在的我只是一个XX罢了" | 大人物自降身份 | 保持角色应有的身份定位 |
| "看起来不止X股势力……"——"堕天使？"——"不止。" | 三段式追问模板 | 减少机械问答，用叙述整合信息 |

## 六、友好互动与战斗高潮的节奏分配

- 读者期待的感情互动不能拖太久——战斗高潮期最需要感情线调剂
- 互动与战斗交替分布：一场紧张战斗前或后，安排亲密/暧昧互动缓冲
- 互动场景可以兼任叙事功能（深化感情、制造铺垫、解锁能力），一举两得

---

## 七、隐晦比喻自洽原则

- 比喻需要前文铺垫（如"铃声"意象需先写出女主的轻吟/叫声）
- 不要在比喻后面加解释句——读者懂的不用解释，不懂的解释也没用，反而破坏氛围

## 写作前自查清单

- [ ] 本章类型：日常 / 战斗 / 高潮 / 过渡
- [ ] 开篇模式：模式A（场景细节）还是 模式B（时空陈述）
- [ ] 4-5 个小节的"小钩子"分别是什么
- [ ] 是否有 AI 味句式？（见第五节黑名单）
- [ ] 时间线是否与上一章衔接明确？
- [ ] 是否有跨世界观名词？
- [ ] 能力使用是否符合设定逻辑？
- [ ] 角色对话/行为是否符合性格标签？（OOC 检查）
- [ ] 每小节结尾是否有钩子？张弛是否交替？
- [ ] 隐晦比喻是否自洽、无元解释？
- [ ] 本场的暧昧/互动发生在哪个小节，作用是什么？
- [ ] 好感度变化发生几次、用哪种格式？
- [ ] 章末面板数据是否有更新？
