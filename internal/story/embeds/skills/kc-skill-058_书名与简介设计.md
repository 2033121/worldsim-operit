# 书名与简介设计

## 核心原则

1. **书名是第一卖点**：编辑和读者只给书名3秒注意力，书名决定点击率，点击率决定一切。
2. **清晰展示卖点的前提下，尽可能简短**：新人书名长度4-9字最佳，过长则失焦。
3. **三大公式可复用**：主体身份+噱头/反常识组合/结果前置，覆盖90%爆款书名。
4. **四标准检验**：好记/有画面/有悬念/有类型感，缺一项则书名不达标。
5. **简介是书名的延伸**：300字以内，人物+冲突+钩子三要素缺一不可。

## 操作步骤/公式

### 步骤1：掌握三大书名公式

```
公式一：主体身份 + 核心噱头
格式：主体身份 + 核心噱头
示例：《直播：道长别装了，你就是在修仙》
特点：直接告诉读者"主角是谁+卖点是什么"
适用：直播流、系统流、身份反差流

公式二：反常识组合
格式：两个看似矛盾的元素组合
示例：《家人们相信科学，但这鬼真不是我请的演员》
特点：制造认知冲突，引发好奇
适用：灵异、搞笑、反差流

公式三：结果前置
格式：直接把爽点或结果放在书名里
示例：《直播算命太准，被全网警察关注了》
特点：让读者一眼看到"爽点在哪"
适用：爽文、装逼流、打脸流
```

### 步骤2：四标准检验

| 标准 | 说明 | 检验问题 |
|------|------|---------|
| **辨识度** | 能和其他书区分开吗？ | 有独特文化标签/人物感 |
| **期待感** | 读者看完想点进去吗？ | 读者能从书名里读到故事 |
| **记忆点** | 读者能记住你的书名吗？ | 有人物感或独特意象 |
| **延展性** | 能承载后续系列作品吗？ | 可成系列（《XX：XX》） |

```
四标准自检：
· 任何一个标准不达标 → 书名需要优化
· 四项全达标 → 优秀书名
· 三项达标 → 合格书名
· 两项及以下达标 → 重新起名
```

### 步骤3：避开书名雷区

```
❌ 过于晦涩的意象或生僻字
  → 读者看不懂，直接划走

❌ 三个字以内且无卖点
  → 太短无法传递信息，除非是大神

❌ 蹭其他爆款的热度
  → 平台限流，读者反感

❌ 书名与内容不符
  → 点击率高但留存率低，平台降权

❌ 堆砌设定词汇
  → "玄天大陆之龙魂觉醒"——读者无感
```

### 步骤4：简介写法

```
核心：300字以内，人物+冲突+钩子三要素

【人物】一句话介绍主角身份和核心特征
【冲突】主角面临的核心冲突/困境
【钩子】留下悬念，让读者想看正文

简介核心原则：
1. 清晰地介绍你的卖点
2. 让读者有一点期待感

示例：
书名：《说好制作烂游戏，泰坦陨落什么鬼》
简介：直接勾勒冲突——男女主不对付，
后面会擦出怎样的火花？

简介避坑：
❌ 大段世界观介绍
❌ 罗列人物清单
❌ 剧透核心反转
✅ 聚焦冲突和钩子，留白引发好奇
```

### 步骤5：书名生成流程

```
1. 确定核心卖点（一句话）
   · 主角是谁？卖点是什么？

2. 套用三大公式生成10个备选
   · 公式一生成3-4个
   · 公式二生成3-4个
   · 公式三生成3-4个

3. 四标准检验
   · 每个备选书名打分（辨识度/期待感/记忆点/延展性）

4. 筛选Top3
   · 选出得分最高的3个

5. A/B测试
   · 在小范围读者群/朋友间测试
   · 看哪个点击率最高

6. 最终确定
   · 结合平台调性和读者偏好
```

## 模板/示例

### 模板1：好书名示例库

```
【卖点清晰型】
《我有一座恐怖屋》—— 卖点清晰（恐怖屋）
《家里养个狐狸精》—— 卖点清晰（狐狸精）
《废土边境检查官》—— 卖点清晰（废土+检查官）

【主体身份+噱头型】
《直播：道长别装了，你就是在修仙》
《我在诡异世界谨慎求生》
《我有一群地球玩家》

【反常识组合型】
《家人们相信科学，但这鬼真不是我请的演员》
《说好制作烂游戏，泰坦陨落什么鬼》
《只想做个好人，怎么就成了反派》

【结果前置型】
《直播算命太准，被全网警察关注了》
《开局签到一万年》
《我，废柴，打爆诸天》
```

### 模板2：简介模板

```markdown
【人物介绍】（50字以内）
______是一个______的主角，他/她______。

【核心冲突】（150字以内）
然而，______打破了平静。
主角不得不面对______，
而他/她唯一的依靠是______。

【钩子】（100字以内）
当______发生时，
主角的选择是______。
而这一切，才刚刚开始……

总字数控制：300字以内
```

## 自检清单

- [ ] 书名是否套用了三大公式之一？
- [ ] 书名长度是否在4-9字（新人）或合理范围内？
- [ ] 书名是否通过四标准检验（辨识度/期待感/记忆点/延展性）？
- [ ] 是否避开了书名雷区（晦涩/过短/蹭热度/堆砌设定）？
- [ ] 是否生成了至少10个备选书名？
- [ ] 是否进行了四标准评分筛选？
- [ ] 简介是否在300字以内？
- [ ] 简介是否包含人物+冲突+钩子三要素？
- [ ] 简介是否避免了世界观大段介绍和人物清单？
- [ ] 书名与内容是否一致（避免标题党导致留存率低）？

## 适用边界

- **适用**：所有网文平台（番茄/起点/纵横/七猫/晋江）
- **强适用**：新人作者（书名是新人唯一的曝光机会）
- **强适用**：番茄小说（免费平台，书名决定点击率）
- **弱适用**：大神作者（有粉丝基础，书名容错率高）
- **不适用**：已签约作品的书名修改（需编辑同意）
- **慎用**：系列作品的后续作品（需保持系列命名一致性）
