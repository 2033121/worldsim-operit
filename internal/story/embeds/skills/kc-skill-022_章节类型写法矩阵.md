# 章节类型写法矩阵

## 核心原则

1. **一章一主型**：每章有一个主导类型（打斗/情感/日常/悬疑/升级/副本），避免"四不像"。
2. **类型决定写法**：不同章节类型有专属的节奏公式、镜头调度和情绪曲线，不可混用。
3. **日常不水公式**：日常章必须同时承担"日常+信息+伏笔+钩子"四重功能，禁止纯流水账。
4. **副本必须闭环**：副本章要有独立的起承转合，结束时主线问题必须更大。
5. **类型选择服务节奏**：章节类型由全书节奏（压→缓→压→爆）决定，不可随意切换。

## 操作步骤/公式

### 步骤1：掌握六大章节类型专属公式

| 章节类型 | 核心公式 | 字数分配（2000字章） |
|---------|---------|---------------------|
| **打斗章** | 战前对峙（憋）→试探交锋（快）→全力爆发（爆）→胜负分晓（收） | 对峙300+交锋800+爆发600+收尾300 |
| **情感章** | 表面平静→一点打破→慌乱掩饰→更深的沉默 | 铺垫500+打破500+慌乱500+沉默500 |
| **日常章** | 场景建立→人物互动→小波澜→温情/搞笑收尾 | 建立400+互动800+波澜500+收尾300 |
| **悬疑章** | 异常感知→危险逼近→关键发现→更大悬念 | 感知400+逼近600+发现600+悬念400 |
| **升级章** | 长期压抑→契机出现→拼命一搏→突破瞬间→爽感释放→新问题 | 压抑500+契机300+拼搏500+突破400+释放300 |
| **副本章** | 进入副本→遭遇问题→层层深入→核心冲突→解决→收获→主线钩子 | 进入300+问题400+深入500+冲突400+收获400 |

### 步骤2：日常不水公式（核心难点）

```
日常章 = 日常 + 信息 + 伏笔 + 钩子

【日常】展示人物性格、推进关系
【信息】埋入1-2条主线信息（设定/势力/线索）
【伏笔】埋入1条支线彩蛋伏笔（可长期不回收）
【钩子】章末必须留钩子，禁止"平淡收尾"

避坑：
❌ 流水账：起床→刷牙→吃早饭→出门→上班→下班→回家→睡觉
❌ 无关对话：聊天气、聊吃了什么、没有信息量
✅ 有信息的：展示人物性格、推进关系、埋伏笔、埋笑点
```

### 步骤3：副本闭环设计

```
副本三要素：
1. 副本有自己的冲突（为什么来？遇到什么？）
2. 副本有自己的解决（怎么赢？）
3. 副本有自己的收获（得到什么？）

副本钩子设计：
1. 副本结束，主线问题更大了
2. 副本中发现意外线索
3. 副本boss说了什么奇怪的话

副本结构（参考《青河娘娘庙》）：
入口（场景建立）
  ↓
第一层：外围（异常初现）
  ↓
第二层：内部（危险升级）
  ↓
核心：直面恐怖/Boss
  ↓
解决：找到方法
  ↓
余韵：新的悬念（主线钩子）
```

### 步骤4：章节类型选择决策树

```
当前节奏需要"压"（压抑感）？
├── 是 → 悬疑章 / 副本章（遭遇问题阶段）
│
当前节奏需要"缓"（喘息空间）？
├── 是 → 日常章（必须用不水公式）/ 情感章（暧昧/温情）
│
当前节奏需要"爆"（释放）？
├── 是 → 打斗章（胜负分晓）/ 升级章（突破瞬间）
│
当前节奏需要"承上启下"？
├── 是 → 副本章（进入新地图）/ 情感章（关系转折）

决策原则：
- 高能章和缓冲章比例：3:1 或 4:1
- 连续三章高能章后必须有缓冲
- 章末钩子数量保持≥1.75个
```

## 模板/示例

### 模板1：打斗章五镜头法

```
镜头1：全景对峙 ——交代双方位置，营造压迫感
镜头2：近景动作 ——展示招式，观众看清细节
镜头3：慢镜定格 ——高潮瞬间，时间拉长
镜头4：环境反应 ——旁观者反应，增加真实感
镜头5：结果呈现 ——胜负明确，不拖泥带水

避坑：
❌ "招式名+结果"直接跳（太快，没有过程）
❌ "主角很强，反派不是对手"（太虚，没有展示）
❌ "大战三百回合"（太水，流水账）
✅ 每招之间有心理/环境变化，1-2处名场面定格
```

### 模板2：悬疑章五感法

```
视觉：黑暗、阴影、模糊的轮廓
听觉：脚步声、喘息声、不知来源的声音
触觉：冷汗、颤抖、发麻
嗅觉：腐烂、金属、血腥
味觉：发苦、发涩、发干

公式：异常感知 → 危险逼近 → 关键发现 → 更大的悬念
```

### 模板3：升级章核心技巧

```
核心：压抑够久，爆发才够爽
1. 压抑要够久（读者憋得难受）
2. 突破要够快（情绪释放要爽）
3. 爽感要够实（具体画面，不是形容词）

公式：长期压抑 → 契机出现 → 拼命一搏 → 突破瞬间 → 爽感释放 → 新问题出现
```

### 模板4：日常章示例（不水版）

```
苏晴的出租屋很小，只有十五平米。
但她收拾得很整齐。床铺叠成豆腐块。
顾沉站在门口："你这是处女座吗？"
"嗯。"
（日常+性格展示）

椅子靠背上挂着一只毛绒熊，眼睛有点歪。
"那你还留着？"
"他送的。"
"他是谁？"
"我前男友。"
（伏笔：前男友线索 + 关系推进）

"我什么都没有送你。"
苏晴笑了："所以你暂时还没资格当教训。"
（信息+钩子：暗示关系发展可能性）
```

## 自检清单

- [ ] 本章是否有明确的主导类型（六选一）？
- [ ] 是否使用了该类型的专属公式？
- [ ] 日常章是否满足"日常+信息+伏笔+钩子"四重功能？
- [ ] 副本章是否形成闭环（冲突+解决+收获+主线钩子）？
- [ ] 打斗章是否有1-2处名场面定格？
- [ ] 悬疑章是否使用了五感法？
- [ ] 升级章压抑是否够久，爆发是否够爽？
- [ ] 章末是否留有钩子（禁止平淡收尾）？
- [ ] 章节类型选择是否符合当前节奏需要（压/缓/爆/承上启下）？
- [ ] 高能章和缓冲章比例是否在3:1到4:1之间？

## 适用边界

- **适用**：所有正文章节写作，尤其是百万字长篇的章节规划
- **强适用**：日更连载作者（提前规划章节类型，避免临时决定导致节奏混乱）
- **弱适用**：开篇黄金三章（前三章是混合型，需综合运用多种类型技巧）
- **不适用**：楔子/番外（有独立写法，不套用六大类型）
- **慎用**：超短章（1000字以下）难以完整执行六类型公式，需简化
