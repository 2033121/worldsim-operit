# 朱雀去痕技法

## 核心原则

AI生成的文本在统计上更"平滑"、更少意外——过检的核心是增加"人味波动"。朱雀去痕不是单纯替换词汇，而是通过识别AI痕迹→替换高频词→打散均匀段落→润色口语化的四步闭环，让文本从"机器读感"回归"人类读感"，最终目标AI率<20%。

---

## 操作步骤/公式

### 一、六大AI痕迹识别清单

| 序号 | 痕迹类型 | 检测项 | 判定标准 |
|:---:|:------|:------|:------|
| 1 | 高频词重复 | "突然/猛然/顿时/缓缓/静静/似乎/然而" | 同一词出现 ≥3处即触发 |
| 2 | 逻辑过于完美 | 因果链无懈可击、无意外分支 | 全章无任何"无用细节" |
| 3 | 缺乏口语化 | 对话工整、无停顿省略打断 | 连续对话无口语语气词 |
| 4 | 情感描写过于直白 | "他很紧张/他很愤怒/他很悲伤" | 直接告诉情绪而非展示 |
| 5 | 场景描写流水账 | 起床→刷牙→吃饭→出门→上班 | 逐项平铺无取舍 |
| 6 | 段落长度过于均匀 | 每段字数接近、节奏单一 | 段落字数方差过小 |

### 二、消痕四步法

```
Step 1【识别】朱雀检测扫描
  └─ 目标AI率<20%，逐项对照六大痕迹清单
  └─ 标记所有触发点

Step 2【替换】AI高频词替换
  └─ 对照"AI高频词替换表"逐项替换
  └─ 保留语义，改变表达

Step 3【打散】段落节奏重构
  └─ 长短句剧烈交错
  └─ 故意制造不完美句式
  └─ 制造情绪突变、口语化打断

Step 4【润色】人味波动注入
  └─ 检查对话不完美化
  └─ 检查心理描写间接化
  └─ 再次检测，循环直至达标
```

### 三、AI高频词替换表

| AI高频词 | 替换方案 | 优先级 |
|:---:|:---|:---:|
| 突然 | 话音刚落 / 霎时间 / 霍地 | 🔴必换 |
| 猛然 | 猛地 / 霍地 / 霎时间 | 🔴必换 |
| 顿时 | 当即 / 立时 / 一下 | 🔴必换 |
| 缓缓 | 慢悠悠 / 一点点 / 磨蹭着 | 🔴必换 |
| 静静 | 默默 / 没吭声 / 安静地 | 🔴必换 |
| 似乎 | 像是在 / 透着 / 带着点 | 🔴必换 |
| 然而 | 可 / 但 / 偏偏 / 不过 | 🔴必换 |
| 然后 | 接着 / 紧跟着 / 这会儿 | 🔴必换 |
| 非常 | 特别 / 贼 / 老 / 倍儿 | 🔴必换 |

### 四、机械句式消痕对照

| 问题类型 | 检测项 | 修正方法 |
|:------|:------|:------|
| 机械比喻 | "仿佛/如同/似乎/像极了" ≥3处 | 改成具体动作描写 |
| 假感慨 | "令人惊叹/令人惋惜/令人感动" | 直接写发生了什么事 |
| 机械转折 | "不是A——而是B" | 换成自然转折 |
| AI腔 | "弹幕飘过/开始变密/气氛凝重" | 删掉，用真实反应代替 |
| 堆感叹号 | 连续感叹号 >2处 | 只留一个，其他改句号 |
| 流水情绪 | "他很紧张/他很愤怒/他很悲伤" | 改成动作+反应 |
| 设定灌输 | 连续3句以上说明文无动作穿插 | 中间穿插动作/对话 |
| 标点混用 | 中英标点混用 / 半角空格 | 统一为中文全角 |

## 模板/示例

### 对话不完美化技巧

```
人类对话四特征：
✅ 口语化："嗯……""啊……""这个嘛……"
✅ 被打断：话说到一半被截断
✅ 重复："我、我不是……""那、那个……"
✅ 语气词："懂？""呢？""啊？""吧？"
✅ 省略："行。""去。""嗯。"

示例（前→后）：
❌ "我真的很喜欢你，你能不能接受我？"
✅ "我..."
   他顿了顿。
   "算了，没什么。"
   "你到底想说什么？"
   "我喜..."
   他深吸一口气。
   "我喜欢你。"
```

### 心理描写间接化

```
四种间接化路径：
✅ 用身体反应表达心理（手心全是汗/指甲抠进掌心/腿在抖）
✅ 用动作暗示心理（攥了攥剑柄又松开）
✅ 用对话反衬心理（嘴上说"没事"，手却在抖）
✅ 用环境烘托心理（窗外的阳光很好，她的眼睛很干）

示例（前→后）：
❌ 林风心里很紧张，他握紧了剑柄，额头冒出了汗。
✅ 林风的手心全是汗。
   他攥了攥剑柄，又松开。
   又攥紧。
   "来就来。"
```

### 段落打散前后对比

```
❌ 打散前（AI均匀感）：
林风走进房间，看到一张桌子。桌子上放着一把刀。刀刃上还有血。他拿起刀看了看。刀很沉。他放下刀，走到窗边。窗外正在下雨。

✅ 打散后（人类节奏感）：
林风推开门。
门轴发出一声刺耳的吱呀。
房间里很暗，窗户被封死了。只有一缕阳光从门缝里挤进来，照在地板上。
空气中有一股霉味，混着...血腥？
他的目光落在桌子上。
桌上放着一把刀。
刀刃上还有没干的血。
```

## 自检清单

- [ ] 机械比喻（仿佛/如同/似乎）≤2处
- [ ] "令人XX"句式 ≤1处
- [ ] 连续感叹号 ≤1处
- [ ] 机械转折句（不是A——而是B）≤1处
- [ ] AI腔（弹幕飘过/气氛凝重等）=0处
- [ ] AI高频词替换表中的"必换词"全部替换
- [ ] 对话存在口语化/停顿/打断/重复中至少2种
- [ ] 心理描写采用间接化（身体反应/动作/对话反衬/环境烘托）
- [ ] 段落长度有长短交错，无连续3段等长
- [ ] 朱雀检测AI率 <20%

---

## 适用边界

**适用**：
- AI辅助生成的初稿去痕
- 平台过检（番茄/起点的AI检测）
- 正文润色阶段
- 对话场景与心理描写改造

**不适用**：
- 纯人工创作的高质量初稿（无人味波动问题）
- 文风刻意追求"机械感"的特殊作品（如科幻AI视角）
- 古风/文言文体裁（口语化会破坏文风）
- 标题、文案等非正文内容（结构不同）

**风险提示**：
- 消痕不能过度——过度口语化会降低文学性
- 替换词需符合人物身份与时代背景（古代角色不能用"贼/倍儿"）
- 循环检测建议≤3轮，避免"过度修改综合征"
