# 人物塑造工作流

> **核心定位：** 人物立住，故事才立得住。从主角到龙套的完整人物体系设计，五步标准化流程。
>
> **适用场景：** 新书人物设计、长篇人物体系搭建、人物扁平没记忆点时的优化
>
> **预计耗时：** 极简版0.5-1天，标准版2-3天，深度版3-5天
>
> **核心原则：** 先主角，后配角，再反派；先核心设定，后细节填充；人物要为故事服务。

---

| 阶段 | 名称 | 核心任务 | 产出物 | 预计耗时 | 调用技能卡 |
|:----:|:-----|:---------|:-------|:--------:|:-----------|
| 1 | 主角设计 | 立住全书的灵魂人物 | 主角人物卡（详细版） | 1天 | 001人物五步塑造法、014金手指设计 |
| 2 | 配角配置 | 建立功能完备的配角群 | 主要配角人物卡（3-5个） | 0.5-1天 | 043配角设计专题 |

## 第一阶段：主角设计（立住灵魂）

### 目标
设计一个让读者喜欢、愿意追、能产生代入感的主角。

### 执行步骤

**步骤1：基础设定**
- **身份背景**：
  - 叫什么名字？
  - 多大年纪？
  - 男/女？
  - 出身什么家庭？
  - 什么职业/身份？
  - 生活在什么地方？
- **外在形象**：
  - 长什么样？（不用太细，有特点就行）
  - 身高体型？
  - 穿着风格？
  - 有什么标志性特征？（伤疤、配饰、习惯动作...）

**步骤2：性格设定**
- **核心性格**：
  - 主角最核心的性格特质是什么？（3个以内）
  - 比如：坚韧、善良、聪明、腹黑、搞笑、冷酷...
- **性格优点**：
  - 主角有什么优点？
  - 这些优点怎么帮助TA？
- **性格缺点**：
  - 主角有什么缺点？
  - 这些缺点给TA带来什么麻烦？
  - 缺点很重要，完美的人不真实，没人喜欢
- **性格反差**：
  - 表面上什么样？实际上什么样？
  - 有没有反差萌？
  - 反差让人物更立体、更有趣

**步骤3：目标与动机**
- **表层目标**：
  - 主角一开始想要什么？
  - 比如：报仇、变强、赚钱、找真相、守护某人...
- **深层动机**：
  - 为什么想要这个？
  - 表层目标背后的深层需求是什么？
  - 比如：报仇的背后是渴望亲情，变强的背后是害怕失去...
- **动机越深层，人物越立体
- 读者可能不认同表层目标，但会理解深层动机

**步骤4：金手指/核心能力**
- 主角的金手指是什么？
  - 系统？穿越？异能？功法？神器？智慧？
- 金手指的规则是什么？
  - 能做什么？不能做什么？
  - 怎么升级？有什么代价？
- 金手指和主角性格匹配吗？
  - 腹黑主角配阴谋系金手指？
  - 热血主角配战斗系金手指？
- 参考KC-SKILL-014「金手指设计」

**步骤5：人物底色**
- 主角最让人喜欢的点是什么？
  - 善良？坚韧？聪明？搞笑？真实？
- 主角最让人共情的点是什么？
  - 出身卑微？受过委屈？背负重担？
- 主角的"人性光辉"是什么？
  - 在关键时刻，会做出什么选择？
- 这是读者喜欢主角的根本原因

### 本阶段产出物
- [ ] 主角基础设定（身份、形象）
- [ ] 主角性格设定（优点、缺点、反差）
- [ ] 目标与动机（表层目标 + 深层动机）
- [ ] 金手指/核心能力设计
- [ ] 人物底色（讨人喜欢的根本原因）

### 验收标准
- [ ] 主角有鲜明的性格吗？（不是模糊的"好人"）
- [ ] 主角有缺点吗？（不是完美的圣人）
- [ ] 主角的动机合理吗？（知道TA为什么这么做）
- [ ] 金手指有规则有代价吗？（不是无脑爽）
- [ ] 你喜欢这个主角吗？你愿意追下去吗？

## 第二阶段：配角配置（搭建群像）

### 目标
设计功能完备、各有特色的配角群，衬托主角，丰富故事。

### 执行步骤

**步骤1：功能分类**
- 你需要哪些功能的配角？
  - **导师型**：指引主角、传授能力、提供信息
  - **伙伴型**：和主角一起冒险、并肩作战
  - **对手型**：和主角竞争、亦敌亦友
  - **情感型**：主角的情感寄托、感情线对象
  - **搞笑型**：调节气氛、提供笑点
  - **工具型**：推动剧情、提供信息（但不能太工具人）
- 每种功能需要几个？
- 不要重复功能，每个配角要有独特的作用

**步骤2：主要配角设计（3-5个）**
- 选出最重要的3-5个配角
- 每个配角都要有：
  - 基础设定（身份、形象）
  - 性格特点（要有记忆点）
  - 和主角的关系
  - 在故事中的作用
  - 自己的小目标/小秘密
- 配角不用像主角那么详细，但要有辨识度

**步骤3：配角差异化**
- 配角之间性格要有差异
  - 不能都是一个模子刻出来的
  - 最好有对比、有反差
  - 比如：一个话痨一个沉默，一个冲动一个冷静
- 配角要有自己的故事
  - 不是只围着主角转
  - 有自己的目标、自己的烦恼、自己的成长
- 参考KC-SKILL-043「配角设计专题」

**步骤4：龙套与背景板**
- 不需要每个龙套都设计
- 但重要的龙套（比如经常出现的）要有个名字和一两个特点
- 背景板人物：不用详细设计，但要合理存在
- 不要让读者觉得"世界只有主角和几个配角"

### 本阶段产出物
- [ ] 配角功能清单（需要哪些类型的配角）
- [ ] 主要配角人物卡（3-5个，含基础设定、性格、作用）
- [ ] 配角差异化检查表
- [ ] 重要龙套清单

### 验收标准
- [ ] 每个配角都有独特的功能吗？（不是重复的）
- [ ] 配角性格有差异吗？（不是千人一面）
- [ ] 主要配角有记忆点吗？（读者能记住）
- [ ] 配角不是纯工具人吧？（有自己的思想）
- [ ] 配角群整体和谐吗？（能产生化学反应）

## 第三阶段：反派塑造（设计好对手）

### 目标
设计有魅力、有深度、能给主角造成真正威胁的反派。

### 执行步骤

**步骤1：反派定位**
- 反派是什么类型的？
  - 个人反派？（一个人）
  - 组织反派？（一个势力/组织）
  - 概念反派？（比如命运、规则、灾难）
- 反派在故事中的定位是什么？
  - 最终BOSS？
  - 阶段性反派？
  - 亦正亦邪？
- 反派和主角的核心矛盾是什么？

**步骤2：反派动机**
- 反派为什么这么做？
  - 为了权力？为了财富？为了复仇？为了理想？为了生存？
- 反派的深层动机是什么？
  - 坏也要坏得有道理
  - 不是"我就是坏"，而是"我有我的理由"
- 读者能理解反派吗？（不一定认同，但能理解）
- 最好的反派：觉得自己才是对的

**步骤3：反派魅力**
- 反派有什么魅力点？
  - 实力强？智商高？有个性？长得帅？悲惨过去？
- 反派的"名场面"有哪些？
  - 出场场面？装逼场面？高光时刻？
- 反派有什么反差？
  - 对敌人狠，对自己人好？
  - 表面冷酷，内心有柔软的地方？
- 参考KC-SKILL-042「反派塑造专题」

**步骤4：反派能力/势力**
- 反派有多强？
  - 比主角强多少？
  - 强在哪里？
- 反派有什么势力/资源？
  - 手下有多少人？
  - 掌握什么资源？
  - 有什么底牌？
- 反派的弱点是什么？
  - 没有弱点的反派没意思
  - 弱点要合理，要能被主角利用

**步骤5：反派弧光**
- 反派有成长/变化吗？
  - 从好变坏？
  - 从坏变更坏？
  - 最后洗白？（慎用）
  - 一直坏到底？（但要有层次）
- 反派和主角的对照关系是什么？
  - 就像镜子的两面？
  - 主角是正义版的反派？反派是邪恶版的主角？

### 本阶段产出物
- [ ] 反派定位与类型
- [ ] 反派动机（表层 + 深层）
- [ ] 反派魅力点设计
- [ ] 反派能力/势力设定
- [ ] 反派弧光（如适用）

### 验收标准
- [ ] 反派有合理的动机吗？（不是"我就是坏"）
- [ ] 反派有魅力吗？（读者会喜欢/记住TA）
- [ ] 反派能给主角造成真正的威胁吗？
- [ ] 反派有弱点吗？（不是无敌的）
- [ ] 你觉得这个反派有意思吗？

## 第四阶段：关系网络（产生化学反应）

### 目标
让人物之间不是孤立的，而是形成一张有张力的关系网。

### 执行步骤

**步骤1：关系类型梳理**
- 主角和各个人物的关系是什么？
  - 亲情？友情？爱情？师徒？敌对？利用？
- 配角之间的关系是什么？
  - 朋友？敌人？竞争？合作？暧昧？
- 反派和其他人的关系是什么？
- 把所有重要关系列出来

**步骤2：关系张力设计**
- 好的关系要有张力，不是一潭死水
- 张力来源：
  - **立场冲突**：立场不同，但又有感情
  - **秘密隐瞒**：某人有秘密，影响关系
  - **利益纠葛**：有共同利益，也有利益冲突
  - **性格碰撞**：性格不合，但又不得不在一起
  - **身份差距**：身份悬殊，但产生了交集
- 每段重要关系，都要有至少一个张力点

**步骤3：人物化学反应**
- 哪两个人在一起最有戏？
- 为什么有戏？
  - 性格反差？
  - 关系张力？
  - 对话火花？
- 参考KC-SKILL-040「人物关系化学反应三原则」
  - 性格对冲
  - 利益绑定
  - 互相暴露

**步骤4：人物关系图**
- 画一张人物关系图
- 把主要人物都放上去
- 用线连起来，标注关系类型
- 用不同颜色/线条表示关系强度
- 一目了然，方便写作时参考

### 本阶段产出物
- [ ] 人物关系清单（所有重要关系）
- [ ] 关系张力设计（每段关系的张力点）
- [ ] 化学反应组合（最有戏的人物组合）
- [ ] 人物关系图

### 验收标准
- [ ] 主要人物之间都有关系吗？（不是孤立的）
- [ ] 重要关系有张力吗？（不是一潭死水）
- [ ] 有让人期待的人物互动吗？
- [ ] 关系网合理吗？（符合世界观和人物设定）
- [ ] 你期待看到这些人物互动吗？

## 第五阶段：成长弧光（人物在故事中成长）

### 目标
确保人物在故事中成长变化，而不是一成不变。

### 执行步骤

**步骤1：起点与终点**
- 主角的起点状态是什么？
  - 性格？能力？认知？价值观？
- 主角的终点状态是什么？
  - 性格？能力？认知？价值观？
- 变化是什么？
  - 从什么到什么？
  - 成长了？堕落了？还是在两者之间？

**步骤2：关键转折点**
- 主角人生中有哪些关键转折点？
- 每个转折点发生了什么事？
- 转折点之后，主角有什么变化？
- 转折点要和主线剧情的关键节点对应
- 3-5个主要转折点就够了

**步骤3：成长原因**
- 主角为什么会变化？
  - 经历了什么事？
  - 遇到了什么人？
  - 想通了什么道理？
- 变化要有原因，不能突然就变了
- 变化要循序渐进，不是一蹴而就

**步骤4：其他人物的成长**
- 主要配角有成长吗？
- 反派有成长/变化吗？
- 不是所有人物都要有弧光，但核心人物要有
- 配角的成长不要抢主角的戏

### 本阶段产出物
- [ ] 主角起点与终点状态
- [ ] 关键转折点（3-5个）
- [ ] 成长原因分析
- [ ] 其他主要人物的成长（如适用）

### 验收标准
- [ ] 主角有明显的成长变化吗？
- [ ] 变化有合理的原因吗？（不是突然变了）
- [ ] 成长和剧情同步吗？
- [ ] 变化可信吗？（读者能接受）
- [ ] 成长后的主角，你更喜欢了吗？

## 常见误区

### ❌ 误区1：主角完美无缺
- 长得帅、实力强、智商高、性格好、女人缘好...什么都好
- 结果：太完美，不真实，读者没代入感，也不关心
- 正解：主角要有缺点，要有弱点，要有不完美的地方。真实的人才可爱。

### ❌ 误区2：反派脸谱化
- 反派就是坏，无恶不作，没有理由
- 结果：反派没魅力，没存在感，打赢了也没成就感
- 正解：坏也要坏得有道理、有深度、有魅力。最好的反派，是觉得自己才是对的。

### ❌ 误区3：配角工具人化
- 配角存在的唯一意义就是帮助主角，没有自己的思想和生活
- 结果：配角没灵魂，读者记不住，世界也显得假
- 正解：每个主要配角都要有自己的目标、自己的故事、自己的成长。他们不是围着主角转的卫星，他们也是自己人生的主角。

### ❌ 误区4：人物关系平淡
- 人物之间的关系很简单，就是朋友/敌人，没有张力
- 结果：互动没火花，不好看
- 正解：好的关系要有张力、有反差、有化学反应。立场不同但又有感情，互相利用但又有真情——这样的关系才好看。

### ❌ 误区5：人物从头到尾没变
- 主角从开头到结尾，性格、认知、价值观一点都没变
- 结果：故事像流水账，人物没成长，读者没获得感
- 正解：人物要在故事中成长变化。事件塑造人物，人物推动事件。

## 最后一句话

**人物是故事的灵魂。**

读者可能会忘记具体的剧情，但他们会记住那些鲜活的人物。

**把人写活了，故事就活了。**

> 先立住人，再讲好故事。
