# 代入感六维度

## 核心原则

代入感就是让读者相信"这是真的"——核心在于"真"：细节的真、情感的真、逻辑的真。代入感由六维度构成（身份/目标/情感/行动/代价/成长认同），配合五感联动配置与渐进式恐怖四阶段，让读者从"旁观"升级为"代入"。代入感是所有网文的生死线——没有代入感，再精彩的剧情也无法留住读者。

---

## 操作步骤/公式

### 一、代入感六维度

| 维度 | 核心问题 | 操作方法 | 检验标准 |
|:---:|:------|:------|:------|
| **身份认同** | 读者愿意把自己代入主角吗？ | 主角有缺陷，不完美；身份贴近读者 | 删掉旁白，读者能从对话/行动感受主角性格 |
| **目标认同** | 读者支持主角的目标吗？ | 目标清晰且合理；动机可理解 | 读者能用一句话说清"主角想要什么" |
| **情感认同** | 读者的情感跟随主角吗？ | 让读者先珍视再失去；情感有铺垫 | 失去时读者会心疼 |
| **行动认同** | 读者认可主角的选择吗？ | 即使失败也合理；选择有代价 | 读者觉得"换我我也这么选" |
| **代价认同** | 读者认可主角付出的代价吗？ | 代价必须够大；代价具体可感 | 读者为代价心疼但不觉得不值 |
| **成长认同** | 读者为角色成长骄傲吗？ | 成长必须有迹可循；不能跳级 | 读者能说出"他从___变成了___" |

### 二、六维度落地公式

```
【身份认同】= 主角缺陷 + 反差特征 + 记忆钉
  └─ 公式：身份 + 反差特征 = 一句话记忆点
  └─ 例：一个嘴上说"相信科学"的探灵主播

【目标认同】= 具体目标 + 合理动机 + 个人利益
  └─ 公式：我想要______，因为______
  └─ 例：我想要守住这个账号，因为这是我在这座城市里唯一属于自己的东西

【情感认同】= 先珍视 + 再失去 + 真实反应
  └─ 公式：建立羁绊 → 制造失去 → 真实悲伤（非哭闹）
  └─ 例：悲伤到极致不哭，只是把手机翻过去，屏幕朝下

【行动认同】= 合理选择 + 已知代价 + 性格一致
  └─ 公式：选择符合性格 + 代价已知情 + 失败也合理
  └─ 例：林风放过敌人，不是因为怕，是因为"不想变成和你一样的人"

【代价认同】= 代价够大 + 代价具体 + 代价推动剧情
  └─ 公式：能力越强，代价越大；代价要具体可感
  └─ 例：用一次能力，疼一次，绝不白嫖

【成长认同】= 起点 → 转折 → 终点，每一步有迹可循
  └─ 公式：成长必须分段，不能一步到位
  └─ 例：金手指升级要循序渐进，每次解锁前要"预热"
```

### 三、五感联动配置

**核心原则**：用感官代替说明

| 感官类型 | 神作级标准 | 实现技巧 | 适用场景 |
|:---:|:------|:------|:------|
| **视觉** | 每场景必有 | 细节具体化 | 所有场景 |
| **听觉** | 每场景必有 | 拟声词+通感 | 悬疑/恐怖/日常 |
| **触觉** | 每场景必有 | 比喻具象化 | 战斗/亲密/恐惧 |
| **嗅觉** | 关键场景必有 | 气味即情绪 | 恐怖/回忆/场景建立 |
| **味觉** | 点睛之笔 | 极少用，用必惊艳 | 特殊情境（血腥/苦涩） |
| **第六感** | 灵异场景必有 | 本能反应 | 灵异/危险逼近 |

```
五感配置标准：
  普通场景：≥4种感官
  关键场景：≥5种感官
  灵异场景：5种感官 + 第六感

错误示例（说明式）：
❌ 废弃医院很阴森，有不好的东西。

正确示例（五感式）：
✅ 废弃医院的走廊弥漫着一股混合着消毒水和腐烂的气味。【嗅觉】
   脚步声在空旷的走廊里回荡，像是有人在后面跟着。【听觉】
   墙上的油漆大片剥落，露出底下发霉的石灰。【视觉】
   某一扇门后传来细微的声响——像是指甲划过玻璃。【听觉】
   一阵阴风从背后袭来，后脖颈一阵发凉。【触觉+第六感】
```

### 四、渐进式恐怖四阶段

```
【第一阶段：微异常】
  └─ 异常微小，主角/读者几乎不 notice
  └─ 示例：病床上的人形被子似乎比昨天塌了一点。
  └─ 读者反应：可能是错觉

【第二阶段：明显异常】
  └─ 异常明显，有人开始注意
  └─ 示例：病床上的人形被子消失了，枕头还在原位。
  └─ 读者反应：不对劲

【第三阶段：确认恐怖】
  └─ 异常确认，恐怖感爆发
  └─ 示例：枕头也不见了。床单平整得像从来没人躺过。
          但床单上有一个凹痕——人形的，从头到脚。
  └─ 读者反应：脊背发凉

【第四阶段：终极恐怖】
  └─ 恐怖升级到认知崩溃
  └─ 示例：第二天查房时，那个病人坐在病床上。
  └─ 读者反应：毛骨悚然

设计要点：
- 每阶段间隔足够的"日常"段落（让读者放松）
- 微异常阶段不能太明显（否则失去"微"的意义）
- 确认恐怖阶段必须有"逻辑闭合"（解释前面的异常）
- 终极恐怖阶段必须打破读者最后的心理防线
```

## 模板/示例

### 代入感六维度设计模板

```markdown
【主角代入感设计表】

1. 身份认同
   - 身份：________________
   - 缺陷：________________
   - 反差特征：________________
   - 记忆钉（招牌动作/口头禅）：________________
   - 一句话记忆点：________ + ________ = ________________

2. 目标认同
   - 核心目标：________________
   - 动机：________________
   - 个人利益：________________
   - 公式：我想要______，因为______

3. 情感认同
   - 珍视对象：________________
   - 将失去什么：________________
   - 失去后的真实反应：________________
   - 避免：哭闹/大喊/直接告诉情绪

4. 行动认同
   - 关键选择：________________
   - 已知代价：________________
   - 性格一致性：________________
   - 失败也合理的原因：________________

5. 代价认同
   - 代价内容：________________
   - 代价大小：□小 □中 □大 □极大
   - 代价是否具体可感：________________
   - 代价如何推动剧情：________________

6. 成长认同
   - 起点（卷初状态）：________________
   - 转折（关键节点）：________________
   - 终点（卷末状态）：________________
   - 成长是否有迹可循：________________
```

### 第六感·本能反应描写清单

```
危险直觉清单（直接调用）：
  后脖颈子发凉 → 危险逼近
  胃里翻涌 → 本能厌恶/危险
  腿软/迈不动 → 恐惧本能
  汗毛竖起 → 生命威胁
  牙根发酸 → 不对劲
  心脏漏跳 → 某种感应

五脏神感应描写（修真题材专用）：
  心口一跳一跳 → 心神预警
  肝脏位置发紧 → 肝神警告
  脾胃翻涌 → 脾神不安
  肺叶发紧 → 肺神示警
  肾脏发凉 → 肾神警示
```

### 限制性视角代入感强化

```
三不原则：
  不描写主角不知道的
  不解释主角没验证的
  不预设读者能理解的

感官边界严格遵守：
  主角能感受：________________
  主角不能做：________________
  读者感受：代入主角的无力感

示例（鬼压床）：
  主角能感受：意识清醒、身体不能动
  主角不能做：转头看、尖叫
  读者感受：代入主角的无力感

  沉闷，压抑，几乎要喘不过气来。
  仿佛鬼压床一样，明明意识是清醒的，但是浑身上下却不能动。
  昏暗的房间此刻仿佛变成了一个黑暗的囚笼。
```

## 自检清单

### 六维度自检
- [ ] **身份认同**：主角是否有缺陷？是否有反差特征？删掉旁白还能感受性格吗？
- [ ] **目标认同**：目标是否清晰？动机是否合理？读者能用一句话说清吗？
- [ ] **情感认同**：失去前是否有珍视铺垫？失去后是否真实反应（非哭闹）？
- [ ] **行动认同**：选择是否符合性格？代价是否已知？失败是否也合理？
- [ ] **代价认同**：代价是否够大？是否具体可感？是否推动剧情？
- [ ] **成长认同**：成长是否有迹可循？是否能说出"从___变成___"？

### 五感自检
- [ ] 普通场景是否≥4种感官？
- [ ] 关键场景是否≥5种感官？
- [ ] 灵异场景是否有第六感？
- [ ] 是否用感官代替说明？（无"很阴森/很恐怖"等直接告诉）
- [ ] 视觉细节是否具体化？（不是"一双眼睛"而是"没有眼白，只有两个黑洞"）

### 渐进式恐怖自检
- [ ] 微异常阶段是否足够"微"？
- [ ] 明显异常阶段是否有人注意到？
- [ ] 确认恐怖阶段是否逻辑闭合？
- [ ] 终极恐怖阶段是否打破心理防线？
- [ ] 各阶段之间是否有"日常"缓冲？

### 视角自检
- [ ] 是否遵守"三不原则"？
- [ ] 是否严格保持限制性视角？
- [ ] 是否避免上帝视角剧透？

## 适用边界

**适用**：
- 所有网文的代入感构建
- 恐怖/悬疑/灵异题材（五感+渐进式恐怖是核心）
- 修真/玄幻题材（代价认同+成长认同是关键）
- 都市/现实题材（身份认同+目标认同是基础）
- 主角视角叙事（限制性视角代入最强）

**不适用**：
- 群像叙事（多视角分散代入感）
- 上帝视角叙事（信息差不产生代入）
- 番外/支线视角（主角不在场，代入感转移）
- 纯设定输出段（无人物，无代入对象）

**题材侧重调整**：
- 恐怖题材：强化五感+渐进式恐怖，弱化成长认同
- 修真题材：强化代价认同+成长认同，五感可适度简化
- 都市题材：强化身份认同+目标认同，渐进式恐怖不适用
- 言情题材：强化情感认同+行动认同，第六感不适用

**风险提示**：
- 五感描写不能堆砌（每场景≤5种，过多会让读者疲劳）
- 渐进式恐怖四阶段不能压缩（必须给读者足够反应时间）
- 代入感不能靠"告诉"（"你应该为他难过"是反代入）
- 限制性视角不能破坏（偶尔切视角会瞬间打破代入）
