# KC-SKILL-239 · 人物外貌与气质描写方法论

> **核心定位：** L3专业方法论——小说人物外貌与气质描写方法论。核心是教作者如何用文学语言写出有辨识度、有画面感、有气质的人物，漫剧适配只是副产品。
>
> **适用范围：** 网文创作、人物外貌描写、气质塑造、角色辨识度提升、漫改剧改前期文字基础。

---

## ⚠️ 正文纯净化铁律

> **这是写作引擎的红线，违反即输出不合格。**

- 正文中**绝对不能**出现"建模参数""3D""头身比（数字）""色号""RGB"等工业化描述
- 所有视觉元素必须转化为**文学描写**——用比喻、感受、氛围代替参数
- 本方法论提供的"脸型/体型/瞳色"等分类体系，是帮助作者建立**清晰的内心图像**，不是让你把参数写进正文
- 正确做法：你心里知道TA是"7.5头身鹅蛋脸桃花眼"，但写出来是"身段修长，面庞温润如画，眼波流转间似有笑意"

---

## 边界声明：写作引擎只做什么

### 写作引擎做的事
- 教你把人物外貌写得**有辨识度**——读者看完能在脑子里画出一个清晰的人
- 教你把人物外貌写得**有画面感**——寥寥几笔就能营造出强烈的视觉印象
- 教你把人物外貌写得**有气质**——外貌不是目的，气质才是灵魂，皮相为性格服务

### 写作引擎不做的事
- 不做3D建模——那是美术引擎的工作
- 不做骨骼绑定——那是动画师的工作
- 不做材质渲染——那是特效师的工作

### 正确的协作方式
1. **作者**用文学语言写好外貌描写 → 读者脑子里有画面
2. **美术师**从文学描写 + 元数据中提取视觉元素 → 建模/立绘
3. 文学描写是"灵魂"，美术建模是"皮囊"——灵魂立住了，皮囊才不会空洞

## 一、核心原则：人设即符号系统

> 读者/观众记住一个角色，不是记住TA的全部细节，而是记住TA的**视觉符号**。
> 好的美型人设，是一套可拆解、可复用、可识别的视觉符号系统。

### 1.1 美型人设三大黄金法则

**法则一：记忆点密度法则**
```
角色记忆度 = 核心符号数量 × 符号独特性 × 符号重复曝光率
```
- 核心符号控制在3-5个：太多记不住，太少没辨识度
- 每个符号必须独特：不能是"黑长直"这种烂大街的
- 符号要反复出现：发型、配饰、武器、动作模式都要呼应

**法则二：视觉统一法则**
- 所有视觉元素（脸型、五官、发型、服饰、体型）必须指向**同一个气质核心**
- 不能"脸是清冷的，衣服是妖艳的，动作是憨厚的"——分裂的人设没人记得住
- 允许有1个**反差元素**，但必须有合理解释

**法则三：漫剧适配法则**
- 简化细节：动画/漫画要能画得出来，太复杂的细节会被省略
- 剪影识别：遮住脸只看剪影，能认出是谁吗？
- 表情可拓展：五官结构要能支撑至少10种表情，不能"面瘫脸"

### 1.2 人设视觉层级金字塔

```
第5层：标志性动作/微表情    ← 灵魂层，最难模仿
    ↑
第4层：气质锚点系统          ← 感觉层，读者/观众"说不出但感受得到"
    ↑
第3层：服饰/配饰/武器        ← 符号层，一眼可识别
    ↑
第2层：发型/五官/脸型        ← 特征层，区分度核心
    ↑
第1层：体型/头身比/肤色      ← 基础层，第一印象
```

> **设计顺序：从上往下设计（先定气质，再定外形），从下往上落地（先画体型，再加细节）。**

### 2.2 四大参考系选择决策树

```
你的故事是什么题材？
    │
    ├─ 东方玄幻/修真/仙侠 ──→ 玄机科技3D国漫风
    │
    ├─ 西方奇幻/现代/校园 ──→ 原神崩铁二次元风
    │
    ├─ 科幻/赛博朋克/未来 ──→ 虚环写实科幻风
    │
    └─ 末世/异能/战术/悬疑 ──→ 明日方舟插画风
```

> **混搭技巧：** 可以70%主风格 + 30%次风格，但主次必须分明。
> 例如：70%原神风 + 30%明日方舟风 = 二次元末世风

### 2.3 参考系迁移适配公式

```
新风格人设 = 核心气质保留 + 基础层替换（体型/肤色）+ 特征层重构（脸型/五官）+ 符号层适配（发型/服饰）
```

**示例：把一个"清冷剑仙"从玄机风迁到明日方舟风**
- 保留：清冷气质、剑的核心符号
- 替换：肤色从暖白→苍白，体型从飘逸→干练
- 重构：脸型从鹅蛋脸→菱形脸，眼睛从丹凤眼→细长吊梢眼
- 适配：长发束发→短发挑染，古风长袍→风衣+战术腰带，长剑→战术刀+源石技艺

## 三、年龄与外貌不一致的设计策略

### 3.1 错位美学的核心价值

> 年龄错位是制造**角色深度**和**记忆点**的最强手段之一。
> 外表和实际的差距越大，角色的故事感越强。

**错位美学公式：**
```
角色吸引力 = |实际年龄 - 外表年龄| × 错位合理性 × 性格与外表反差度
```

### 3.2 六种经典错位类型

| 错位类型 | 外表年龄 | 实际年龄 | 核心魅力 | 设计要点 | 代表角色 |
|:---------|:---------|:---------|:---------|:---------|:---------|
| **萝莉身御姐心** | 8-12岁 | 25-40岁 | 反差萌、成熟感、可靠 | 眼睛要成熟（眼神光沉稳），动作要稳重，服装要精致但不幼稚 | 康娜（小林家的龙女仆）、灰原哀 |
| **少年脸沧桑心** | 15-18岁 | 30-50岁 | 心疼感、神秘感、成熟 | 眼下阴影/眼袋，眼神深邃，偶尔流露出疲惫，身形偏瘦 | 金木研（东京喰种）、夏尔（黑执事） |
| **大叔身少年眼** | 40-50岁 | 18-25岁 | 反差萌、纯真感、热血 | 眼睛要亮、要圆，笑容要灿烂，体型可以壮但动作要灵活 | 毛利小五郎（柯南）、奎爷（新战神） |
| **御姐身少女心** | 25-30岁 | 15-18岁 | 反差萌、可爱感、娇羞 | 表情要丰富，会害羞，喜欢可爱的东西，体型可以成熟但行为要少女 | 八重神子（原神）、涂山雅雅 |
| **老人身青年态** | 60-80岁 | 20-30岁 | 神秘感、强大感、沧桑 | 身形挺拔，动作矫健，眼神锐利，只有头发/皱纹暴露年龄 | 张三丰、老天师 |
| **孩童身智者魂** | 6-10岁 | 50-100岁 | 智慧感、反差萌、可靠 | 眼神平静深邃，说话慢条斯理，动作从容，喜欢抚摸胡须（即使没有） | 柯南、一休 |

### 3.3 错位设计操作步骤

**Step 1：确定错位方向**
- 先定实际年龄（决定角色的行为模式、价值观、能力水平）
- 再定外表年龄（决定角色的视觉第一印象）
- 错位方向：外表 < 实际（幼化） or 外表 > 实际（老化）

**Step 2：设计年龄特征**
- **幼化特征**：圆脸、大眼睛、小鼻子小嘴、身材娇小、皮肤光滑
- **老化特征**：方脸/长脸、细长眼、高鼻梁、薄唇、皱纹、眼袋、白发

**Step 3：制造冲突点**
- 选1-2个"暴露真实年龄"的细节（眼神、语气、习惯动作）
- 选1-2个"强化外表年龄"的细节（装扮、喜好、说话方式）
- 冲突越强烈，角色越有魅力

**Step 4：给出合理解释**
- 为什么会错位？（诅咒/修炼/实验/种族特性/穿越/重生/返老还童）
- 解释不需要太复杂，但必须自洽

| 脸型 | 气质倾向 | 适用角色类型 | 性别适配 | 代表角色 | 设计要点 |
|:-----|:---------|:-------------|:---------|:---------|:---------|
| **鹅蛋脸** | 温婉、端庄、大气 | 女主、大家闺秀、正派掌门、仙女 | 女为主，男也可 | 唐三（斗罗）、陆雪琪 | 线条流畅，额头与下巴宽度比例协调，最"安全"的美型脸 |
| **瓜子脸** | 精致、清冷、妖艳 | 冰山美人、反派女、狐狸精、杀手 | 女为主 | 涂山红红、少司命 | 下巴尖但不能太尖（蛇精脸避雷），颧骨略高，小巧精致 |
| **娃娃脸** | 可爱、纯真、幼态 | 萝莉、正太、萌系角色、开心果 | 男女皆可 | 柯南、小乔 | 脸颊饱满有肉，下巴圆，眼睛大，显年轻5-10岁 |
| **方脸** | 刚毅、稳重、威严 | 将军、帝王、硬汉、正派大叔 | 男为主，女则飒 | 项羽、张起灵 | 下颌线清晰硬朗，腮骨明显，给人可靠、有力量感 |
| **长脸** | 冷峻、疏离、智慧 | 谋士、高冷角色、禁欲系、反派 | 男为主 | 张良、宇智波鼬 | 脸长大于宽的1.5倍，五官分布舒展，显成熟 |

| **心形脸** | 甜美、温柔、亲切 | 邻家女孩、甜妹、治愈系 | 女为主 | 小昭、聂怀桑（少年） | 额头宽下巴尖，像倒心形，亲和力最强 |

### 4.3 脸型选择决策矩阵

| 角色定位 ↓ / 性别 → | 男性角色 | 女性角色 |
|:-------------------|:---------|:---------|
| **正派主角** | 鹅蛋脸/方脸 | 鹅蛋脸/心形脸 |
| **高冷角色** | 长脸/菱形脸 | 瓜子脸/菱形脸 |
| **可爱角色** | 娃娃脸 | 娃娃脸/心形脸 |
| **威严角色** | 方脸/长脸 | 方脸（女强） |
| **妖艳/魅惑** | 菱形脸/瓜子脸 | 瓜子脸/菱形脸 |
| **反派角色** | 长脸/菱形脸 | 瓜子脸/长脸 |
| **憨厚/可靠** | 方脸/娃娃脸 | 娃娃脸/鹅蛋脸 |

### 4.4 脸型与五官比例规范

**三庭五眼原则（美型基础）：**
```
三庭：发际线→眉弓 = 眉弓→鼻底 = 鼻底→下巴尖 （各占1/3）
五眼：脸的宽度 = 5只眼睛的宽度
     两眼间距 = 1只眼睛的宽度
     外眼角到脸侧 = 1只眼睛的宽度
```

**漫剧美化调整：**
- 眼睛可以放大到正常的1.2-1.5倍（二次元风可到2倍）
- 下巴可以略尖0.1-0.2倍（但不能超过鼻子宽度的1.5倍）
- 鼻子可以略缩短，中庭略短显年轻，中庭略长显成熟

## 五、体型美学：5种主流体型 + 头身比规范

### 5.1 五种主流体型对比

| 体型 | 别称 | 特征描述 | 气质倾向 | 适用角色 | 头身比推荐 |
|:-----|:-----|:---------|:---------|:---------|:-----------|
| **沙漏型** | X型 | 肩宽=臀宽，腰细，曲线明显 | 性感、成熟、妩媚 | 御姐、女王、妖女、舞姬 | 8头身（女） |
| **倒三角** | Y型/V型 | 肩宽>臀宽，上宽下窄 | 力量感、威严、安全感 | 将军、战士、肌肉男、霸总 | 8-8.5头身（男） |
| **直筒型** | H型 | 肩宽≈臀宽，腰不明显，线条直 | 干练、清爽、少年感 | 学生、少年、禁欲系、职场人 | 7.5-8头身 |
| **圆润型** | O型 | 整体圆润，有肉感，曲线柔和 | 可爱、亲切、憨厚 | 胖哥、萌妹、吃货、开心果 | 7-7.5头身 |
| **纤瘦型** | I型 | 整体瘦削，骨感，肩窄臀窄 | 清冷、疏离、病态、脆弱 | 病娇、弱受、谋士、隐士 | 8-8.5头身（显高） |

### 5.2 头身比规范体系

| 头身比 | 风格定位 | 适用场景 | 视觉效果 | 注意事项 |
|:-------|:---------|:---------|:---------|:---------|
| **6.5头身** | Q版/萌系 | 搞笑番、Q版小人、表情包 | 可爱、幼态、亲和 | 手脚要短，头要圆 |
| **7头身** | 少年/少女风 | 校园、青春、少年向 | 年轻、活力、青涩 | 四肢略短，显小 |
| **7.5头身** | 标准美型 | 大多数漫剧/游戏 | 匀称、自然、好看 | 最通用的比例 |
| **8头身** | 理想美型 | 帅哥美女、主角团 | 修长、精致、完美 | 主流美型标准 |
| **8.5头身** | 修长型 | 模特、霸总、高挑角色 | 挺拔、气场、大长腿 | 腿长比例要注意 |
| **9头身** | 超修长/写实 | 时装画、超写实、特定角色 | 极致修长、超现实 | 容易失真，慎用 |

### 5.3 体型与角色力量感的关系

**力量感视觉公式：**
```
力量感 = 肩宽 / 头宽 × 肌肉明显度 × 体脂率的反向
```

**不同类型角色的体型参数：**

| 角色类型 | 肩宽（头宽倍数） | 体脂率感觉 | 肌肉感 |
|:---------|:----------------|:-----------|:-------|
| 柔弱书生/病娇 | 1.8-2.0 | 低（瘦） | 无 |
| 普通少年/少女 | 2.0-2.2 | 正常 | 微 |
| 训练有素战士 | 2.3-2.5 | 低（肌肉） | 明显 |
| 肌肉猛男/力士 | 2.5-3.0 | 低（健美） | 非常明显 |
| 胖哥/圆润型 | 2.2-2.4 | 高（胖） | 隐藏 |

### 5.4 体型差异化设计技巧

**避免"所有角色都是同一种体型"的方法：**

1. **主角团体型差异化配置**
   - 队长：倒三角（力量感、领导力）
   - 军师/智慧担当：纤瘦型（聪明感、疏离感）
   - 刺客/敏捷型：直筒型（干练、灵活）
   - 力量担当：倒三角/圆润型（力量感、憨厚）
   - 颜值担当：沙漏型/标准型（美型、养眼）

2. **体型与性格的呼应**
   - 急性子：肌肉紧实、动作幅度大
   - 慢性子：肌肉放松、动作幅度小
   - 严谨的人：站姿挺拔、衣服整齐
   - 随性的人：站姿放松、衣服随意

**原则二：运动可行性原则**

- 长发角色要有合理的束发方式（否则打架时挡眼睛）

**原则三：发质暗示原则**
- 头发柔顺有光泽：养尊处优、性格温和
- 头发毛躁/炸毛：性格暴躁、生活粗糙
- 头发一丝不苟：严谨、洁癖、强迫症
- 头发乱翘/睡乱：随性、邋遢、天然呆

## 八、服饰模块化设计逻辑

### 8.1 服饰四层模块化结构

```
第4层：武器挂载点/特殊装备    ← 功能层，战斗/职业相关
    ↑
第3层：配饰/装饰              ← 符号层，个性/身份识别
    ↑
第2层：外层服装               ← 风格层，整体风格定位
    ↑
第1层：内层服装/基底          ← 基础层，舒适/实用
```

### 8.2 各层设计要点

**第1层：内层服装（基底）**
- 功能：贴身、舒适、保护
- 常见款式：紧身衣、衬衫、T恤、亵衣、肚兜
- 设计要点：尽量简洁，不要抢外层的风头
- 颜色：黑、白、灰、肤色等中性色为主

**第2层：外层服装（风格层）**
- 功能：表达风格、身份、地位
- 常见款式：长袍、风衣、外套、裙子、甲胄
- 设计要点：这是**最能体现风格**的一层，要重点设计
- 颜色：主色调+辅助色，控制在2-3种颜色以内

**第3层：配饰（符号层）**
- 功能：增加辨识度、表达个性、身份象征
- 常见配饰：
  - 颈部：项链、吊坠、围巾、领结、choker
  - 手部：手套、戒指、手镯、护腕
  - 腰部：腰带、腰封、玉佩、荷包
  - 头部：发饰、眼镜、耳环、头饰
- 设计要点：选2-3个重点配饰，不要全身挂满

**第4层：武器挂载点（功能层）**
- 功能：武器收纳、工具携带
- 常见挂载点：
  - 背部：剑、刀、弓、翅膀
  - 腰部：佩剑、匕首、药瓶、钱袋
  - 腿部：匕首、枪套、护腿
  - 手臂：臂甲、暗器、护腕
- 设计要点：挂载位置要合理，符合人体工学，方便取用

### 8.3 服饰风格与角色类型匹配

| 风格类型 | 核心元素 | 适用角色 | 色彩方案 |
|:---------|:---------|:---------|:---------|
| **古风仙侠** | 长袍、广袖、飘带、玉佩、发冠 | 修士、仙人、侠客 | 低饱和、渐变色、单色为主 |
| **都市现代** | 西装、卫衣、牛仔裤、风衣、制服 | 学生、上班族、都市人 | 日常色、黑白灰、流行色 |
| **科幻未来** | 紧身衣、机甲、义体、发光条、面罩 | 机器人、战士、赛博朋克 | 金属色、霓虹色、黑色为主 |
| **西式奇幻** | 斗篷、铠甲、法杖、尖帽、长袍 | 法师、战士、精灵、骑士 | 主题色、对比色、金属装饰 |
| **末世废土** | 风衣、面罩、护目镜、绷带、战术装备 | 拾荒者、战士、幸存者 | 大地色、军绿色、做旧感 |
| **学院制服** | 校服、西装、领带、格裙、水手服 | 学生、学院角色 | 藏青、灰白、格纹 |

### 8.4 服饰设计五要素

**要素一：主题色**
- 每个角色要有1个**主色调**（占60-70%）
- 1-2个辅助色（占20-30%）
- 1个点缀色（占5-10%）
- 颜色总数控制在3-4种以内

**要素二：材质对比**
- 软硬对比：硬甲 vs 软布
- 光泽对比：哑光 vs 亮面/金属
- 厚薄对比：厚重 vs 轻薄
- 层次对比：多层叠穿 vs 单层

**要素三：文化符号**
- 中式：盘扣、云纹、龙凤、水墨、书法
- 西式：十字架、纹章、蕾丝、蝴蝶结
- 科幻：电路板、机械结构、发光线条
- 原始：兽皮、骨头、羽毛、图腾

**要素四：职业特征**
- 战士：护甲、武器、手套、靴子
- 法师：长袍、法杖、吊坠、符文
- 刺客：紧身衣、兜帽、暗器、面罩
- 医者：白大褂、药箱、手套、口罩

**要素五：社会阶层**
- 上层：面料精致、装饰华丽、颜色鲜艳
- 中层：面料普通、简洁大方、颜色日常
- 下层：面料粗糙、有补丁、颜色暗淡

| **慵懒** | 闲散、随性、提不起劲 | 鹅蛋脸/娃娃脸 | 半睁眼、眼神迷离 | 直筒型/圆润型 | 宽松舒适、质感好 | 打哈欠、伸懒腰、靠东西 | 米白、浅棕、灰蓝 |
| **凌厉** | 尖锐、好斗、像一把刀 | 菱形脸/长脸 | 吊梢眼、眼神凶狠 | 倒三角/纤瘦型 | 紧身/利落、黑色为主 | 站姿挺拔、手握拳、下巴微抬 | 纯黑、血红、银白 |
| **温柔** | 温暖、治愈、让人安心 | 鹅蛋脸/心形脸 | 杏眼/下垂眼、眼神柔和 | 沙漏型/直筒型 | 暖色调、柔软材质 | 微笑、轻声说话、手放身前 | 米黄、粉红、浅绿 |
| **颓废** | 疲惫、消沉、没精神 | 长脸/娃娃脸 | 眼下阴影、眼神涣散 | 纤瘦型 |  oversized、有褶皱、深色 | 驼背、插兜、走路慢 | 灰黑、暗紫、墨绿 |
| **圣洁** | 神圣、纯净、不可侵犯 | 鹅蛋脸 | 金色瞳/清澈眼、眼神悲悯 | 直筒型/沙漏型 | 白色/金色、长袍、光环 | 双手合十、抬头望天、脚步轻 | 纯白、亮金、浅蓝 |

### 9.2 气质锚点设计法

**Step 1：确定主气质（70%）**
- 从10种核心气质中选1个作为主气质
- 这是角色给人的第一印象

**Step 2：确定副气质（20%）**
- 再选1个作为副气质，增加层次感
- 例如：清冷 + 温柔 = 外冷内热
- 例如：威严 + 慵懒 = 佛系大佬

**Step 3：确定隐藏气质（10%）**
- 平时不明显，特定条件下才暴露
- 例如：憨厚的人黑化后很凌厉
- 例如：温柔的人发怒很威严

**Step 4：分配视觉元素**
- 70%的视觉元素指向主气质
- 20%指向副气质
- 10%隐藏气质只在细节中暗示

## 十、微表情库：5个固定微表情锚点

### 10.1 为什么需要固定微表情？

> 动画师/画手容易"画着画着就OOC"。
> 给每个角色设定5个固定微表情锚点，确保**人设不崩**。

**微表情锚点的作用：**
- 统一不同画师/动画师的理解
- 增加角色辨识度（"这个表情只有TA会做"）
- 强化性格特征
- 方便观众记住角色

### 10.2 微表情锚点设计五维

| 维度 | 说明 | 可选方向 |
|:-----|:-----|:---------|
| **眉毛动势** | 眉毛的运动方式 | 挑眉/皱眉/八字眉/挑眉尾/一边高一边低 |
| **眼睛状态** | 眼睛的开合与神态 | 眯眼/瞪眼/半睁眼/眼尾上挑/下垂 |
| **嘴部形态** | 嘴的形状与位置 | 撇嘴/抿嘴/歪嘴笑/咬唇/虎牙露出 |
| **脸部肌肉** | 其他面部特征 | 鼓腮/脸红/青筋/汗滴/阴影 |
| **附加小动作** | 配合表情的小动作 | 推眼镜/撩头发/托下巴/挠头/抱胸 |

### 10.3 微表情锚点模板（每角色5个）

**锚点1：日常放松表情**
- 最常见的状态，角色的"默认脸"
- 例如：温柔角色的"平静微笑"，高冷角色的"面无表情"

**锚点2：开心/满意表情**
- 遇到好事、达成目标时的表情
- 例如：狡黠角色的"计划通坏笑"，憨厚角色的"傻笑露齿"

**锚点3：思考/疑惑表情**
- 想问题、拿不定主意时的表情
- 例如：智者角色的"扶眼镜+眯眼"，天然角色的"歪头+眨眼"

**锚点4：生气/认真表情**
- 发怒、进入战斗状态时的表情
- 例如：老好人角色的"青筋暴起+沉默"，暴躁角色的"瞪眼+咬牙"

**锚点5：害羞/尴尬表情**
- 被夸、被戳中软肋时的表情
- 例如：傲娇角色的"转头+脸红+嘴硬"，开朗角色的"挠头+干笑"

|:---------|:---------|:---------|:---------|:---------|:---------|

## 十一、标志性动作：3个专属动作设计

### 11.1 标志性动作的价值

> 当读者看到这个动作，立刻想到这个角色。
> 这是比脸更深刻的记忆点。

**标志性动作三大功能：**
1. **识别功能**：增加角色辨识度
2. **性格功能**：强化角色性格
3. **情绪功能**：表达特定情绪状态

### 11.2 标志性动作设计三维

| 维度 | 说明 | 示例 |
|:-----|:-----|:-----|
| **触发场景** | 什么情况下会做这个动作 | 思考时、紧张时、开心时、装酷时 |
| **身体部位** | 主要用哪个部位做动作 | 手、头、肩、腰、腿、全身 |
| **动作含义** | 这个动作表达什么情绪/性格 | 自信、紧张、思考、害羞、不屑 |

### 11.3 标志性动作模板（每角色3个）

**动作1：思考/习惯性动作**
- 角色思考、走神、放松时会下意识做的动作
- 最常用，出现频率最高
- 例如：推眼镜、摸下巴、绕头发、转笔、敲手指

**动作2：装酷/标志性pose**
- 角色耍帅、出场、放狠话时的标志性姿势
- 最有辨识度，读者一看到就"哦是TA"
- 例如：单手插兜、交叉抱胸、扶剑、挑眉、转身

**动作3：情绪爆发动作**
- 角色情绪激动（开心/生气/害羞）时的特殊动作
- 强化情绪表达，增加感染力
- 例如：开心时跳起来、生气时攥拳、害羞时捂脸

## 十二、设计原则总纲

### 12.1 十大设计原则

**原则一：符号化原则**
- 人设 = 符号集合
- 每个视觉元素都要有意义，不要为了好看而乱加

**原则二：统一性原则**
- 所有视觉元素指向同一个气质核心
- 风格统一、颜色统一、材质统一

**原则三：辨识度原则**
- 剪影识别：遮住脸能认出
- 颜色识别：只看色块能认出
- 动作识别：只看动作能认出

**原则四：差异化原则**
- 主角团每个人都要不一样
- 脸型、发型、体型、气质至少有2个维度不同

**原则五：层次感原则**
- 主气质70% + 副气质20% + 隐藏气质10%
- 表层性格 + 深层性格 + 底色性格

**原则六：故事性原则**
- 每个特征都有故事
- 疤痕怎么来的？为什么喜欢这个颜色？为什么总是这个姿势？

**原则七：可动性原则**
- 发型和衣服要考虑动起来怎么样
- 不能设计得太复杂，动画师画不出来

**原则八：适配性原则**
- 根据目标平台/风格调整细节
- 漫画可以细一点，动画要简化，3D要考虑面数

**原则九：成长性原则**
- 人设要预留成长空间
- 前期和后期可以有变化（服装、发型、气质）

**原则十：记忆点原则**
- 控制在3-5个核心记忆点
- 多了记不住，少了没特点

### 12.2 美型人设公式

```
美型人设 = 
  基础层（体型+头身比+肤色）  →  第一印象
+ 特征层（脸型+五官+发型）    →  辨识度核心
+ 符号层（服饰+配饰+武器）    →  风格与身份
+ 气质层（表情+动作+神态）    →  灵魂与性格
```

## 十三、操作步骤：从零开始设计一个漫剧人设

### Step 1：定位——确定角色基本盘

**1.1 确定角色定位**
- 角色在故事中的功能：主角/配角/反派/路人？
- 角色的核心性格：用3个关键词描述
- 角色的核心气质：从10种核心气质中选主+副

**1.2 确定风格参考系**
- 选择四大参考系之一（或混搭）
- 确定整体美术风格

**1.3 输出：角色定位卡**
```
角色名：
角色定位：（主角/配角/反派...）
核心性格：[关键词1] [关键词2] [关键词3]
主气质：
副气质：
隐藏气质：
参考风格：
```

### Step 2：基础层——体型与头身比

**2.1 选择题型**
- 从5种体型中选1种
- 确定头身比（7/7.5/8/8.5头身）
- 确定身高范围

**2.2 选择肤色**
- 冷白/暖白/自然/小麦/古铜/苍白
- 考虑角色的生活环境（室内/室外/地下/太空）

**2.3 输出：体型参数卡**
```
体型类型：
头身比：
身高：
肤色：
体型特点：（肩宽、腰细、肌肉感...）
```

### Step 3：特征层——脸型与五官

**3.1 选择脸型**
- 从7种脸型中选1种
- 考虑年龄感（圆脸显小，长脸显成熟）

**3.2 设计五官**
- 眼睛：形状 + 瞳色 + 眼神光
- 眉毛：形状 + 颜色
- 鼻子：类型
- 嘴唇：形状 + 唇色

**3.3 加入个性标记**
- 选1-2个五官个性标记（泪痣、疤痕、眼镜...）

**3.4 输出：面部特征卡**
```
脸型：
眼睛：（形状+瞳色+眼神特点）
眉毛：
鼻子：
嘴唇：
个性标记：
```

### Step 4：发型层——发型设计

**4.1 确定发型长度与造型**
- 长度：极短/短/中长/长/超长

**4.2 确定发色**
- 主发色
- 是否有挑染/渐变色

**4.3 选择发饰**
- 1-2个发饰

**4.4 输出：发型设计卡**
```
发型长度：
发型造型：
发色：
发质特点：（柔顺/毛躁/蓬松...）
发饰：
```

### Step 5：符号层——服饰与配饰

**5.1 设计内层服装**
- 款式 + 颜色

**5.2 设计外层服装**
- 款式 + 主色调 + 辅助色 + 点缀色
- 材质说明

**5.3 选择配饰**
- 颈部、手部、腰部各选0-1个

**5.4 设计武器挂载点**
- 武器类型 + 挂载位置

**5.5 输出：服饰设计卡**
```

挂载位置：
```

### Step 6：气质层——表情与动作

**6.1 设定5个微表情锚点**
- 日常表情
- 开心表情
- 思考表情
- 生气表情
- 害羞表情

**6.2 设定3个标志性动作**
- 思考习惯动作
- 装酷标志性pose

  2. 开心：

  1. 思考动作：
  2. 装酷动作：
  3. 情绪爆发动作：

## 十四、避坑指南：人设设计二十大雷区

### ❌ 雷区1：记忆点过载
- 问题：身上挂满了饰品、发型超复杂、颜色五颜六色
- 后果：读者记不住，动画师画到崩溃
- 正解：3-5个核心记忆点就够了，少即是多

### ❌ 雷区2：风格混乱
- 问题：古风脸+现代衣服+科幻武器，什么元素都想加
- 后果：违和感强烈，不知道是什么题材
- 正解：70%主风格 + 30%次风格，主次分明

### ❌ 雷区3：全员帅哥美女
- 问题：主角团全是8头身完美脸型，分不清谁是谁
- 后果：辨识度为0，读者脸盲
- 正解：角色要有差异化，美也要美得不一样

### ❌ 雷区4：只有正面没有负面
- 问题：角色太完美，没有任何瑕疵
- 后果：不真实，没有代入感
- 正解：给角色加1-2个外貌小瑕疵（疤痕、小雀斑、虎牙...）

### ❌ 雷区5：服饰不符合身份
- 问题：穷人穿得比富人还华丽，战士穿长裙打架
- 后果：违和感出戏，不符合世界观
- 正解：服饰要符合角色的身份、职业、经济状况

### ❌ 雷区6：发型不考虑实用性
- 问题：战斗角色留及地长发，还总是披散着
- 后果：不合理，打架时不挡眼睛吗？
- 正解：战斗角色要有束发/扎发的设定，长发也要有合理的处理方式

### ❌ 雷区7：颜色太多太杂
- 问题：全身彩虹色，超过4种主色
- 后果：视觉混乱，廉价感
- 正解：主色1个 + 辅助色1-2个 + 点缀色1个，控制在4色以内

### ❌ 雷区8：气质分裂
- 问题：脸是清冷的，衣服是妖艳的，动作是憨厚的
- 后果：角色精神分裂，读者看不懂
- 正解：所有视觉元素指向同一个气质核心，反差只能有1个

### ❌ 雷区9：忽略剪影识别
- 问题：遮住脸就认不出是谁了
- 后果：辨识度太低
- 正解：设计完后做剪影测试，确保能认出

### ❌ 雷区10：五官比例失调
- 问题：眼睛太大占了半张脸，下巴尖得能戳死人
- 后果：蛇精脸/外星人感，不舒服
- 正解：遵循三庭五眼基础上美化，不要过度

### ❌ 雷区11：头身比失衡
- 问题：9头身腿太长显得不协调，或者6头身画成年人
- 后果：怪异感
- 正解：成年人7.5-8头身最安全，特殊角色特殊处理

### ❌ 雷区12：忽视性别差异
- 问题：男女角色除了头发和胸部都一样
- 后果：性别模糊（除非刻意设计）
- 正解：男性肩宽、下颌线明显；女性肩窄、线条柔和

### ❌ 雷区13：配饰无意义
- 问题：为了好看乱加配饰，跟角色身份没关系
- 后果：虚假感
- 正解：每个配饰都要有它的功能或故事

### ❌ 雷区14：武器与体型不匹配
- 问题：纤瘦小萝莉扛着比人还大的巨锤（除非有特殊设定）
- 后果：违和感
- 正解：武器大小重量要和体型力量匹配，特殊情况要给解释

### ❌ 雷区15：表情单一
- 问题：角色永远一个表情，像面瘫
- 后果：没有感染力，像机器人
- 正解：设定5个微表情锚点，确保表情丰富

### ❌ 雷区16：动作没有特点
- 问题：所有角色动作都一样，没有个人特色
- 后果：辨识度低
- 正解：每个角色3个标志性动作

### ❌ 雷区17：设计完不检验
- 问题：设计完就完事了，不测试能不能被认出
- 后果：可能有问题但发现不了
- 正解：用自检清单逐项检查

### ❌ 雷区18：过度追求"美"而忽视性格
- 问题：为了好看什么都往脸上堆，不管符合不符合性格
- 后果：人设空洞，只有皮相没有灵魂
- 正解：先定性格气质，再定外形，外形为气质服务

### ❌ 雷区19：参考系迁移失败
- 问题：把A风格的人设直接搬到B风格，不做调整
- 后果：违和感强烈
- 正解：使用「参考系迁移适配公式」，逐层调整

### ❌ 雷区20：人设一成不变
- 问题：从开头到结尾，外形、气质一点变化都没有
- 后果：没有成长感
- 正解：给角色预留成长空间，剧情推进后可以有外形变化

## 十五、实战案例：完整人设设计示范

### 案例：设计一个「清冷御姐型女剑客」（玄机风 + 明日方舟风混搭）

#### Step 1：定位
```
角色名：沈霜
角色定位：女主角之一，剑修，宗门大师姐
核心性格：外冷内热、责任心强、嘴硬心软
主气质：清冷
副气质：威严
隐藏气质：温柔（只对亲近的人）
参考风格：70%玄机科技3D国漫风 + 30%明日方舟插画风
```

#### Step 2：基础层
```
体型类型：沙漏型偏直筒（练武的原因，肩略宽）
头身比：8头身
身高：175cm
肤色：冷白色（长期在室内练剑）
体型特点：肩宽腰细，有肌肉线条但不夸张，双腿修长有力
```

#### Step 3：特征层
```
脸型：菱形脸（偏瓜子脸）
眼睛：丹凤眼，冰蓝色瞳孔，眼神平淡但锐利
眉毛：剑眉，深蓝色
鼻子：高鼻梁，鼻型挺拔
嘴唇：薄唇，淡粉色
个性标记：左眼下有一颗小泪痣，右手虎口有一道旧剑伤
```

#### Step 4：发型层
```
发型长度：及腰长发
发型造型：平时高马尾（练武方便），发尾微碎；正式场合半束发
发色：银蓝色（接近月光的颜色）
发质特点：柔顺有光泽，但发尾有些微开叉（经常练剑风吹日晒）
发饰：银色发冠（宗门大师姐的象征），左耳有一个小银环
```

#### Step 5：符号层
```
内层：白色中衣，黑色紧身裤，白色布靴
外层：
  - 款式：月白色广袖长袍，领口和袖口有银色云纹刺绣
  - 主色：月白
  - 辅助色：银灰
  - 点缀色：冰蓝
材质：外层是飘逸的轻纱，内层是结实的布料（兼顾美观和实用）
配饰：
  - 颈部：银色长命锁（师傅送的）
  - 手部：白色手套（半指，方便握剑）
  - 腰部：白色腰封，挂着玉佩和剑穗
武器/工具：长剑「霜华」
挂载位置：背部斜挎，剑柄在右肩上方
```

#### Step 6：气质层
```
微表情锚点：
  1. 日常：面无表情，眼神平淡，微微垂眼
  2. 开心：嘴角微扬（只有1毫米），眼神柔和一点
  3. 思考：眉头微蹙，手指无意识摩挲剑柄
  4. 生气：眼神变冷，眉头皱起，握剑的手收紧
  5. 害羞：眼神闪躲，耳尖微红，轻咳一声转开脸

标志性动作：
  1. 思考动作：手指轻轻敲击剑柄
  2. 装酷动作：反手拔剑，剑指对方，眼神凌厉
  3. 情绪爆发动作：剑往地上一插，抬头闭眼深呼吸（强忍怒气）
```

#### Step 7：故事层
```
疤痕/标记的来历：
  - 左眼泪痣：天生的，师傅说"这痣主情，你这一生会为情所困"
  - 右手虎口旧伤：16岁那年为了保护师弟师妹，被妖兽所伤

最喜欢的衣服的故事：
  - 这件月白长袍是师傅亲手织的，是师傅去世前最后一件作品
  - 虽然已经有些旧了，但沈霜一直舍不得换

习惯性动作的成因：
  - 敲剑柄：师傅还在的时候，每次沈霜练剑遇到瓶颈，师傅就会敲她的剑柄
  - 现在她自己思考时也会敲，像师傅还在身边一样
```

#### Step 8：最终校验
- [x] 记忆点3-5个？（银蓝长发 + 泪痣 + 月白长袍 + 敲剑柄动作）✓
- [x] 气质统一？（清冷为主，威严为辅）✓
- [x] 剪影可识别？（高马尾 + 长剑 + 广袖长袍）✓
- [x] 颜色控制在4色以内？（月白+银灰+冰蓝+黑）✓
- [x] 服饰符合身份？（宗门大师姐 + 剑修）✓
- [x] 发型实用？（高马尾，练武方便）✓
- [x] 有故事性？（每个特征都有来历）✓
- [x] 有成长空间？（后期可以换发型/换衣服）✓

## 十六、质量自检清单

### 16.1 基础层检查

- [ ] 体型选择是否符合角色性格和职业？
- [ ] 头身比是否在合理范围内？
- [ ] 肤色是否符合角色的生活环境？
- [ ] 体型和力量感是否匹配？

### 16.2 特征层检查

- [ ] 脸型是否符合角色气质？
- [ ] 五官比例是否协调（三庭五眼基础上美化）？
- [ ] 眼睛形状和瞳色是否有符号意义？
- [ ] 是否有1-2个五官个性标记？
- [ ] 发型是否符合角色身份和职业？
- [ ] 发色是否有符号意义？
- [ ] 发型在运动时是否合理？
- [ ] 遮住脸只看剪影，能认出这个角色吗？

### 16.3 符号层检查

- [ ] 服饰是否符合角色的身份、职业、经济状况？
- [ ] 颜色是否控制在4种以内？
- [ ] 主色调是否明确？
- [ ] 材质是否有对比（软硬/光泽/厚薄）？
- [ ] 配饰是否有意义（不是乱加的）？
- [ ] 武器/工具是否符合角色能力？
- [ ] 武器挂载位置是否合理？

### 16.4 气质层检查

- [ ] 主气质是否明确？
- [ ] 所有视觉元素是否指向同一个气质核心？
- [ ] 是否有副气质增加层次感？
- [ ] 是否有隐藏气质预留悬念？
- [ ] 是否设定了5个微表情锚点？
- [ ] 是否设定了3个标志性动作？
- [ ] 表情和动作是否符合角色性格？

### 16.5 故事层检查

- [ ] 每个显著外貌特征是否有故事？
- [ ] 习惯性动作是否有成因？
- [ ] 服饰/配饰是否有特殊含义？
- [ ] 人设是否预留了成长变化空间？

### 16.6 漫剧适配检查

- [ ] 设计是否简化到动画师能画出来？
- [ ] 细节在远景时还能看清吗？
- [ ] 角色动起来（跑/跳/打）时，衣服头发会怎么样？
- [ ] 和其他主角团成员放在一起，能一眼区分吗？

> **核心心法：** 人物描写的最高境界，不是"堆一堆好看的形容词"，而是**用文字创造一个有灵魂的活人**——读者读到TA的第一眼，脑子里就浮现出TA的样子，感受到TA的气息，甚至能预判TA会说什么话、做什么事。
>
> 皮相是入门，气质是进阶，故事是灵魂。
>
> 先写好人物，再谈漫剧。
>
> 文字立住了，怎么改编都不会垮。
