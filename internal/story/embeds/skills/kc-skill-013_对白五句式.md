# 对白五句式

## 核心原则

对话不是聊天，是"目的+冲突"——每句都要带：想得到什么 / 想掩盖什么 / 想激怒谁 / 想说服谁。好对话必须同时满足三个目的：**展示性格 / 推进情节 / 揭示信息**。

**铁律**：少说话，多做事。用动作、表情、停顿代替废话。每个人说话不一样——口音、口头禅、长短句、逻辑，一眼就能分清是谁。

---

## 操作步骤/公式

### 五种对话句式

#### 句式一：描写 + 对白

**格式**：先给动作/神态/环境描写，再出对白

**示例**：
```
大长老冷笑，"叶玄，忘记告诉你了。你已被罢黜世子之位！"
```

**核心效果**：描写是"预告"，对白是"落点"
**适用场景**：人物第一次出场、情绪爆发前、需要强调人物态度时
**注意**：描写控制在10字以内，最长不超过15字

#### 句式二：对白 + 描写

**格式**：先出对白，再用动作/神态/情绪反应收尾

**示例**：
```
"三十年河东，三十年河西，莫欺少年穷！"萧炎铮铮冷语，
让得纳兰嫣然娇躯轻颤。
```

**核心效果**：对白是"内容"，描写是"情绪注解"
**适用场景**：对白内容平淡需要补充情绪、语言和真实情绪有反差时
**高阶用法**：利用反差（嘴上说"没事"，手却在抖）

#### 句式三：对白 + 描写 + 对白

**格式**：说一句，停顿（加描写），再说一句

**示例**：
```
"呵呵，"吕树黑着脸，"莫名其妙的自信。"
```

**核心效果**：中间的描写是"情绪的刹车"，停顿越长后面那句话重量越重
**适用场景**：人物做艰难决定时、情绪转折时、需要强调某句话的重量时

#### 句式四：纯对话（对白+对白+对白）

**格式**：去掉所有描写，只用对话推进

**示例**：
```
"18年了，没人联系我……"
"30号人，我走第一年，战死了9个……"
"还在战场上！"
```

**核心效果**：节奏极快，冲突感极强
**适用场景**：冲突爆发高潮时刻、快速过场、喜剧节奏
**风险提示**：纯对话不能连续太长，超过6句读者会分不清谁在说话

#### 句式五：复合节奏（对白 + 描写 + 对白 + 描写）

**格式**：情绪有起有伏，像一首完整的曲子

**示例**：
```
"你已经长大了，"他看着眼前的人儿，有些愠怒，
"做事还像个小孩子，唉……"他说罢转身离开，头也没回。
```

**核心效果**：情绪有起有伏，像一首完整的曲子
**适用场景**：情感浓度高的场景、人物关系发生转折的时刻、章节收尾的"余韵"

### 潜台词公式

**核心公式**：`嘴上说A → 心里想B → 动作暴露C`

```
直白： "你别走，我舍不得你。"
生动： "风大，路上慢点……记得，常回来。"

嘴上说A：风大路上慢点（关心对方）
心里想B：我舍不得你走（依恋）
动作暴露C：（如：手指攥着衣角不放）暴露真实情绪
```

**万能插入语**（替代"说"）：
> 顿了顿、抬眼、垂眸、嗤笑、喉间滚出一声、指尖敲了敲桌、脚步顿住

**情绪动词**（替代"说"）：
> 吼、嗤、冷嗤、呢喃、轻叹、嗤笑、低吼、哑声、提醒、警告、逼问

### 人物说话节奏设计

| 人物类型 | 说话特点 |
|---------|---------|
| 强势人 | 短句、命令、打断 |
| 温柔人 | 长句、解释、试探 |
| 聪明人 | 话少、点到为止 |
| 暴躁人 | 重复、反问、脏话（适度） |

## 模板/示例

### 暧昧拉扯场景模板

```
[动作碰触] + [对白]
[退缩动作] + [对白]
[对白转折] + [描写暴露真实情绪]

他指尖轻轻碰了下她的手腕，又很快收回：
"很晚了，我送你。"
她往后缩了缩，声音轻得像羽毛：
"不用，我自己可以。"
"我知道。"他抬眼，目光很沉，"但我想。"
```

### 吵架冲突场景模板

```
[情绪爆发对白] + [反击对白] + [核心信息对白]

"你从来都不信我！"
"信你？"他笑了一声，却没半点温度，"你拿什么让我信？"
她猛地抬头，眼眶发红："就凭我……从来没骗过你！"
```

### 装逼打脸场景模板

```
[反派嘲讽对白] + [主角淡定对白] + [反派出手] + [主角一招制敌]
+ [反派震惊对白] + [主角收尾对白] + [周围死寂描写]

"就你？也配挑战我？"王五不屑地看着他。
张三淡淡道："试试不就知道了。"
王五出手，张三抬起一根手指，轻轻一弹。
"这……这怎么可能？！"
"我说过了，"张三收回手指，"试试不就知道了。"
四周一片死寂。
```

### 节奏控制模板

```
1. 场景开头：2-3句环境描写，建立空间感
2. 人物入场：描写+对白（句式一），立住人物状态
3. 对话展开：对白+描写交替（句式二），推进剧情
4. 冲突升级：切换纯对白（句式四），节奏加快
5. 冲突顶点：对白+描写+对白（句式三），用停顿制造重量
6. 场景收尾：对白+描写+对白+描写（句式五），完成情绪收束
```

## 自检清单

### 对话自检4问

- [ ] **去掉名字，我还能认出是谁在说话吗？**（口音/口头禅/长短句/逻辑区分）
- [ ] **每句都有目的吗？有没有废话？**（每句必须带：想得到/想掩盖/想激怒/想说服）
- [ ] **有没有潜台词和情绪？**（嘴上说A→心里想B→动作暴露C）
- [ ] **是不是在推动剧情/制造冲突？**（满足展示性格/推进情节/揭示信息三目的）

### 句式使用自检

- [ ] 是否交替使用了五种句式？（避免单一句式疲劳）
- [ ] 纯对话（句式四）是否控制在6句以内？
- [ ] 句式一的描写是否控制在15字以内？
- [ ] 句式三的停顿是否与后面那句话的"重量"匹配？

### 潜台词自检

- [ ] 是否避免了"直白说情绪"？（如直接说"我舍不得你"）
- [ ] 是否用动作/神态暴露了真实情绪？
- [ ] 是否使用了"万能插入语"替代"说"？
- [ ] 是否使用了"情绪动词"替代"说"？

### 人物区分度自检

- [ ] 强势人物是否用短句、命令、打断？
- [ ] 温柔人物是否用长句、解释、试探？
- [ ] 聪明人是否话少、点到为止？
- [ ] 暴躁人物是否重复、反问？

## 适用边界

**适用场景**：
- 网络小说人物对话写作（全题材）
- 双人/多人对话场景设计
- 情绪转折点的对话打磨
- 装逼打脸/暧昧拉扯/吵架冲突等典型场景

**不适用场景**：
- 内心独白（不属于对话范畴）
- 纯环境描写（无对话元素）
- 文学小说的诗化对话（节奏要求不同）

**特别注意**：
- 纯对话不能连续太长（超过6句读者会分不清）
- 对话三目的（展示性格/推进情节/揭示信息）至少满足两项，最好三项都满足
- 对话里的"信息+悬念"：每段对话最好同时推动剧情+暴露性格+埋钩子
- 用"打断、停顿、跑题"制造真实感：明明在吵架，突然问"你吃饭了吗？"
