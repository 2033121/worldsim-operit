# 世界设定自洽性检验体系

> **核心定位：** 世界观的"质检系统"。构建完世界观之后，用这套体系全面检查，找出bug、漏洞、矛盾，确保世界能"立得住"。
>
> **核心公式：** 自洽度 = 规则一致性 × 逻辑闭环性 × 因果完整性 × 细节匹配度
>
> **关键认知：** 没有bug的世界观不存在，但关键位置不能有bug——读者注意不到的地方可以放水，核心逻辑必须严丝合缝。

---

## 一、七维自洽性检验框架

### 第一维：规则一致性检验

**检验目标：** 世界的核心规则前后一致，不会说变就变。

**检验清单：**

- [ ] **核心规则明确吗？** 3-5条核心规则，写下来了吗？
- [ ] **规则边界清晰吗？** 什么能做、什么不能做，有明确界限吗？
- [ ] **规则有代价吗？** 使用力量/资源需要付出代价吗？
- [ ] **规则前后一致吗？** 前面说的和后面说的一样吗？
- [ ] **规则被遵守了吗？** 人物（包括主角）都在规则内行动吗？
- [ ] **打破规则有铺垫吗？** 任何打破规则的行为，都有合理的解释和代价吗？
- [ ] **规则之间有矛盾吗？** 不同规则之间不会互相冲突吗？

**常见bug类型：**
1. **规则漂移**：一开始说A，后面变成B（比如境界划分越写越多）
2. **双标规则**：主角能用，别人不能用，没有合理解释
3. **规则万能**：规则能解决一切问题，没有边界
4. **规则无用**：设定了一堆规则，但剧情里根本没用上

**修复方法：**
- 把核心规则写在一个固定的地方，随时对照
- 每次要打破规则时，问自己三个问题：为什么？代价是什么？影响是什么？
- 建立"规则变更日志"，记录每次规则调整的原因和影响范围

---

### 第二维：逻辑闭环性检验

**检验目标：** 事情的发生有因有果，没有凭空出现的东西。

**检验清单：**

- [ ] **核心冲突有根源吗？** 不是"因为他是坏人所以坏"，而是有具体的利益/理念冲突
- [ ] **人物行为有动机吗？** 每个人物做每件事，都有合理的理由吗？
- [ ] **事件发展有因果吗？** 因为A所以B，不是作者说怎样就怎样
- [ ] **伏笔有回收吗？** 前面埋的线，后面都收回来了吗？
- [ ] **反转有铺垫吗？** 反转是意料之外情理之中，还是硬转？
- [ ] **结局有铺垫吗？** 结局是前面发展的必然结果，还是作者硬编的？

**常见bug类型：**
1. **空降设定**：需要的时候突然冒出来一个设定，前面完全没提
2. **工具人行为**：人物为了推动剧情，做出不符合自己人设的事
3. **因果倒置**：为了某个结果，硬编一个原因
4. **逻辑跳步**：从A直接跳到C，中间的B不见了

**修复方法：**
- 每条重要剧情线，都画一张因果链图
- 每个人物的重要决策，都写"动机-决策-结果"三要素
- 问自己：如果我是读者，我会觉得合理吗？

---

### 第三维：时间线一致性检验

**检验目标：** 历史、时间、年龄、事件先后顺序都对得上。

**检验清单：**

- [ ] **历史年表清晰吗？** 重要历史事件的时间、顺序、影响都明确吗？
- [ ] **人物年龄对得上吗？** 经历的事情和年龄匹配吗？
- [ ] **事件顺序正确吗？** 事情发生的先后顺序没有矛盾吗？
- [ ] **时间流逝合理吗？** 修炼/成长/旅行需要的时间符合设定吗？
- [ ] **历史影响连贯吗？** 历史事件对现在的影响是连贯的吗？
- [ ] **代际关系清楚吗？** 师徒、父子、祖孙等代际关系的时间线对得上吗？

**常见bug类型：**
1. **年龄bug**：人物年龄和经历对不上（比如20岁就有30年功力）
2. **时间压缩**：明明需要十年的事，三个月就完成了
3. **历史矛盾**：前面说某件事发生在500年前，后面又说是300年前
4. **失忆式历史**：历史大事对现在完全没影响

**修复方法：**
- 做一张简单的时间线表格
- 重要人物都算一下年龄：某年发生某事时，他多大？
- 旅行/修炼时间，按设定的速度算一算，对不对？

---

### 第四维：空间地理检验

**检验目标：** 地理、位置、距离、交通都合理。

**检验清单：**

- [ ] **地图清晰吗？** 主要地点的相对位置明确吗？
- [ ] **距离合理吗？** 从A到B需要的时间符合交通方式吗？
- [ ] **地理环境一致吗？** 气候、地形、物产符合地理规律吗？
- [ ] **城市分布合理吗？** 城市为什么建在这里？（水源、交通、防御）
- [ ] **势力范围清晰吗？** 各个势力的地盘、边界、缓冲带有明确划分吗？
- [ ] **战略位置合理吗？** 重要关隘、战略要地的位置符合逻辑吗？

**常见bug类型：**
1. **瞬移bug**：昨天还在万里之外，今天就到了
2. **地理混乱**：东边是海，过两章又变成了山
3. **城市凭空出现**：需要的时候就冒出来一座城
4. **距离随便写**：说远就远，说近就近，全看剧情需要

**修复方法：**
- 画一张简单的地图，不需要多好看，但位置要对
- 算一下：按正常速度，从A到B要多久？
- 重要地点，都标注一下：为什么在这里？有什么特殊？

---

### 第五维：人物行为检验

**检验目标：** 人物的行为符合人设、符合逻辑、符合他的认知水平。

**检验清单：**

- [ ] **人物行为符合人设吗？** 性格、价值观、行事风格一致吗？
- [ ] **人物有成长变化吗？** 变化有过程、有原因，不是突然变了
- [ ] **人物认知符合设定吗？** 他知道的，是他这个位置/身份应该知道的吗？
- [ ] **人物决策有道理吗？** 站在他的角度，他会这么选吗？
- [ ] **人物能力匹配吗？** 他能做到的事，符合他的实力/身份吗？
- [ ] **人物关系一致吗？** 两个人的关系，和之前发生的事对应吗？

**常见bug类型：**
1. **OOC（Out of Character）**：人物突然做出不符合性格的事
2. **智商掉线**：本来很聪明的人，突然变傻了（为了推动剧情）
3. **全知全能**：人物不该知道的事，他全知道
4. **能力漂移**：一开始说他不会这个，后面突然就会了

**修复方法：**
- 重要人物都做一张"人设卡"，随时对照
- 写人物决策时，问自己：他的性格会让他怎么选？他现在知道哪些信息？
- 人物能力有提升时，一定要有铺垫和过程

---

### 第六维：社会文化检验

**检验目标：** 社会结构、文化习俗、经济体系都自洽。

**检验清单：**

- [ ] **社会结构合理吗？** 顶层/中层/底层的比例和关系符合逻辑吗？
- [ ] **权力来源清晰吗？** 统治者凭什么统治？力量？财富？血统？
- [ ] **经济体系自洽吗？** 钱从哪来？怎么花？物价合理吗？
- [ ] **职业体系完整吗？** 人们靠什么吃饭？有哪些主要职业？
- [ ] **文化有根源吗？** 习俗、信仰、价值观有形成的原因吗？
- [ ] **阶层流动正常吗？** 底层能不能往上爬？难不难？通过什么途径？

**常见bug类型：**
1. **经济悬浮**：主角从不缺钱，钱从哪来不知道
2. **职业单一**：全世界只有修炼者，没有农民、工匠、商人
3. **社会过简**：社会结构简单得像过家家
4. **文化装饰化**：文化只是点缀，不影响人的行为和社会运转

**修复方法：**
- 想一想：一个普通人，他一天怎么过？靠什么吃饭？
- 算一算：顶层靠什么维持统治？底层为什么不造反？
- 文化习俗，都找一个"为什么"：为什么会有这个习俗？

---

### 第七维：力量体系检验

**检验目标：** 战力、等级、能力体系不崩坏。

**检验清单：**

- [ ] **等级划分清晰吗？** 每个等级的差距、特征、瓶颈都明确吗？
- [ ] **升级难度递增吗？** 越往上越难，不是线性升级
- [ ] **战力有天花板吗？** 最高级别有多强，有上限吗？
- [ ] **能力有代价吗？** 越强的能力，代价越大吗？
- [ ] **克制关系存在吗？** 没有无敌的能力，都有克制方法
- [ ] **升级有过程吗？** 不是突然就升级了，有积累、有契机、有感悟

**常见bug类型：**
1. **战力膨胀**：越往后战力越夸张，前面的设定全作废
2. **等级注水**：本来10个等级，写着写着变成20个
3. **主角光环**：主角同阶无敌，越阶挑战如家常便饭
4. **能力万能**：某个能力太强，没有弱点，解决一切问题

**修复方法：**
- 做一张"战力等级表"，每个等级的上限、特征、代表人物都写清楚
- 升级时，对照一下：按设定，他现在应该是什么水平？
- 给每个强力能力都设计一个弱点或代价
- 参考KC-SKILL-039「战力体系防崩三铁律」

## 二、五大压力测试法

### 测试一：极端情境测试

**方法：** 把设定推到极端，看看会不会崩。

**测试问题示例：**
- 如果最强的人全力出手，世界会怎么样？
- 如果核心资源突然枯竭了，社会会怎么变？
- 如果规则突然失效一天，会发生什么？
- 如果底层人民集体造反，顶层能镇住吗？
- 如果主角一开始就黑化了，世界会怎样？

**通过标准：**
- 极端情况下，世界的反应符合你设定的规则和逻辑
- 不会出现"这不可能"、"说不通"的情况
- 即使会毁灭，毁灭的过程也是合理的

---

### 测试二：边界条件测试

**方法：** 测试规则的边界，看看边界在哪、过了边界会怎样。

**测试问题示例：**
- 规则的适用范围有多大？（全世界？还是某个区域？）
- 规则有没有例外？什么情况下会失效？
- 能力的上限在哪？再往上会怎样？
- 最小的单位是什么？能不能再细分？
- 两种规则冲突时，听谁的？

**通过标准：**
- 每个规则都有清晰的边界
- 边界之外的情况，也有合理的解释
- 不会出现"我不知道"、"没想过"的情况

---

### 测试三：连锁反应测试

**方法：** 改变一个设定，看看会引发哪些连锁反应。

**测试方法：**
1. 选一个核心设定（比如：灵气浓度翻倍）
2. 想一想：这会影响哪些东西？
3. 第一层影响：直接相关的（比如：修炼速度变快）
4. 第二层影响：间接相关的（比如：境界通货膨胀、宗门扩招）
5. 第三层影响：深层影响（比如：底层更难翻身、冲突更激烈）
6. ...一直推到你能想到的最深层

**通过标准：**
- 连锁反应的链条是清晰的、合理的
- 不会出现"只有主角受益，其他都不变"的情况
- 改变一个设定，整个世界都会有相应的变化

---

### 测试四：反向推理测试

**方法：** 从结果倒推原因，看看能不能倒推回去。

**测试方法：**
1. 选一个你设定好的"现状"（比如：现在是三家分天下的局面）
2. 倒推：为什么会变成这样？
3. 再倒推：造成那个原因的原因是什么？
4. 一直倒推到最开始的核心设定
5. 看看链条是不是完整的、合理的

**通过标准：**
- 从现状能一路倒推回核心设定
- 每一步都有合理的原因
- 没有"就是这样"、"我设定的"之类的偷懒答案

---

### 测试五：平民视角测试

**方法：** 把自己代入一个普通人，看看这个世界能不能活下去。

**测试问题：**
- 你是一个普通人，你靠什么吃饭？
- 你的一天是怎么过的？
- 你最怕什么？最期待什么？
- 你知道这个世界的"真相"吗？
- 你对现在的生活满意吗？为什么？
- 如果给你一个机会改变命运，你会怎么做？

**通过标准：**
- 普通人的生活是具体的、可想象的
- 社会能正常运转，不会所有人都饿死
- 普通人有普通人的喜怒哀乐，不是背景板
- 主角的行为，会对普通人产生影响（正面或负面）

## 三、五十项编辑级自检清单

### 核心规则类（10项）

- [ ] 核心规则不超过5条，简洁清晰
- [ ] 每条规则都有明确的适用范围和边界
- [ ] 规则之间没有矛盾
- [ ] 任何力量/能力都有对应的代价
- [ ] 代价和力量成正比
- [ ] 打破规则有合理的解释和代价
- [ ] 规则不会为了主角方便而改变
- [ ] 反派也能利用规则（规则不偏向正义）
- [ ] 规则有"不能做什么"的明确限制
- [ ] 规则体系有整体逻辑，不是零散拼凑

### 人物行为类（10项）

- [ ] 主角的重要决策都有合理动机
- [ ] 反派的行为有自己的逻辑，不是为坏而坏
- [ ] 配角有自己的目标和行动，不是工具人
- [ ] 人物性格前后一致（变化有过程）
- [ ] 人物的认知符合他的身份和经历
- [ ] 人物能力和他的修炼/训练匹配
- [ ] 人物关系的发展有铺垫和过程
- [ ] 人物说话的语气符合身份和性格
- [ ] 没有人会做出"换我我绝对不会这么做"的事
- [ ] 人物的成长弧线清晰、合理

### 剧情逻辑类（10项）

- [ ] 核心冲突清晰，贯穿始终
- [ ] 每条剧情线都有完整的因果链
- [ ] 重要反转都有铺垫（能找到伏笔）
- [ ] 没有"空降"的设定和人物
- [ ] 巧合不能太多（最多1-2个启动剧情的巧合）
- [ ] 问题的解决符合逻辑，不是机械降神
- [ ] 主角的成功主要靠自己，不是靠运气
- [ ] 失败有合理的原因，不是为了虐而虐
- [ ] 时间线没有矛盾
- [ ] 地理/距离没有bug

### 社会文化类（10项）

- [ ] 社会结构清晰（顶层/中层/底层）
- [ ] 权力来源合理（不是"我就是能统治"）
- [ ] 经济体系自洽（钱从哪来、怎么花）
- [ ] 职业体系完整（不只有战斗职业）
- [ ] 普通人的生活状态具体可感
- [ ] 文化习俗有形成的原因
- [ ] 不同地区/民族有文化差异
- [ ] 阶层流动渠道清晰
- [ ] 法律/制度明确且被执行
- [ ] 历史对现在有真实影响

### 力量体系类（10项）

- [ ] 等级划分清晰，每个等级有明确特征
- [ ] 升级难度递增（越往上越难）
- [ ] 战力有明确的天花板
- [ ] 同级别内有强弱之分，但不会天差地别
- [ ] 越阶挑战极难，且有合理原因
- [ ] 每个能力都有弱点和限制
- [ ] 能力之间有克制关系
- [ ] 修炼资源的获取难度合理
- [ ] 功法/技能有明确的等级和效果
- [ ] 战力不会无缘无故膨胀

## 四、世界观bug修复方法论

### bug分级标准

| 等级 | 定义 | 影响 | 处理优先级 |
|:----:|:-----|:-----|:----------:|
| **S级** | 核心规则矛盾，整个世界观根基动摇 | 读者直接弃书，根本没法圆 | 最高，立刻修复 |
| **A级** | 重要剧情逻辑bug，影响主线走向 | 读者出戏，讨论"作者bug了" | 高，尽快修复 |
| **B级** | 次要设定矛盾，不影响主线 | 细心的读者会发现，但不影响阅读 | 中，有空就修 |
| **C级** | 小细节错误，比如名字写错 | 几乎没人注意，或注意了也不在意 | 低，攒一波一起改 |

---

### 修复策略

#### 策略一：打补丁（适用于B/C级bug）

**方法：** 在后面的章节里，找个机会补一句，把bug圆过去。

**例子：**
- bug：前面说某功法不能传给外人，后面主角传了
- 补丁："这门功法本来传内不传外，但你是例外，因为..."

**优点：** 简单，不用改前面
**缺点：** 补丁多了会显得刻意

---

#### 策略二：埋伏笔（适用于A级bug，还没暴露时）

**方法：** 在bug暴露之前，先埋下伏笔，让读者觉得"哦，原来如此"。

**例子：**
- 你计划让主角打破某个规则
- 提前十几章就埋下："传说中，在某某条件下，规则是可以被打破的..."

**优点：** 读者会觉得你早有预谋，不是bug
**缺点：** 需要提前规划，不能临时抱佛脚

---

#### 策略三：将错就错（适用于A级bug，已经暴露了）

**方法：** 干脆把bug变成设定，让它合理化。

**例子：**
- bug：你写着写着，战力膨胀了
- 将错就错："原来之前的认知是错的，上面还有更高的境界..."

**优点：** 不用认错，还能制造新的悬念
**缺点：** 用多了会失控，比如境界越写越多

---

#### 策略四：直接修改（适用于所有等级，最好的方法）

**方法：** 回去把前面的bug改掉，保持前后一致。

**优点：** 最彻底，没有后遗症
**缺点：** 已经发出去的章节，改了老读者会懵

**建议：**
- 没发出去的，直接改，不要犹豫
- 已经发出去的，S/A级bug还是要改，改完在作者说一声
- B/C级bug，可以攒一波，上架前/完本时统一大修

---

## 五、不同阶段的检验重点

### 立项阶段：核心规则检验

**重点：** 核心规则、核心矛盾、核心设定
**方法：** 极端测试 + 边界测试
**目标：** 确保根基是稳的，不会写着写着发现核心设定有问题

---

### 大纲阶段：整体框架检验

**重点：** 时间线、地理、势力、人物关系
**方法：** 连锁反应测试 + 反向推理测试
**目标：** 确保整体框架自洽，没有大的逻辑漏洞

---

### 写作阶段：细节同步检验

**重点：** 人物行为、剧情逻辑、设定一致性
**方法：** 每写完一卷，对照七维检查清单过一遍
**目标：** 边写边检查，不要攒到最后，攒到最后就改不动了

---

### 完本阶段：全面终检

**重点：** 所有维度的全面检查
**方法：** 五十项自检清单全部过一遍
**目标：** 完本大修，把能修的bug都修了，给读者一个完整的作品

---

## 六、终极认知：没有完美的世界观

首先要接受一个事实：

**没有任何世界观是100%自洽的。**

哪怕是《魔戒》《哈利波特》这样的神作，仔细抠也能抠出bug。

为什么？
因为世界观是人造的，而真实世界是演化出来的。
人造的东西，再精密也会有漏洞；演化出来的东西，看似混乱但处处自洽。

所以，我们追求的不是"零bug"，而是：
1. **核心逻辑不能有bug**——根基要稳
2. **读者注意不到的地方可以放水**——别在不重要的地方死磕
3. **bug出现了能圆回来**——圆得好，反而变成亮点

**记住：** 读者来看的是故事，不是来找bug的。
故事足够精彩，人物足够动人，哪怕有几个小bug，读者也会帮你圆。

反过来，故事不好看，人物不吸引人，世界观再自洽也没用。

**自洽是基础，不是目的。**
**目的，是讲一个好故事。**

---

> **最后一句话：** 检验世界观的最好方法，不是对着清单打勾，而是读一遍——你自己信不信这个世界？
>
> 你自己信了，读者才会信。
>
> 你自己都觉得牵强，读者肯定更觉得牵强。
