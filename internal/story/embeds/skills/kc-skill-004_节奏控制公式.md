# 节奏控制公式

## 压→缓→压→爆四阶段节奏

```
【压】主角陷入困境，读者跟着紧张
    ↓
【缓】给一点喘息空间，但埋下隐患
    ↓
【压】隐患爆发，更大的困境
    ↓
【爆】主角爆发，读者跟着爽
    ↓
【留钩】新问题出现，读者想知道怎么解决
```

## 章节节奏公式

### 开头（100-200字）
- 衔接上一章
- 点明本章主题

### 发展（1200-1500字）
- 情节推进
- 冲突展开

### 高潮（300-500字）
- 本章爽点或冲突顶点

### 结尾（100-200字）
- 引出下一章
- 制造悬念

| 字数区间 | 核心任务 | 节奏要点 |
|---------|---------|---------|
| 0-10万 | 建置期待 | 建立世界观/主角/核心冲突/金手指 |

## 情绪曲线设计

### 核心原则
情绪曲线必须是"波浪形"而非"直线"

### 标注方法
- 按500字分段
- 每段标注情绪值（-5绝望到+5狂喜）
- 必须在-3到+3之间波动
- 禁止连续两段同向情绪超过2个刻度

### 情绪曲线示例
```
-3（紧张）→ +1（缓解）→ -2（发现异常）→ -4（高潮爆发）→ +2（短暂胜利）→ -1（新悬念）
```
