# 反向推导五步法

## 核心原则

1. **已写即判例**：已完成的章节确立为不可更改的"判例"，后续所有剧情必须遵守，否则前文铺垫全部作废。
2. **从无意识中挖掘矿脉**：作者在写作中无意识埋下的种子，可反向推导出30-50章规模的支线，是创意的重要来源。
3. **GPS导航式创作**：总纲是北极星（方向），大纲是高速公路（路径），卷纲是服务区（休整），章纲是导航语音（精确指令）。
4. **商业钩子密度前置规划**：在架构阶段就规划每章钩子类型，禁止连续两章没有钩子。
5. **锚点校验保证一致性**：支线与主线咬合时，必须校验时间点、人物状态、细节一致性。

## 操作步骤/公式

### 步骤1：建立"法律体系"（确立判例）

```
核心：将已写章节确立为"判例"，后续所有剧情必须遵守。

操作：
1. 通读已写章节（3-10章正文）
2. 提取所有已确立的规则、设定、人物特征
3. 整理为"判例清单"
4. 后续剧情必须与判例一致，不可擅改

例：第3章设定"喊三声娘娘回魂触发封印"
→ 后续所有副本都必须遵守"三声触发"规则
→ 不能随意更改，否则前面所有铺垫全部作废

判例清单模板：
【规则判例】第X章设定：______ → 后续必须遵守
【设定判例】第X章设定：______ → 后续必须遵守
【人物判例】第X章设定：______ → 后续必须遵守
【道具判例】第X章设定：______ → 后续必须遵守
```

### 步骤2：挖掘隐藏矿脉（从种子推导支线）

```
核心：从无意识埋下的种子中推导支线。

操作：
1. 标记已写章节中的"未解释细节"
2. 评估每个细节的延伸价值
3. 反向推导支线规模

例1："老鬼徒弟的背叛"（第6章无意识提及）
→ 可反向推导出30-50章规模的"财阀内斗篇"

例2："柳三爷的鳞片"（第2章道具细节）
→ 可延伸出"柳三爷真实身份"的长期悬念线

挖掘流程：
已有内容 → 隐藏线索 → 可延伸支线 → 商业价值评估

商业价值评估维度：
· 能延伸多少章？（规模）
· 能制造多少爽点？（爽点密度）
· 能埋多少钩子？（钩子数量）
· 与主线关联度？（咬合程度）
```

### 步骤3：建立创作GPS（导航系统）

```
核心：构建从当前到目标的导航系统。

GPS四层结构：

总纲 = 北极星（方向）
  · 始终指向最终目标
  · 50字内说清全书核心脉络
  · 核心主题 + 一句话概括 + 结局走向

大纲 = 高速公路地图（路径）
  · 5-10卷的结构
  · 起承转合线路图，标注核心转折点
  · 每卷有独立高潮

卷纲 = 服务区（休整+高潮）
  · 每卷20-30万字
  · 有独立小目标和收官高潮
  · 卷末必须有让读者"必须看下一卷"的钩子

章纲 = 导航语音（精确指令）
  · 精确到每章的任务
  · 每章3000-5000字，明确核心功能
  · 必须有冲突或钩子，禁止"过渡章"
```

### 步骤4：确保商业钩子密度

```
核心：在架构阶段就规划每章结尾的钩子类型。

钩子三种类型：

| 钩子类型 | 效果 | 示例 |
|---------|------|------|
| 悬念型 | 新人物登场/新谜题出现 | "门后传来的声音是谁？" |
| 情绪型 | 主角遭遇重大打击 | "他倒下了，血染红了地面" |
| 爽点型 | 打脸/升级/揭秘 | "他竟然是……" |

铁律：禁止连续两章没有钩子

钩子密度规划模板：
第X章：悬念型钩子（______）
第X+1章：情绪型钩子（______）
第X+2章：爽点型钩子（______）
第X+3章：悬念型钩子（______）
...

钩子节奏公式：
一个钩子拆开的同时，另一个钩子已经套上了。
```

### 步骤5：锚点校验三问

```
核心：支线与主线咬合时，必须校验一致性。

锚点校验三问：

1. 支线发生在主线时间轴的哪个精确位置？
   · 不能出现时间线矛盾
   · 例：支线发生在"主角刚突破筑基期之后"，
     此时主角战力必须与筑基期匹配

2. 在这个时间点，人物能力/心理/道具是什么状态？
   · 能力：主角此时是什么境界？有什么技能？
   · 心理：主角此时是什么心态？有什么执念？
   · 道具：主角此时身上有什么？缺什么？

3. 哪些细节必须和主线100%咬合？
   · 已出现的NPC状态
   · 已提及的地点
   · 已发生的事件
   · 已确立的规则（判例）

校验失败的处理：
· 调整支线时间点
· 修改支线细节
· 必要时回溯修改主线（成本高，慎用）
```

## 模板/示例

### 模板1：反向推导工作流程

```markdown
【输入】已写3-10章正文

【步骤1：建立判例清单】
□ 通读已写章节
□ 提取规则/设定/人物/道具判例
□ 整理为判例清单（不可更改）

【步骤2：挖掘矿脉】
□ 标记未解释细节
□ 评估延伸价值（规模/爽点/钩子/关联度）
□ 选出高价值矿脉（3-5条）

【步骤3：建立GPS】
□ 总纲（50字内）
□ 大纲（5-10卷结构）
□ 卷纲（每卷20-30万字）
□ 章纲（精确到每章）

【步骤4：规划钩子密度】
□ 每章钩子类型标注
□ 检查是否连续两章无钩子
□ 钩子交替使用（悬念/情绪/爽点）

【步骤5：锚点校验】
□ 支线时间点与主线对齐
□ 人物状态一致性校验
□ 细节咬合校验

【输出】完整大纲 + 判例清单 + 矿脉清单 + 钩子规划
```

### 模板2：判例清单示例

```markdown
【规则判例】
· 第3章：喊三声娘娘回魂触发封印 → 后续必须遵守
· 第5章：心神丹元被动觉醒条件是"心神受创" → 后续必须遵守

【设定判例】
· 第1章：娘娘庙位于青河村东 → 后续地点不可更改
· 第4章：玄冥会通过短信联系成员 → 后续通讯方式一致

【人物判例】
· 第2章：柳三爷嘴碎但护犊子 → 后续人设不可崩
· 第6章：陈默嘴硬说"相信科学" → 后续性格标签保持

【道具判例】
· 第2章：柳三爷身上的鳞片 → 后续可延伸身份线
· 第3章：洗髓丹瓶底的符号 → 后续可延伸身世线
```

### 模板3：矿脉挖掘示例

```markdown
【矿脉1】柳三爷的鳞片（第2章道具细节）
· 延伸方向：柳三爷真实身份
· 预估规模：50-80章长期悬念线
· 爽点密度：3-5个大爽点（身份揭秘/能力展示/护道爆发）
· 钩子数量：每10章至少1个相关钩子
· 与主线关联度：高（陈默的护道人，直接影响主角安全）

【矿脉2】老鬼徒弟的背叛（第6章无意识提及）
· 延伸方向：财阀内斗篇
· 预估规模：30-50章支线
· 爽点密度：2-3个中爽点（打脸/反转/复仇）
· 钩子数量：每5章至少1个相关钩子
· 与主线关联度：中（可通过财阀资源与主线连接）
```

## 适用边界

- **适用**：已写完3-10章正文，需要从已有内容反向推导后续大纲
- **强适用**：修改和优化阶段，已有正文需要梳理出完整大纲
- **强适用**：百万字长篇中期，需要从已写内容中挖掘新支线
- **弱适用**：开篇阶段（尚未有足够正文作为判例基础）
- **不适用**：从零开始的新书（无已写章节可反向推导）
- **慎用**：与正向大纲冲突时（正向大纲是主线，反向推导用于补充和优化）
