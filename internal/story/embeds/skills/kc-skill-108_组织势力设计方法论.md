# KC-SKILL-108 · 组织势力设计方法论

> **核心定位：** 从"述源"组织完整设定、大昭王朝官制体系、墨家派系设定中提炼的组织势力设计方法论。教你如何设计一个**有信念、有结构、有运作逻辑、有叙事张力**的组织势力，而非简单的"坏人组织"或"工具人势力"。

---

## 一、组织设计的七维框架

一个完整的组织必须回答七个核心问题。缺任何一维，组织都会显得单薄或悬浮。

| 维度 | 核心问题 | 设计产物 | 源提炼 |
|:-----|:---------|:---------|:-------|
| **信念维** | 他们相信什么？为什么存在？ | 宗旨+原则+行为三层信念体系 | 述源"故事是情感的载体，是传递美好的媒介" |
| **结构维** | 他们如何组织？权力如何分配？ | 组织结构图+权力流转路径 | 述源的"公司外衣+信仰内核"双重结构 |
| **运作维** | 他们如何运作？靠什么维持？ | 资源来源+决策机制+行动流程 | 述源的商业部门供养信仰部门的模式 |
| **成员维** | 什么样的人加入？忠诚从何而来？ | 成员画像+忠诚来源分层 | 述源"自由加入自由退出"的自我筛选机制 |
| **对外维** | 外界如何看待他们？他们如何对外？ | 公众形象+对外策略+接触界面 | 述源的合法公司形象vs真实的信念共同体 |
| **冲突维** | 内部矛盾是什么？外部敌人是谁？ | 内部分歧+异端定义+外部对手 | 述源对"背叛信念者"的清除逻辑 |
| **极限维** | 他们的天花板在哪里？什么能摧毁他们？ | 组织极限+致命弱点+崩溃条件 | 述源"故事比神更值得信任"的底层脆弱性 |

### 1.1 七维检验法

设计完组织后，用以下问题检验完整性：

```
□ 信念维：能用一句话说清这个组织为什么存在吗？
□ 结构维：新成员加入后，知道向谁汇报、听谁指挥吗？
□ 运作维：他们的钱/资源从哪里来？日常在做什么？
□ 成员维：一个普通人为什么要加入？又为什么不离开？
□ 对外维：路人怎么看他们？官方怎么看他们？同行怎么看他们？
□ 冲突维：他们内部吵什么？外部怕什么？
□ 极限维：如果要毁掉这个组织，第一步该做什么？
```

## 二、核心信念设计法——组织的灵魂

### 2.1 信念不是口号，是底层逻辑

从"述源"提炼的信念设计核心：**信念不是贴在墙上的标语，而是组织一切行动的底层操作系统**。

述源的信念——"故事是情感的载体，是传递美好的媒介"——体现在每一个决策中：
- 对作者有耐心 → 因为故事需要时间成长
- 给予多次机会 → 因为美好的故事值得等待
- 对异端零容忍 → 因为背叛故事的人是污染源
- 高层真诚祝福胜利者 → 因为好故事比权力重要

**信念设计三层次：**

| 层次 | 名称 | 功能 | 设计模板 | 述源示例 |
|:-----|:-----|:-----|:---------|:---------|
| **第一层** | 宗旨层 | 为什么存在——宏大叙事 | "让所有人都能______" | "让所有人都能感受到美好的故事" |
| **第二层** | 原则层 | 如何做——可操作准则 | "我们坚持______，反对______" | "作者有责任完成故事""故事不容亵渎" |
| **第三层** | 行为层 | 具体做法——日常行为 | "遇到X情况，我们做Y" | "给予三次机会但不无限循环""清除异端而非杀死" |

### 2.2 信念的"反向验证"

好的信念应该能推导出组织的所有行为。验证方法：

```
步骤1：写出组织的核心信念（一句话）
步骤2：列出组织的10个关键行为/决策
步骤3：问——"如果这个信念是真的，他们会这样做吗？"
步骤4：如果有3个以上行为推不出来，说明信念是空口号
```

**反面教材：** 某个组织声称"为了世界和平"，但行为却是到处杀人放火——除非你能解释"为什么杀人放火能带来世界和平"，否则这个信念就是假的。

## 三、组织结构设计法

### 3.1 表面结构与真实结构的反差

从"述源"提炼的结构设计精髓——**合法外衣 + 内在纽带的双重结构**：

| 层面 | 述源的结构 | 功能 | 设计要点 |
|:-----|:-----------|:-----|:---------|
| **表面结构** | 公司制运营，有完整的商业部门 | 可追溯、可审查、合法存在 | 必须看起来像一个正常组织 |
| **真实结构** | 以信念为纽带的信仰共同体 | 维持纯度、保证行动力 | 必须有不为人知的一面 |
| **连接方式** | 商业部门供养信仰部门 | 资源从合法渠道流向真实目的 | 两者的连接点要隐蔽但合理 |

**高层互动模式——"竞争-祝福"：**
- 竞争：高层之间争夺资源、争夺项目主导权
- 祝福：一旦竞争分出胜负，失败者真诚祝福胜利者
- 逻辑：因为目标一致（美好的故事），所以竞争是对事不对人
- 叙事价值：这种模式让组织既有效率又有人情味，避免"内斗必黑化"的俗套

### 3.2 五种组织结构原型

| 原型 | 典型代表 | 权力模式 | 优势 | 劣势 | 叙事价值 |
|:-----|:---------|:---------|:-----|:-----|:---------|
| **金字塔型** | 传统宗门/官僚体系 | 层级分明，命令自上而下 | 效率高、执行力强 | 僵化、底层无话语权 | 主角从底层逆袭的经典路径 |
| **网络型** | 秘密结社/地下组织 | 节点连接，无明确中心 | 隐蔽性强、难以摧毁 | 协调困难、效率低 | 主角寻找"幕后黑手"的悬疑感 |
| **同心圆型** | 宗教/信仰组织 | 核心层→中间层→外围层 | 核心稳固、层层保护 | 外围松散、易被渗透 | 主角逐层深入、接近真相的过程 |
| **联邦型** | 联盟/议会 | 多势力联合，各有主权 | 力量多元、互相制衡 | 内耗严重、决策缓慢 | 派系博弈、合纵连横的权谋戏 |
| **生态型** | 述源式组织 | 以信念为锚，自由流动 | 自我筛选、纯度极高 | 规模受限、依赖信念 | 信念崩塌=组织崩溃的张力 |

### 3.3 结构设计SOP

```
步骤1：选择1-2种结构原型（主结构+辅助结构）
  → 例：同心圆型（主）+ 金字塔型（辅：核心层内部有层级）

步骤2：设计"表面结构"——合法外衣
  → 是公司？是宗门？是官方机构？是民间社团？
  → 对外的组织架构图是什么样的？

步骤3：设计"真实结构"——内在本质
  → 真正的权力核心在哪里？
  → 哪些部门是幌子，哪些部门是真核心？

步骤4：设计权力流转路径
  → 决策从哪里产生？如何传递到执行层？
  → 资源从哪里来？如何分配？

步骤5：设计"结构漏洞"——叙事突破口
  → 哪里最脆弱？哪里最容易被渗透？
  → 主角可以从哪里切入？
```

## 四、成员忠诚设计法

### 4.1 忠诚不是靠纪律，而是靠认同

从"述源"提炼的忠诚设计核心：**最高级的忠诚是"我相信"，不是"我服从"**。

述源的忠诚构建三步法：
1. **自由加入自由退出** → 不认同的人自行离开 → 留下的都是信徒
2. **高层可接近性** → 没有层级壁垒 → 信任基础
3. **创始人的典范作用** → "故事比神更值得信任"的传说 → 信念具象化

### 4.2 忠诚的五个来源（从低到高）

| 层级 | 忠诚类型 | 驱动因素 | 表现 | 脆弱点 | 设计要点 |
|:-----|:---------|:---------|:-----|:-------|:---------|
| **L1** | 利益忠诚 | 给钱就干 | 拿多少钱做多少事 | 钱给够就反水 | 适合底层成员、外围成员 |
| **L2** | 恐惧忠诚 | 不服从就受罚 | 表面服从，暗中摸鱼 | 威慑消失就背叛 | 适合高压组织、反派组织 |
| **L3** | 情感忠诚 | 有归属感，像家人 | 愿意多付出，讲情面 | 情感破裂就动摇 | 适合小团体、主角团队 |
| **L4** | 信念忠诚 | 相信组织的理念 | 主动奉献，不计较得失 | 信念崩塌就崩溃 | 适合信仰组织、理想主义组织 |
| **L5** | 使命忠诚 | 将组织目标视为自己的生命意义 | 愿意牺牲一切，包括生命 | 几乎没有，但极稀有 | 适合核心成员、殉道者角色 |

**设计要点：** 一个组织的忠诚应该是**混合配比**的——大部分人是利益/恐惧忠诚，中间层是情感忠诚，核心层是信念/使命忠诚。全都是信念忠诚的组织不真实，全都是利益忠诚的组织没凝聚力。

### 4.3 忠诚设计SOP

```
步骤1：为组织设计"忠诚配比"
  → 核心层（5%）：信念忠诚+使命忠诚
  → 中间层（20%）：情感忠诚+信念忠诚
  → 执行层（50%）：利益忠诚+恐惧忠诚
  → 外围层（25%）：纯利益忠诚

步骤2：设计"晋升筛选机制"
  → 从执行层到中间层：需要什么考验？
  → 从中间层到核心层：需要什么证明？
  → 述源式：靠自我筛选——不认同的人自己走

步骤3：设计"忠诚锚点"——让成员留下的具体理由
  → 每个人加入组织都有一个"个人理由"
  → 这个理由最好和组织信念有交集，但不必完全重合
  → 例：某人加入述源是因为述源帮他完成了已故朋友的遗作

步骤4：设计"背叛触发点"
  → 什么情况下，一个忠诚成员会背叛？
  → 利益忠诚：钱不够了
  → 情感忠诚：被组织伤害了
  → 信念忠诚：发现组织信念是假的
```

## 五、对手/异端设计法

### 5.1 异端不是"和我们不一样"，而是"背叛了核心信念"

从"述源"的异端处理提炼的对手设计核心：**对手与组织的冲突必须是信念冲突，不是个人恩怨**。

述源的异端定义：
- 不是"不相信故事的人" → 那是外人，不是异端
- 而是"曾经相信、后来背叛了故事的人" → 这才是异端
- 因为"背叛"比"不信"更能污染信念的纯度

**异端处理的逻辑：**
- 不是惩罚 → 惩罚是因为对方做错了事
- 而是清除 → 清除是因为对方是污染源
- 死亡是仁慈 → 让其活着承受"故事崩坏"才是真正的清除
- 这种处理方式比单纯的"杀掉"更恐怖，也更有特色

### 5.2 对手设计三原则

| 原则 | 含义 | 反面教材 | 设计方法 |
|:-----|:-----|:---------|:---------|
| **对手有自己的逻辑** | 对手不是邪恶的化身，他们有自己的信念体系 | "我就是坏，就是要毁灭世界" | 为对手设计一套自洽的信念体系 |
| **冲突是信念冲突** | 冲突的根源是理念不同，不是个人恩怨 | "因为你杀了我师傅所以我要杀你" | 找到双方信念的核心矛盾点 |
| **对手让组织更鲜明** | 对手的存在应该反衬组织的信念，而不是混淆 | 打了半天不知道为什么而战 | 问：如果没有这个对手，组织的信念会模糊吗？ |

### 5.3 异端/对手设计SOP

```
步骤1：定义"什么是异端"
  → 不是"和我们不一样的人"
  → 而是"背叛了我们核心信念的人"
  → 背叛的具体表现是什么？

步骤2：设计"异端处理流程"
  → 发现→确认→审判→执行
  → 执行者是谁？用什么方式？
  → 有没有"救赎"的可能？还是必须清除？

步骤3：设计"镜像对手"
  → 一个和组织很像、但信念相反的对手
  → 例：述源 vs "为了好故事可以牺牲一切"的极端组织
  → 镜像对手最能凸显组织的边界和原则

步骤4：设计"对手的合理性"
  → 站在对手的角度，他们为什么是对的？
  → 如果你写不出对手的合理性，说明对手太单薄
```

## 六、组织叙事的六大冲突来源

组织设定不能只放着当背景，要能**产生故事、驱动剧情**。以下六大冲突来源，让你的组织"活"起来。

| 冲突来源 | 核心张力 | 典型情节 | 设计要点 |
|:---------|:---------|:---------|:---------|
| **信念的考验** | 当信念与现实冲突时如何选择 | 为了救一个人，要不要破坏组织原则？ | 设计"信念两难"——选哪边都有代价 |
| **内部的分裂** | 不同派系对信念的不同解读 | 激进派vs温和派，谁才是"真正的信徒"？ | 分裂的根源是"对同一句话的不同理解" |
| **创始人的神秘** | 创始人的身份/能力/行踪成谜 | 创始人是死是活？他留下的遗嘱是真的吗？ | 创始人的传说要比创始人本人更重要 |
| **异端的渗透** | 敌人从内部瓦解 | 最信任的人竟然是异端？ | 渗透者不能是脸谱化的坏人，要有自己的动机 |
| **极限的逼近** | 组织目标永远无法实现，如何面对 | "让所有人都有好故事"是不可能的，那还要坚持吗？ | 组织的终极目标最好是"不可及"的，这样才有悲剧感 |
| **合法与非法的边界** | 表面合法，实际在灰色地带运作 | 官方调查来了，要不要销毁证据？ | 灰色地带的操作要符合组织信念，不能是"为了坏而坏" |

### 6.1 冲突层级设计

```
第一层（日常冲突）：
  → 成员之间的小摩擦、任务执行中的小问题
  → 作用：展示组织的日常运作

第二层（中期冲突）：
  → 内部派系斗争、外部势力摩擦
  → 作用：推动剧情发展，展示组织的结构

第三层（高潮冲突）：
  → 信念的终极考验、组织的生死存亡
  → 作用：升华主题，展示组织的本质
```

## 七、组织势力设计SOP

```
步骤1：设计核心信念
  → 宗旨层（一句话，为什么存在）
  → 原则层（3-5条，如何做）
  → 行为层（10个具体行为，验证信念）

步骤2：选择组织结构原型
  → 从5种原型中选1个主结构
  → 可选1个辅助结构
  → 画出大致的权力结构图

步骤3：设计合法外衣与真实本质的反差
  → 表面上是什么组织？（公司/宗门/官方机构/民间社团）
  → 真实本质是什么？（信仰共同体/犯罪集团/秘密结社）
  → 两者如何连接？资源如何流转？

步骤4：设计成员忠诚体系
  → 五个层次的人员配比
  → 晋升筛选机制
  → 每个人加入的"个人理由"（至少设计3个典型成员）

步骤5：设计对手/异端的定义与处理逻辑
  → 什么是异端？
  → 如何发现、审判、执行？
  → 至少设计1个镜像对手

步骤6：设计创始人/领袖的形象
  → 公开形象（外界认知的）
  → 真实形象（内部知道的）
  → 传说形象（被神化的）
  → 三个形象可以不一样，差距越大越有戏剧性

步骤7：设计运作逻辑
  → 靠什么维持？（钱从哪里来？人从哪里来？）
  → 如何决策？（一人说了算？集体讨论？投票？）
  → 如何行动？（接到任务后，执行流程是什么？）

步骤8：设计六大叙事冲突来源
  → 每个冲突来源至少想1个具体情节
  → 标出哪些是日常冲突、哪些是中期冲突、哪些是高潮冲突

步骤9：设计组织的极限与天花板
  → 这个组织做不到什么？
  → 什么能摧毁这个组织？
  → 组织的终极目标为什么是"不可及"的？
```

## 八、常见坑点与避坑指南

| 坑点 | 症状 | 避坑方法 |
|:-----|:-----|:---------|
| **组织脸谱化** | 只有"好人组织"和"坏人组织"，没有灰色地带 | 每个组织都要有"做得对的地方"和"做得不对的地方" |
| **信念空泛** | 只有口号，没有具体行为支撑 | 用"反向验证法"——从信念能推导出所有关键行为吗？ |
| **结构太复杂** | 读者记不住谁是谁、哪个部门管什么 | 核心结构控制在3层以内，核心人物控制在7个以内 |
| **成员都是工具人** | 组织里的人没有个人诉求，全都是"为了组织" | 给每个重要成员设计一个"加入组织的个人理由" |
| **对手太弱** | 组织没有真正的威胁，一路平推 | 设计"镜像对手"——和组织很像但信念相反的对手 |
| **运作逻辑模糊** | 他们靠什么活下来？钱从哪来？人从哪来？ | 至少写清3个资源来源（钱、人、信息） |
| **组织万能** | 只要是这个组织的人，什么都能做到 | 设计"组织的极限"——明确他们做不到什么 |
| **创始人全知全能** | 创始人什么都算到了，一切都在计划中 | 创始人也要有"算错的地方"和"没想到的事" |
| **异端=敌人** | 所有反对组织的都是异端，都要消灭 | 明确区分"外人""对手""异端"——只有背叛者才是异端 |
| **忠诚靠嘴说** | 角色天天说"我对组织忠心耿耿"，但没有行为证明 | 用行动证明忠诚——设计"忠诚考验"情节 |

> **方法论归旨：** 组织势力的本质不是"设计一群人的集合"，而是"设计一个有灵魂的生命体"。信念是它的灵魂，结构是它的骨架，成员是它的细胞，对手是它的镜像。最好的组织势力，让读者在理解组织的过程中，理解这个世界的运行逻辑——以及人性的复杂与光辉。
