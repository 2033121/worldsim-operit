# 扫榜与市场研究方法论

## 一、核心本质：扫榜是作者的市场调研

**扫榜 = 系统性研读目标平台榜单头部作品 + 拆解爆款底层逻辑 + 形成可复用方法论**

扫榜不是"看书"，是"做调研"。读者看书是为了娱乐，扫榜看书是为了找规律。

| 维度 | 读者看书 | 扫榜看书 |
|------|----------|----------|
| **目的** | 娱乐享受 | 市场调研 |
| **心态** | 被动接受 | 主动拆解 |
| **关注点** | 剧情好不好看 | 为什么能火的底层逻辑 |
| **输出** | 无 | 可复用模板/方法论 |
| **价值** | 即时快乐 | 长期创作能力 |

**核心认知**：写作是一门手艺，也是一门生意。知道市场要什么，才知道自己写什么。闭门造车的结果，大概率是死路一条。

---

## 二、五步闭环流程

```
定标 → 粗扫 → 精扫 → 复盘 → 仿写
  │       │       │       │
  └───────┴───────┴───────┴────→ 完整闭环
```

五步环环相扣，缺了任何一步，扫榜的效果都会大打折扣。

---

## 三、第一步：定标——选对方向比努力更重要

定标错了，后面所有努力都是白费。

### 3.1 锁定唯一平台

不同平台的用户画像、阅读习惯、付费逻辑完全不同，混扫会导致认知混乱。

**四大主攻平台特性对比**：

| 平台 | 用户画像 | 核心调性 | 付费模式 | 适合方向 |
|-----|---------|---------|---------|---------|
| **番茄小说** | 下沉市场，三四线城市，年龄偏大 | 快节奏、强钩子、新媒体风 | 免费+广告 | 都市系统、玄幻修仙、穿越历史 |
| **起点中文网** | 一二线城市，年轻男性居多 | 精品化、慢热、设定党 | 订阅付费 | 玄幻奇幻、科幻星际、游戏悬疑 |
| **七猫小说** | 下沉市场，女性用户多 | 保底制、节奏快 | 免费+保底 | 甜宠、重生复仇、年代文 |
| **晋江文学城** | 女性为主，年轻用户多 | 情感细腻、人设优先 | 付费订阅 | 甜宠、马甲、团宠、宅斗 |

**铁则**：选定一个平台，全程只扫这个平台。写番茄就只扫番茄，写起点就只扫起点。

### 3.2 锁定细分赛道

大品类下还要再细分，越细分越精准。

**番茄男频热门赛道**：
- 都市高武 / 系统流
- 玄幻修仙 / 凡人流
- 穿越历史 / 架空
- 末世求生 / 无限流

**番茄女频热门赛道**：
- 甜宠 / 马甲 / 团宠
- 重生复仇 / 年代文
- 玄幻言情 / 仙侠
- 真千金 / 假少爷

**起点男频热门赛道**：
- 玄幻 / 奇幻
- 科幻 / 星际
- 游戏 / 悬疑
- 诸天 / 无限流

**选赛道三原则**：
1. **自己擅长**：写自己熟悉的领域，才能写得好
2. **市场有需求**：榜单上有同类型的爆款，证明有读者
3. **有差异化空间**：不是红海一片，还有创新的机会

### 3.3 选对榜单

不同榜单的价值天差地别，选对榜单事半功倍。

**高价值榜单（优先扫）**：

| 榜单 | 价值星级 | 说明 |
|------|:--------:|------|
| 畅销榜/热销榜 | ⭐⭐⭐⭐⭐ | 付费验证，最能反映读者真实偏好 |
| 新书榜（3个月内） | ⭐⭐⭐⭐⭐ | 市场风向标，反映最新趋势 |
| 在读榜/飙升榜 | ⭐⭐⭐⭐ | 下一个爆款预判，增长最快的书 |

**中价值榜单（参考扫）**：

| 榜单 | 价值星级 | 说明 |
|------|:--------:|------|
| 三江榜/推荐榜 | ⭐⭐⭐ | 平台扶持方向，品类倾斜参考 |
| 完结榜 | ⭐⭐⭐ | 常青树作品，整体架构参考 |

**低价值榜单（不推荐）**：
- ❌ 总榜TOP100：分类混杂，参考价值低
- ❌ 老书榜：时效性差，逻辑可能过时
- ❌ 大神新书榜：光环效应太强，学不来

### 3.4 确定对标范围

**目标数量**：同分类榜单TOP20-50本

**最终筛选**：选出3-5本最值得深度拆解的

**筛选标准**：
- ✅ 和你的创作方向匹配
- ✅ 非大神白金出品（新人的机会，可复制性强）
- ✅ 数据稳定上涨（不是昙花一现）
- ✅ 能说出"我学到了什么"（有明确学习点）
- ❌ 大神光环太强，学不来
- ❌ 方向完全不匹配
- ❌ 说不清为什么火
- ❌ 数据一般或下滑

## 四、第二步：粗扫——快速筛选，精准定位

粗扫的目标是：用最少的时间，找出最值得深度拆解的书。

### 4.1 10分钟速判法

每本书只花10分钟，判断值不值得精扫。

**看什么（按顺序）**：

| 序号 | 看什么 | 核心问题 | 用时 |
|:----:|--------|---------|------|
| 1 | 书名 + 简介 | 核心卖点是什么？用什么词/句式吸引人？ | 1分钟 |
| 2 | 标签/分类 | 题材是什么？融合了哪些元素？ | 1分钟 |
| 3 | 首章标题 | 有没有悬念/冲突/金句？ | 1分钟 |
| 4 | 更新频率 + 总字数 | 日更多少？写了多少？稳定性如何？ | 1分钟 |
| 5 | 开篇3章 | 主角是谁？核心矛盾？金手指？章末钩子？ | 6分钟 |

### 4.2 判断标准

**值得精扫的书（满足3条以上）**：
- ✅ 开篇3章有强钩子，能抓住你
- ✅ 你能明确说出"这本书为什么火"
- ✅ 有你可以直接学习的点
- ✅ 非大神但数据好
- ✅ 同赛道同类型

**不值得精扫的书**：
- ❌ 大神光环太强，学不来
- ❌ 你的方向完全不匹配
- ❌ 你说不清它为什么火
- ❌ 数据一般或下滑
- ❌ 开篇就劝退你

**核心原则**：连你自己都看不下去的书，就算数据再好也别学——你学不来的。

## 五、第三步：精扫——深度拆解，提炼规律

精扫是扫榜最核心的环节，决定了扫榜的质量。

### 5.1 五大拆解维度

#### 维度1：开篇拆解（最重要）

开篇决定了80%的读者留存。

**逐章拆解前10章**，每章记录：
- 核心事件是什么？
- 钩子/爽点在哪里？
- 情绪高低点？
- 留下什么悬念？

**重点分析**：
- 开篇1000字如何抓人？
- 背景如何交代？（什么时候交代？交代多少？）
- 金手指何时出场？（第几章出场？出场方式？）
- 章末悬念如何设计？
- 前三章的节奏规律是什么？

#### 维度2：人设与金手指拆解

**人设分析**：
- 主角身份/性格/痛点是什么？
- 什么让读者代入/喜欢主角？
- 配角如何设计（不工具人）？
- 反派有没有自己的逻辑/魅力？

**金手指分析**：
- 类型？（系统/传承/重生/异能...）
- 出场方式？
- 和主线的绑定度？
- 升级逻辑？
- 有没有代价/限制？

#### 维度3：节奏与爽点拆解

**情绪曲线法**：
标注每一章的情绪值：
- 低谷：日常/压抑/困境
- 铺垫：积累/伏笔/准备
- 高潮：爆发/冲突/逆袭
- 爽点：打脸/升级/收获

**统计规律**：
- 多少章一个小爽点？
- 多少章一个大高潮？
- 高潮之间如何铺垫？
- 爽点密度是多少？

**提炼爽点类型**：
- 扮猪吃虎
- 打脸反击
- 越级挑战
- 意外收获
- 情感升温
- 身份揭秘
- ...

#### 维度4：剧情架构拆解

**整体结构**：
- 分为几个大阶段？
- 每个阶段的中心事件是什么？
- 主线如何推进？
- 节奏是快还是慢？

**支线设计**：
- 有哪些重要支线？
- 支线如何服务主线？
- 支线什么时候收？

**副本/地图设计**：
- 有几个副本/世界/地图？
- 每个副本的核心矛盾是什么？
- 副本如何递进（难度/收益）？

#### 维度5：读者反馈拆解

读者用脚投票的结果，最真实。

**看什么**：
- 评论区高赞在夸什么？
- 读者骂得最多的是什么？
- 哪些章节追读率高？
- 哪些章节读者流失？

**为什么**：
- 为什么读者喜欢这个点？
- 为什么读者讨厌这个点？
- 作者做对了什么？做错了什么？

**启示**：
- 我要学什么？
- 我要避免什么？

### 5.2 精扫记录表模板

```
【书籍：《书名》
平台：番茄/起点/...
分类：都市/玄幻/...
数据：在读XX万 / 字数XX万

1. 开篇拆解
   - 开篇公式：
   - 前三章节奏：
   - 钩子设计：
   - 可复用点：

2. 人设与金手指
   - 主角人设：
   - 金手指类型：
   - 配角设计：
   - 反派设计：

3. 节奏与爽点
   - 爽点密度：X章一个小爽点，X章一个大高潮
   - 主要爽点类型：
   - 情绪曲线规律：

4. 剧情架构
   - 整体结构：
   - 主线推进方式：
   - 支线/副本设计：

5. 读者反馈
   - 读者最喜欢的点：
   - 读者最讨厌的点：
   - 我的启示：

   - 这本书为什么火：
   - 我能直接学的：
   - 我要避免的：
```

## 六、第四步：复盘——找共性，找差异，做沉淀

单本书的拆解价值有限，3-5本书放在一起对比，才能提炼出真正的规律。

### 6.1 找共性——提炼底层规律

拆解3-5本后，提炼共同点：

**开篇共性**：
- 开篇都是怎么抓人的？
- 前3章的节奏规律是什么？
- 金手指出场的时机？

**人设共性**：
- 爆款主角有什么共同标签？
- 金手指有什么共同特点？
- 反派设计有什么规律？

**爽点共性**：
- 高频爽点类型是什么？
- 爽点节奏是什么？
- 爽点设计有什么共同套路？

**平台适配**：
- 这个平台的用户喜欢什么调性？
- 这个平台的节奏是快还是慢？
- 这个平台的付费点在哪里？

### 6.2 找差异——发现差异化机会

**差异化分析**：
- 这些爆款里，有哪些微创新？
- 在成熟套路里，做了什么不同？
- 哪些点是别人没做过的？

**核心问题**：
- 我的差异化在哪里？
- 我能在成熟套路里加什么新东西？
- 我怎么避免同质化？

**差异化公式**：
```
我的作品 = 成熟套路（验证过的） + 微创新（我的独特价值）
```

**注意**：创新不是从零开始创造，而是在已经被验证的基础上做微创新。
完全创新 = 找死；完全照搬 = 死路。中间的微创新，才是正确答案。

### 6.3 做沉淀——形成自己的方法论

扫榜的最终目的，是形成你自己的工具箱。

**沉淀内容**：

| 沉淀类型 | 说明 | 示例 |
|---------|------|------|
| **开篇公式** | 写出自己的开篇模板 | 黄金三章公式 |
| **爽点清单** | 列出学到的爽点类型 | 打脸、升级、揭秘、收获... |
| **金句摘录** | 积累觉得好的表达 | 书名句式、台词模板 |
| **人物模板** | 总结人设的公式 | 主角人设五要素 |
| **节奏模板** | 不同章节的节奏规律 | X章一个小爽点，X章一个大高潮 |

**铁则**：不做沉淀的扫榜，等于白扫。看了再多，不记下来，不用，等于没看。

## 七、第五步：仿写——从学到会

看了≠会了。只有写出来，才是真的会了。

### 7.1 仿写的正确姿势

```
仿写 = 仿结构 / 节奏 / 底层逻辑
✗ 不等于：抄情节 / 抄人设 / 抄原文
```

**绝对禁止**：
- ❌ 复制粘贴原文
- ❌ 改个名字就当自己写的
- ❌ 套用核心剧情框架
- ❌ 抄袭人物设定和关系

### 7.2 四项仿写练习

**练习1：仿开篇**
- 用学到的开篇公式，写一个新书开篇
- 重点：节奏、钩子、金手指出场时机

**练习2：仿爽点**
- 用学到的爽点设计，写一个打脸/升级/揭秘场景
- 重点：情绪铺垫、爆发时机、爽感设计

**练习3：仿人设**
- 用学到的人设公式，设计一个新角色
- 重点：身份、性格、痛点、成长线

**练习4：仿节奏**
- 用学到的节奏规律，写一章剧情推进
- 重点：信息密度、情绪曲线、章末钩子

### 7.3 对比优化

仿写完成后，和原文对比：
1. 我的和原版差距在哪里？
2. 哪些地方感觉不对？
3. 怎么改才能更好？
4. 学到的公式，我用对了吗？

**迭代循环**：仿写 → 对比 → 修改 → 再仿写 → 再对比... 直到融会贯通。

## 八、扫榜频率与时机

### 8.1 扫榜频率建议

| 类型 | 频率 | 说明 |
|-----|------|------|
| **日常扫榜** | 每周2-3次，每次30分钟 | 保持市场敏感度 |
| **新书前** | 连续扫榜1周，每天1小时 | 选题定位，找方向 |
| **新书期** | 前30章每天看数据+扫榜 | 快速调整优化 |
| **中期崩文** | 立刻扫榜找原因 | 诊断问题，调整方向 |
| **卡文期** | 扫榜找灵感 | 突破瓶颈 |
| **月度复盘** | 每月1次系统复盘 | 总结规律 |
| **季度评估** | 每季度更新市场报告 | 重新评估方向 |

### 8.2 扫榜的最佳时机

- 开新书之前：最重要的扫榜时机，决定方向
- 数据下滑时：找原因，调整方向
- 卡文写不动时：找灵感，突破瓶颈
- 写完一卷后：对比差距，优化下一卷

## 九、常见问题与误区

### 误区1：扫了很多但用不上

**原因**：只看不记，只记不用

**解法**：
1. 每次扫榜必须写记录
2. 每次写作前看一遍记录
3. 有意识地在写作中应用
4. 写完后对比分析

### 误区2：不知道学什么

**原因**：没有目的性扫榜

**解法**：
1. 先明确自己缺什么
   - 开篇不好？→ 重点学开篇
   - 爽点不够？→ 重点学爽点
   - 人设单薄？→ 重点学人设
2. 带目的去扫，有针对性

### 误区3：扫榜和原创冲突

**答案**：不冲突，反而互相成就

**原理**：
- 扫榜是站在巨人肩上
- 原创是创造独特价值
- 扫榜 → 学习 → 转化 → 原创

**关键**：扫榜不是抄袭，是"站在市场验证过的基础上创新"。

### 误区4：只扫大神的书

**问题**：大神的书学不来——人家有人气加成，有品牌效应，有读者基础。

**正确做法**：
- 重点扫新人黑马的书
- 数据好、作者不知名的
- 这种才是你能学的

## 十二、使用建议

1. **从定标开始**：先选好平台和赛道，再开始扫，不要乱扫
2. **带目的扫**：先知道自己缺什么，再去扫，效率最高
3. **边扫边记**：不做记录的扫榜等于白扫
4. **扫完就用**：学到的东西立刻用到写作里，不然很快就忘
5. **定期复盘**：每月做一次系统复盘，更新自己的方法论
6. **持续迭代**：市场在变，读者在变，你的认知也要跟着变
