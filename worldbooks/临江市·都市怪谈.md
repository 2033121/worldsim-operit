# 世界书：临江市·都市怪谈

## A1 世界观
临江市，一座临江的工业老城。表面是普通的三线城市，暗处藏着"里世界"的痕迹：深夜地铁的异常停电、旧城区墙角的血色涂鸦、据说能看见'那个东西'的算命摊。普通人照常生活，只有极少数人知道——这座城市每年都会"吞掉"几个消失的人，而他们的名字会被所有人忘记，仿佛从未存在过。

## A2 物理与超自然规则
1. 存在"灵体"与"异常现象"，但普通人肉眼不可见；普通人灵力上限极低，无法主动对抗灵体。
2. "消失者"现象：每年固定时段（阴历七月）失踪概率上升；被"吞掉"的人会从所有人的记忆中消失。
3. 少数人拥有微弱"灵视"（看到异常），且多为被动触发；强行直视灵体会导致精神损伤（san值下降）。
4. 现实社会规则（法律、物理、经济）正常运转，灵异事件必须掩盖在"意外/巧合"的外衣下。
5. 灵体遵循"规则"：大多怕光、怕盐、怕叫出真名；普通人的恐惧会"喂饱"它们。

## A3 社会结构
临江市人口约80万，社会分层明显：老城区（贫民区，怪谈高发地）、新城区（写字楼与商场）、江畔（老工业区，废弃厂房多）。本地有三大社区纽带：老城区的街坊会、新城区的商会、江畔的船帮。市民普遍迷信但又耻于承认；电视台有档深夜栏目《夜半听风》专门讲都市传说。

## A4 地理
- 旧城区：主角住地。密集的老楼、夜市、早餐店（老陈的店）、废弃书店、地铁3号线（怪谈高发）。
- 新城区：商业中心，有临江大厦、中心医院、警察局。
- 江畔工业区：废弃厂房、货运码头，"消失者"传闻的重灾区。
- 关键地点：旧城区·地铁3号线站台（断手事件发生地）、废弃书店（藏着线索）、老陈早餐店（情报集散地）。

## A5 势力速览
- 街坊会（旧城区）：地头蛇组织，表面是民间互助会，实际把控旧城区灰色生意。老大外号"刘三爷"。
- 青禾集团（新城区）：明面是房地产巨头，暗中收购旧城区物业——有传言他们"知道些什么"。
- 特殊事务科（存在与否是机密）：据说处理"异常"的政府机构，只存在于传说中。
- 夜半听风栏目组：都市传说的传播者，主播"阿风"在收集怪谈素材。

## B1 世界秘密
- 青禾集团在临江大厦地下建有"收纳库"，收藏灵体与异常物（包括地铁3号线的断手）。
- "消失者"的真相：临江市的河底沉着一件古代容器"镇魂瓮"，每年七月它需要"祭品"；青禾集团知道这件事，并在暗中挑选祭品。
- 老陈（早餐店老板）年轻时是特殊事务科的外勤，现在退休隐居，但他记得一切。
- 主角身上有微弱灵视潜质（家族遗传），这让他成为"被选中"的观察者——镇魂瓮开始注意到他。

## B2 事件类型池
- 日常线：早餐店闲聊、夜班工作、房东催租、街坊八卦（低severity 0.1-0.3）
- 冲突线：与街坊会摩擦、青禾集团收购逼迫、警察盘问、混混找茬（0.4-0.6）
- 奇遇线：地铁异常、废弃书店线索、灵视触发、被'人'跟踪（0.7-0.9）
- 特殊：七月临近时的"消失者"前兆（城市级大事件，0.9+）

## B3 弧线建议
第一弧（约10-15天）：主角在旧城区遭遇"地铁断手"事件 → 发现灵视能力 → 结识老陈 → 初步接触青禾集团的秘密。
第二弧：追踪"消失者"传闻 → 卷入夜半听风栏目调查 → 发现镇魂瓮的存在。
第三弧：七月来临，主角必须在"被选中"与"反抗"之间抉择 → 与青禾集团正面对抗 → 真相与牺牲。

## B4 伏笔清单
- fs-01 地铁断手（第一弧核心，第1-3天埋设，第8-12天回收）
- fs-02 老陈的过去（日常闲聊中透露，第10-15天回收）
- fs-03 镇魂瓮低语（主角灵视触发时听到，贯穿全书，最终弧回收）
- fs-04 夜半听风·阿风（第5天登场，中期关键情报源）
- fs-05 青禾集团地下收纳库（第12天起暗示，第二弧回收）

## C 叙事约束
- 文风：都市怪谈，悬疑+轻惊悚，拒绝中二玛丽苏；克制描写灵异，留白比直白更吓人。
- 视角：第三人称限知（跟随主角），主角不知道的秘密不写进正文。
- 节奏：Scene（场景慢放）/ Summary（概括）/ Skip（跳跃）三种时间处理，跳跃必须交代状态/关系/伏笔变化。
- 结局：不做强行圆满，允许开放式与牺牲结局；伏笔必须回收或明确放弃。

## D 内容安全边界
- 禁止血腥暴力细节描写（断手事件只写"视觉冲击"不写器官细节）。
- 禁止对现实宗教、民族的恶意影射；灵异元素纯虚构。
- 涉及未成年人保护：不出现未成年角色进入危险情境的描写。
- 心理健康：主角的恐惧与创伤描写克制，不鼓励自伤；必要时给出"寻求帮助"的剧情出路。
