## 一、调研发现：六大可借鉴项目/产品

### 1. NeuroBook（GitHub ★415 · TypeScript）——"用工程的方法写完长篇"
> 设定不吃书 · 伏笔有账本 · 文字没AI味 · AI听指挥

**核心理念（与 WorldSim 天然契合）**：
- **世界状态由引擎推算，而不是靠模型记忆**——和 WorldSim 的 State Engine 事件溯源完全一致！
- **伏笔像技术债一样记账追踪**——planted→progressing→resolved 全生命周期
- **成稿用 360 条规则做 lint**——一致性自动检查
- 正文是本地 Markdown + SQLite，随时带走

**借鉴点**：伏笔账本系统、一致性 lint 规则、设定文件树（世界书分层管理）

### 2. NovelClaw（GitHub ★357 · Python）——"动态记忆优先的长篇协作框架"
> structured long-form fiction workspace：sessions / storyboards / manuscript surfaces / **character and world views** / **editable memory banks**

**借鉴点**：角色视图 + 世界视图分离（每个角色/地点都有独立视图卡片）、可编辑记忆库

### 3. 马良写作（中文产品）——"7个Agent像编辑部一样分工协作"
- 三级大纲 + 知识图谱 + 角色设定管理
- 写百万字长篇**不吃书不烂尾**
- 支持 15+ 大模型按需切换（和我们的模型分层理念一致！）

**借鉴点**：编辑部多Agent分工（主编/人设/世界观/文笔各自负责）、三级大纲、知识图谱式角色关系

### 4. 链智云·AI小说工厂——"多智能体引擎一键生成长篇网文"
- 长程一致性审计 + 伏笔与世界观管理
- **一键导出 epub / 起点 / 番茄格式**（网文平台格式！）

**借鉴点**：网文平台导出格式（起点/番茄）、长程一致性审计

### 5. 蛙趣拼文——"3000+网文作者的AI日更神器"
- 世界观管理、角色追踪、伏笔系统、千章大纲，防写崩
- **本地向量记忆**（长篇"管不住"的本质问题：写30章角色崩溃前后矛盾）

**借鉴点**：向量记忆检索（我们已有记忆系统，可加向量）、千章大纲管理

### 6. simp-skill（GitHub ★284）——"不教PUA，只教真心"
- 恋爱关系模拟 skill：从心动到相处的关系进展模拟

**借鉴点**：好感度/关系进展的分阶段模拟（对应多女主感情线）

## 二、网文读者要什么（调研提炼）

| 用户需求 | 网文机制 | 技术方案 |
|---------|---------|---------|
| 奇特的世界 | 独特世界观 + 规则可探索 | 世界书分层 + **灵视解锁层级**（越探索越深） |
| 各种事件和遭遇 | 事件类型池 + 因果链 | 事件类型扩展（奇遇/危机/修罗场/机遇）+ **遭遇链**（A触发B） |
| 多女主 | 感情线 + 修罗场 | **女主池**（性格/背景/线路）+ 好感度系统 + 感情事件 |
| 重要配角 | 群像刻画 | **角色谱系**（重要配角/反派/路人）+ 独立记忆流 |
| 只见过几年 | 时间跨度 | **时间轴系统**（跨年Skip）+ 角色年表（何时出现/离开） |
| 变化的地点 | 场景随剧情演变 | **地点系统**（状态会变：被毁/繁荣/污染）+ 地点记忆 |
| 世界因主角而变 | 蝴蝶效应 | **影响反馈**：主角行动→世界状态→未来事件池重排 |

## 三、WorldSim 网文引擎升级方案

### 🔴 P0（先做，让人物和世界"活"起来）

**1. 人物系统升级：角色谱系 + 关系图 + 多女主**
- 角色分类：主角 / 女主×N / 重要配角 / 反派 / 路人NPC
- 每个人独立：persona + 记忆流 + 关系网
- **关系系统**：双向好感度/信任/羁绊值，随时间自然演化（久不联系会淡，共同经历会深）
- **女主系统**：女主池（不同性格/背景），好感度触发感情事件，感情线推进→确立关系→修罗场
- **角色生命周期**：注册时带"活跃期"（如2024-2027），到点触发离开/远去/死亡——"只见过几年"的悲欢

**2. 地点系统：会变化的世界**
- locations 表：名称/类型/氛围/状态/常驻角色
- 地点状态随剧情变化（地铁站被封、旧书店起火、巷子拆建）
- 主角行为可改变地点（救下书店老板→书店成为安全屋）

**3. 世界影响反馈（蝴蝶效应）**
- 主角行动提案提交时，世界 Agent 评估"此行动对世界的影响"→ 写回 global_events / 势力状态 / 未来事件池
- 影响力积累：主角从"无名小卒"→"改变城市的人"

### 🟡 P1（丰富剧情）

**4. 事件系统扩展**
- 事件类型池：日常/冲突/奇遇/机遇/危机/感情/修罗场/支线/主线
- **遭遇链**：事件 A 的选项/结果触发事件 B（因果）
- 事件-角色绑定：指定事件涉及角色（触发对话+关系变化）

**5. 时间轴系统**
- 月/季/年推进（Skip 跨年块）
- 角色年表：谁在什么时间出现/活跃/离开

**6. 伏笔账本（NeuroBook 理念）**
- 伏笔登记：planted→progressing→resolved 全追踪
- 超期提醒：埋了 N 章没回收 → 提示回收或宣告废弃

### 🟢 P2（网文体验）

**7. 爽点系统**
- 事件模板库：打脸/装逼/收获/成长/危机解除
- 张力引擎升级为"网文节奏"（铺垫→高潮→爆发→收束）

**8. 网文导出格式**
- 起点/番茄格式章节输出 + epub 导出

**9. 一致性 lint（NeuroBook 360条理念）**
- 写完后自动检查：角色姓名/关系/地点/伏笔一致性，不过自动修订

## 四、落地路线（与现有代码衔接）

| 优先级 | 模块 | 现有基础 | 新增 |
|--------|------|---------|------|
| P0-1 | 关系系统+多女主 | entities + 记忆系统 | relationship 双向图 + 女主池 + 感情事件 Agent |
| P0-2 | 地点系统 | 已有 location 字段 | locations 表 + 地点状态机 + 地点 Agent |
| P0-3 | 世界影响反馈 | State Engine 提案 | 世界 Agent 影响评估 + 事件池重排 |
| P1 | 事件扩展+遭遇链 | EventGenLLM | 事件类型池 + 因果链 + 事件-角色绑定 |
| P1 | 时间轴+角色年表 | Skip 跨天 | 跨年块 + 年表记录 |
| P2 | 爽点+伏笔账本+导出 | 张力引擎+novel | 模板库 + 伏笔追踪 + 起点/番茄导出 |

> 核心原则：**状态由引擎推算不靠模型记忆**（NeuroBook）——我们已有 State Engine，天然正确。
> 模型分层已就绪（fast/normal/premium）——多个 Agent 可以各司其职，加 Agent 不加成本焦虑。
