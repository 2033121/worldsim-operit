# WorldSim · 世界模拟器

> **让世界先活起来，故事自然发生。**

WorldSim 是一套"**活的世界生成引擎**"：它搭建一座虚构的城市、一群有血有肉的人物、一张层层展开的真相之网，让这个世界**自行运转、自然演化**，最终把演化出的每一天，变成一部真正能读的**长篇小说**。

它不是一个"自动写小说工具"，而是一个"**先创造一个世界，再让这个世界讲故事**"的创作系统。

---

## 一、它解决什么问题

传统小说创作（包括 AI 辅助创作）有一个共同困境：

- 大纲写着写着就"散"了；
- 人物前后行为矛盾、说着说着"人设崩了"；
- 埋下的伏笔写着写着就忘了回收；
- 剧情靠硬编，缺乏"世界自己的逻辑"。

WorldSim 的答案是：**不直接写故事，而是先养一个世界。**

- 这个世界有它自己的规则（世界观）、势力、秘密和天气；
- 每个角色有自己的身份、性格、记忆和欲望，会自己"过日子"；
- 事件之间环环相扣：一个选择引发一连串后果；
- 伏笔被埋下后，会在漫长的日常里慢慢酝酿，直到某一天自然爆发。

故事，是这个活世界自己长出来的。

---

## 二、核心能力

### 🌍 1. 活的城市（世界观引擎）
- 只需一份"世界设定书"，就能生成一座完整虚构城市：社会结构、势力格局、隐藏真相、城市氛围。
- 世界"很大但只露出冰山一角"：越往后走，越深的真相才慢慢浮出水面——像剥洋葱，也像真实世界。

### 👤 2. 有灵魂的人物（角色系统）
- 每个角色都有独立档案：身份、性格、说话方式、记忆、目标、秘密。
- 角色有自己的记忆流，会记得之前发生过的事，并影响之后的言行。
- 人物关系不是设定死的，而是在相处中自然演化：信任、猜疑、心动、决裂……都"长"出来。

### 🎬 3. 会讲故事的导演（剧情系统）
- 系统里有一位"总导演"，像写小说大纲一样，把漫长的日子切成一幕幕"剧情段落"：
  - 这一段主角要达成什么目标；
  - 反派这一段会做什么、怎么施压；
  - 哪些伏笔要酝酿、哪些要回收；
  - 这一段结束时要给读者一个怎样的"爽点"。
- 段落大纲会被完整记录下来——**不会写着写着忘了前面发生了什么**。

### ⏳ 4. 张弛有度的节奏（时间系统）
- 平淡的日子不会被硬写成一章流水账：它会被"浓缩"成几行有信息量的过渡——日子在过、伏笔在攒、主角在变。
- 需要时时间可以大步跳跃（几天、几周、甚至半年），需要时又放慢放大——**节奏由剧情说了算，不由日历说了算**。

### 📚 5. 伏笔账本（悬念系统）
- 每一个埋下的伏笔都有记录，还有"酝酿度"：它会随着日常慢慢发酵，成熟后自然触发爆发情节。
- 长篇小说不会"断头"——伏笔有埋必有收。

### 📖 6. 长篇小说生成（小说引擎）
- 把世界演化出的每一天，自动编排成章节：开局钩子、对话交锋、小高潮、结尾悬念，按网文的节奏来。
- **跨章节记忆**：写第 20 章时，还记得第 1 章埋的线——前情提要、伏笔清单随章注入。
- 支持一键导出多种阅读格式。

## 三、工作流程

```
① 定世界    —— 写一份"世界设定书"（城市、规则、势力、秘密、主角）
② 养世界    —— 让世界自行运转：角色过日子、事件发生、关系演化、伏笔酝酿
③ 看世界    —— 每天的世界动态、人物命运、剧情进展，像看一部活的编年史
④ 出小说    —— 一键把世界演化史编排成章、生成小说，可反复调整
```

整个过程是"**模拟 → 观察 → 成书**"，而不是"写作 → 硬编 → 修补"。

## 四、现在的成果（实测）

- 完成了一座虚构城市《浮城·异能打工人》的完整设定与演化：
  - **13 名角色**全部有独立灵魂（主角、导师、女主、对手、掮客……关系网自然生长）；
  - **30+ 天世界演化**，1400+ 条世界动态，伏笔与遭遇环环相扣；
  - **剧情段落自动规划**：总导演把演化切成一幕幕有目标的"戏"；
  - **10 章小说**自动成书，具备：开局钩子、主角主动、对话交锋、爽点、结尾悬念、跨章伏笔回收。

**一句话总结当前状态：世界已活，故事已能自动长出，且越写越像一本能追更的网文。**

## 五、它可以用在哪

| 场景 | 怎么用 |
|------|--------|
| **网文/长篇小说创作** | 设定世界观 → 养世界 → 自动出稿，作者负责改与把关 |
| **游戏世界观设计** | 生成一座活的城、一群活的 NPC，甚至一套自行运转的势力动态 |
| **剧本/影视策划** | 用世界演化推演人物关系与情节走向，做前期世界构建 |
| **交互叙事 / 沉浸式内容** | 世界持续演化，读者/玩家的选择影响后续走向 |
| **创意灵感引擎** | 输入一句话设定，得到一整个世界 + 一串能写的故事线 |

## 六、未来方向

- **更深的角色意志**：每个角色拥有更强的自我目标与主动性，世界冲突更"自燃"。
- **读者互动**：读者可以投喂选择，影响世界走向（真正的"参与式故事"）。
- **多世界观并行**：一座城跑完，换一套设定再来一座，形成"创作宇宙"。
- **人类协作模式**：作者在关键节点介入（改大纲、定方向、裁剧情），人机共创长篇。
